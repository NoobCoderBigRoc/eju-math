# 三角形の性質

### 五心

| 心 | 定義 | 性質 |
| --- | --- | --- |
| 外心 $O$ | 3 辺の垂直二等分線の交点 | $OA = OB = OC = R$。鈍角三角形では三角形の外部にある |
| 内心 $I$ | 3 つの内角の二等分線の交点 | 3 辺までの距離が等しく、内接円の半径 $r$ |
| 重心 $G$ | 3 本の中線の交点 | 中線を頂点から $2 : 1$ に内分する |
| 垂心 $H$ | 3 本の垂線の交点 | 鋭角三角形では内部、鈍角三角形では外部 |
| 傍心 | 1 つの内角と 2 つの外角の二等分線の交点 | 傍接円の中心 |

### チェバの定理・メネラウスの定理

三角形 $ABC$ 与点 $P$（チェバ：三顶点的连线共点）／直线截三角形（メネラウス）：

$$\frac{AF}{FB} \cdot \frac{BD}{DC} \cdot \frac{CE}{EA} = 1$$

（三个比值的乘积为 1；绕三角形一周取比，别取错方向。）角の二等分線の性質：内角平分线分对边之比等于两邻边之比。

**演習：チェバの定理**

$\triangle ABC$ の辺 $BC$、$CA$、$AB$ 上の点 $D$、$E$、$F$ が $BD : DC = 2 : 1$、$CE : EA = 1 : 1$、$AF : FB = 1 : 2$ を満たすとき、$AD$、$BE$、$CF$ は1点で交わるか。

??? example "思路・解答"
    **答案**

    交わる（1点で交わる）

    **思路**

    三个比值连乘，看是否等于 1。

    **解答**

    $$\frac{BD}{DC} \cdot \frac{CE}{EA} \cdot \frac{AF}{FB} = \frac{2}{1} \cdot \frac{1}{1} \cdot \frac{1}{2} = 1$$

    乘积为 1，由チェバの定理的逆，三线共点。

## 易错点

- [ ] チェバ／メネラウスの比の取る方向を一周で統一する（绕一周方向统一）
- [ ] 外心・垂心の位置は鈍角三角形で外部に出る（钝角时在形外）
