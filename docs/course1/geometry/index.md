# 図形の性質简介（数学A）

平面图形的性质（三角形的五心、圆的定理群）与空间图形的基础。定义多、定理多，靠图记最牢。

本项目的具体内容都在下面的细目页中（左侧导航点开「7. 図形の性質」即可逐层展开）。

## 在 EJU 中的位置

定理与定义的记忆型项目，在 Course 1 中多以小题或大题的局部结论出现，单独成大题的比重不高，但五心・円の定理群是图形证明的词汇表，没记住就无从下笔。题型气质偏图形观察与定理调用；空間図形（直線と平面）部分为 Course 2 的空間ベクトル打底。与図形と計量互为表里：本项目给性质与判定，那个项目给長さ・面積の計量，两者常在同一道几何题里接力。
