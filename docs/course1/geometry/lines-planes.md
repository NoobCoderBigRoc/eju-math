# 直線と平面

## 空間での位置関係

空間では「交わらないのに平行でもない」関係が現れるのが平面との最大の違い。

| 組み合わせ | 位置関係 |
| --- | --- |
| 直線と直線 | 平行 / 交わる / **ねじれの位置** |
| 直線と平面 | 平行（交わらない） / 交わる / 平面に含まれる |
| 平面と平面 | 平行 / 交わる（交線は直線） |

- 位置关系：平行・交わる・ねじれの位置（异面直线，既不平行也不相交）。
- **ねじれの位置**：同一平面上にない 2 直線。空間でのみ現れる関係で、2 直線を含む平面が存在しないことと同値。

## 平行と垂直の判定

- 平行/垂直的判定：直线与平面平行 ⇔ 与平面内一条直线平行；直线与平面垂直 ⇔ 与平面内两条相交直线垂直。

正確に述べると、判定には次の条件が要る。

- **直線と平面の平行**：平面外の直線が、平面内の 1 本の直線と平行なら、その直線は平面と平行。
- **直線と平面の垂直**：直線が、平面内の**交わる 2 直線**の両方と垂直なら、その直線は平面と垂直。2 直線が平行なだけでは不十分（その 2 直線と垂直でも、平面内の他の方向とは限らないため）。

## 直線と平面のなす角・二面角

- **直線と平面のなす角**：直線を平面に射影した直線（正射影）と、元の直線とのなす角。直線が平面と垂直なときは $90^\circ$。
- 二面角：取交线上一点向两个半平面作垂线，两垂线的夹角。手順としては、2 平面の交線上の 1 点から、各平面内で交線に垂線を引く。その 2 本の垂線のなす角が二面角で、交線上のどこに点を取っても大きさは変わらない。

## 三垂線の定理

平面外の点から引いた垂線・斜線について成り立つ、空間図形の計量で最頻出の定理。

平面 $\alpha$ 上にない点 $A$ から $\alpha$ に垂線 $AH$（$H$ は足）を下ろし、$\alpha$ 上の直線 $l$ に $H$ から垂線 $HB$（$B$ は $l$ 上の点）を引く。このとき $AB \perp l$ となる。逆も成り立つ（$AB \perp l$ なら $HB \perp l$）。

使いどころ：立体の中で「ある辺とある辺が垂直」であることを示したり、点と直線の距離を平面の問題に落としたりするとき。項目 4 の [図形の計量](../measure/measurement.md) の空間応用はこの定理が土台になる。

## ねじれの位置の 2 直線のなす角

一方の直線を平行移動して他方と交わるようにし、そのなす角（$0^\circ$ から $90^\circ$ の範囲）で定義する。平行移動しても角の大きさは変わらない。

## 易错点

- [ ] ねじれの位置の直線のなす角は、平行移動して測る（异面直线所成角要平移后量）
- [ ] 直線と平面の垂直判定で「平面内の平行な 2 直線」に垂直と言う（交わる 2 直線でなければならない）
- [ ] 二面角を取る垂線を交線以外の辺から引く（2 本とも交線に垂直でなければならない）
