# 集合と命題简介（数学I）

集合是全数学的通用语言，命题与条件是逻辑证明的基础。本项目多以小题形式出现，注意与場合の数・確率共用的计数语言。

本项目的具体内容都在下面的细目页中（左侧导航点开「2. 集合と命題」即可逐层展开）。

## 在 EJU 中的位置

在 Course 1 中分量偏轻，多以小题、概念判定题的形式出现，但「集合的语言」渗透全卷：要素の個数与場合の数・確率共用同一套计数语言，必要条件・十分条件与対偶则是各项目证明题的通用工具。题型气质偏逻辑与概念判定，计算量小，失分多在方向与否定这类细节上。前置承接数と式，后续直接服务場合の数と確率（事象的运算）。
