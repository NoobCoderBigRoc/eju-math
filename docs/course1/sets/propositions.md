# 命題と条件

- 命题 $p \Rightarrow q$ 为真时：$q$ 是 $p$ 的**必要条件**，$p$ 是 $q$ 的**十分条件**（充分条件）；两者互为充要条件（必要十分条件）当且仅当 $p \iff q$。
- 逆・裏・対偶：命题与其**逆否命题（対偶）同真假**——证明困难时改证对偶是常用手段。
- 「すべての $x$」「ある $x$」的否定要互换：$\forall$ 的否定是 $\exists$（反例），反之亦然。

## 反証法

要证命题为真，先假设结论不成立（命題の否定を仮定），推出矛盾。常用于「无理数である」「無限にある」等否定形结论的证明。

??? example "演習：必要条件・十分条件"
    **问题**

    $x = 2$ は $x^2 = 4$ であるための何条件か。

    **答案**

    十分条件であるが必要条件ではない

    **思路**

    $x = 2 \Rightarrow x^2 = 4$ 成立，所以是充分条件；反之 $x^2 = 4$ 时 $x = -2$ 也可以，不必 $x = 2$，所以不是必要条件。

    **解答**

    $p \Rightarrow q$ 真、$q \Rightarrow p$ 伪，故 $p$ 是 $q$ 的充分非必要条件。

## 易错点

- [ ] 必要条件与十分条件的方向读反（记：箭头出发的一侧是十分、到达的一侧是必要）
- [ ] 否定时「すべての⇄ある（存在）」要互换，谓语也要否定
- [ ] 「対偶は真」を使うとき、元の命題の対偶を正しく書けているか（用对偶时先确认对偶写对了）
