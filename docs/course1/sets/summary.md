# 集合と命題要点总结

本项目题量不大但概念判定密集：考前要确认集合运算和元素个数的公式、必要条件与充分条件的判定方向、命題的否定与対偶的写法不出错。

## 公式・定理清单

### 集合

- $a \in A$（$a$ 是 $A$ 的要素）、$A \subset B$（部分集合）、$A \cap B$（共通部分、「かつ」）、$A \cup B$（和集合、「または」）、$\overline{A}$（補集合）、$\varnothing$（空集合）—— 先把记号与读法对齐
- ド・モルガンの法則（和集合の補集合）：$\overline{A \cup B} = \overline{A} \cap \overline{B}$ —— 取补集时 $\cup$ 变成 $\cap$
- ド・モルガンの法則（共通部分の補集合）：$\overline{A \cap B} = \overline{A} \cup \overline{B}$ —— 取补集时 $\cap$ 变成 $\cup$
- 要素の個数：$n(A \cup B) = n(A) + n(B) - n(A \cap B)$ —— 重叠部分被数两次，要减掉一次
- 3 つの集合：$n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C)$ —— 用ベン図（文氏图）整理最稳妥

### 命題と条件

- $p \Rightarrow q$ 为真时：$p$ 是 $q$ 的**十分条件**、$q$ 是 $p$ 的**必要条件** —— 箭头出发的一侧是充分、到达的一侧是必要
- 必要十分条件（充要条件）：$p \iff q$ —— 两个方向的箭头都真
- 逆・裏・対偶：命題与它的対偶真伪一致（逆与裏之间也一致）—— 原命题难证时改证対偶
- 対偶的写法：$p \Rightarrow q$ 的対偶是 $\overline{q} \Rightarrow \overline{p}$ —— 把假设与结论交换位置，并把两者都否定（写错整个证明就崩了）
- 否定的写法：「すべての $x$」的否定是「ある $x$（〜でない）」、「ある $x$」的否定是「すべての $x$（〜でない）」—— 量词互换且谓语也要否定
- 反証法：假设结论的否定并推出矛盾 —— 是证明「無理数である」「無限にある」这类否定形结论的手段

## 解法パターン

- **画ベン図计数**：两个（三个）集合的人数・个数问题 → 画ベン図从交集往外填，或直接套要素の個数的公式
- **「两者都不」用補集合**：问两者都不属于的有多少 → 先求 $n(A \cup B)$，再从全体中减去
- **「〜でない」改写成補集合**：条件里带否定表达时 → 先改写成 $\overline{A}$，再处理元素个数与真伪，思路更清楚
- **判定条件查双向**：判必要・十分 → $p \Rightarrow q$ 与 $q \Rightarrow p$ 分别验；否掉一个方向只需举一个反例
- **切换到対偶**：直接证明别扭的命題 → 写出対偶并证明，真伪与原命题一致
- **写否定文的两步**：先交换「すべての ⇄ ある」，再否定谓语，两步缺一不可

## 考前注意

- [ ] 求 $n(A \cup B)$ 时忘记减去 $n(A \cap B)$
- [ ] 读错「または」与「かつ」对应的 $\cup$、$\cap$
- [ ] 把必要条件与十分条件的方向搞反（按箭头方向记）
- [ ] 写否定时只换量词、忘记否定谓语（或反过来）
- [ ] 用対偶时，把原命題的対偶本身写错
