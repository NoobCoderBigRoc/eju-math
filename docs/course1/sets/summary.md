# 集合と命題要点总结

本项目题量不大但概念判定密集：考前要确认集合の演算と要素の個数の公式、必要条件・十分条件の方向、命題の否定と対偶の書き方不出错。

## 公式・定理清单

### 集合

- $a \in A$（要素である）、$A \subset B$（部分集合）、$A \cap B$（共通部分、「かつ」）、$A \cup B$（和集合、「または」）、$\overline{A}$（補集合）、$\varnothing$（空集合）—— 记号与读法先对齐
- ド・モルガンの法則（和集合の補集合）：$\overline{A \cup B} = \overline{A} \cap \overline{B}$ —— 取补集时 $\cup$ が $\cap$ に変わる
- ド・モルガンの法則（共通部分の補集合）：$\overline{A \cap B} = \overline{A} \cup \overline{B}$ —— 取补集时 $\cap$ が $\cup$ に変わる
- 要素の個数：$n(A \cup B) = n(A) + n(B) - n(A \cap B)$ —— 重叠部分被数两次，要减掉一次
- 3 つの集合：$n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C)$ —— 用ベン図（文氏图）整理最稳妥

### 命題と条件

- $p \Rightarrow q$ が真のとき：$p$ は $q$ の**十分条件**、$q$ は $p$ の**必要条件** —— 箭头出发的一侧是十分、到达的一侧是必要
- 必要十分条件（充要条件）：$p \iff q$ —— 两个方向的箭头都真
- 逆・裏・対偶：命題とその対偶は真偽が一致する（逆と裏どうしも一致）—— 原命题难证时改证対偶
- 対偶の作り方：$p \Rightarrow q$ の対偶は $\overline{q} \Rightarrow \overline{p}$ —— 仮定と結論を入れ替え、両方を否定する（書き間違えると証明が崩れる）
- 否定の作り方：「すべての $x$」の否定は「ある $x$（〜でない）」、「ある $x$」の否定は「すべての $x$（〜でない）」—— 量词互换且谓语也要否定
- 反証法：結論の否定を仮定し、矛盾を導く —— 「無理数である」「無限にある」等否定形结论的证明手段

## 解法パターン

- **ベン図で数える**：两个（三个）集合的人数・个数の問題 → 画ベン図从交集往外填，或直接套要素の個数の公式
- **「どちらでもない」は補集合**：问两者都不属于的有多少 → 先求 $n(A \cup B)$，再用全体から引く
- **「〜でない」は補集合に言い換える**：否定表現が絡む条件 → $\overline{A}$ に直してから要素の個数や真偽を処理すると見通しがよくなる
- **条件の判定は両方向**：判必要・十分 → $p \Rightarrow q$ 与 $q \Rightarrow p$ 分别验；否掉一个方向只需举一个反例
- **対偶に切り替える**：直接证明别扭的命題 → 写出対偶并证明，真伪与原命题一致
- **否定文の 2 手順**：「すべての ⇄ ある」を入れ替える → 谓语を否定する，两步缺一不可

## 考前注意

- [ ] $n(A \cup B)$ で $n(A \cap B)$ を引き忘れる
- [ ] 「または＝$\cup$、かつ＝$\cap$」を読み違える
- [ ] 必要条件と十分条件の方向を取り違える（箭头の向きで覚える）
- [ ] 否定を作るとき量詞だけ換えて述語の否定を忘れる（またはその逆）
- [ ] 対偶を使うとき、元の命題の対偶そのものを書き間違える
