# 2次関数のグラフと2次不等式

## 基本の読み方

先看开口方向与交点：$ax^2 + bx + c > 0$（$a > 0$、两根 $\alpha < \beta$）的解为 $x < \alpha$ 或 $x > \beta$；$< 0$ 的解为 $\alpha < x < \beta$。「图像在 $x$ 轴上方/下方」直接读区间最稳妥。

解く手順は常に同じ：①左辺を 0 とした方程式の解（$x$ 軸との交点）を求める → ②簡易グラフを描く → ③不等号の向きに合う $x$ の範囲（軸より上か下か）を読む。

## 判別式による場合分け（$a > 0$）

| $D$ | グラフと $x$ 軸 | $ax^2 + bx + c > 0$ の解 | $ax^2 + bx + c < 0$ の解 |
| --- | --- | --- | --- |
| $D > 0$（交点 $\alpha < \beta$） | 2 点で交わる | $x < \alpha$、$x > \beta$ | $\alpha < x < \beta$ |
| $D = 0$（接する、頂点 $\alpha$） | 1 点で接する | $x = \alpha$ を除くすべての実数 | 解なし |
| $D < 0$ | 交わらない（常に上） | すべての実数 | 解なし |

- 「すべての実数」と「解なし」が答えになるのは $D \le 0$ の場合だけ。まず $D$ を確認する習慣をつける。
- $\ge 0$、$\le 0$ の場合は等号の分だけ境界が加わる（$D = 0$ で $\le 0$ なら解は $x = \alpha$ のみ）。

## $a < 0$ の場合

両辺に $-1$ を掛けて $a > 0$ の形に直す（不等号の向きが変わる）か、そのまま「上に凸」のグラフを描いて同じ手順で読む。どちらでもよいが、途中で混ぜないこと。

## 応用への接続

- 連立 2 次不等式：各自を解いて数直線で共通部分をとる（[1 次不等式](../numbers/inequalities.md) と同じ考え方）。
- 「すべての実数 $x$ に対して $ax^2 + bx + c > 0$」型は、$a > 0$ かつ $D < 0$ と翻訳する恒等式的不等式問題につながる（[2次関数のグラフと2次方程式](graph-equation.md) の判別式の応用）。

## 易错点

- [ ] 不等式 $>0$ 与 $<0$ 的区间取反（开口向上先画简图再读）
