# 2次関数の決定

2次関数を決める問題は「条件に合った形を選び、係数を定める」問題。与えられた条件によって、最も計算が楽な形が変わる。

## 3 つの形と使い分け

由顶点式（已知顶点）、一般式（已知 3 点）、交点式 $y = a(x - \alpha)(x - \beta)$（已知与 $x$ 轴交点）三种形式中选最省计算的一种，代入条件定系数。

| 与えられた条件 | 使う形 | 決める係数 |
| --- | --- | --- |
| 頂点 $(p, q)$ が分かる | $y = a(x - p)^2 + q$（頂点形） | $a$ の 1 つだけ |
| 軸と通る 1 点、頂点の $x$ 座標など | $y = a(x - p)^2 + q$（頂点形） | $a$ と $q$ |
| $x$ 軸との交点 $(\alpha, 0)$, $(\beta, 0)$ | $y = a(x - \alpha)(x - \beta)$（因数形） | $a$ の 1 つだけ |
| グラフが通る 3 点 | $y = ax^2 + bx + c$（一般形） | $a, b, c$ の 3 つ（連立方程式） |
| $y$ 軸との交点（切片）が分かる | 一般形で $c$ が即決まる | 残り 2 つ |

## 決定の手順

1. 条件を読み、上の表で形を選ぶ。未知数の個数 = 条件の個数になっているかを確認する（2次関数の決定には原則 3 つの条件が必要だが、頂点や交点の形を使うと条件が形に組み込まれ、未知数が減る）。
2. 残りの点の座標を代入し、$a$（や他の係数）についての方程式を解く。
3. 求めた式を展開して一般形に直し、与えられた点をすべて通るか検算する。

## 条件の読み替え

- 「頂点が直線 $y = \cdots$ 上にある」「軸が $x = 2$」など、頂点・軸の条件は頂点形の $p, q$ に直接翻訳できる。
- 最大値・最小値の条件（例：$x = 1$ で最大値 5）は「頂点が $(1, 5)$」と同じ情報。
- $x$ 軸と接する $\iff$ 頂点の $y$ 座標が 0 $\iff$ 判別式 $D = 0$（[2次関数のグラフと2次方程式](graph-equation.md)）。

## 易错点

- [ ] 条件に合わない形を選んで未知数を増やしてしまう（頂点が分かっているのに一般形で 3 元連立にする）
- [ ] 頂点形の符号を取り違える（頂点 $(p, q)$ に対して $y = a(x - p)^2 + q$、$x + p$ ではない）
- [ ] 求めたあと検算しない（与えられた 3 点をすべて代入して確認する）
