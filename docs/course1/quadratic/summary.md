# 2次関数要点总结

Course 1 的出题大户：考前要确认平方完成、頂点・最值、判別式三件套能互相翻译，含参题的分情况（場合分け）临界点找得准。

## 公式・定理清单

### 2次関数とグラフ

- 平方完成：$y = a(x - p)^2 + q$、頂点 $(p, q)$、軸 $x = p$ —— 顶点式是读图的第一步
- 頂点の公式：$\left(-\dfrac{b}{2a},\ \dfrac{4ac - b^2}{4a}\right)$ —— 不配方时直接套用，轴是 $x = -\dfrac{b}{2a}$
- $a > 0$ 时为下に凸（开口向上），$a < 0$ 时为上に凸（开口向下）—— 开口方向只由 $a$ 的符号决定（凸向按日语说法记，不要按中文直觉读反）
- 2次関数の決定の 3 つの形：頂点形 $y = a(x - p)^2 + q$／因数形 $y = a(x - \alpha)(x - \beta)$／一般形 $y = ax^2 + bx + c$ —— 按已知条件选未知数最少的形

### 2次方程式と2次不等式

- 解の公式：$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ —— 分子整体除以 $2a$，不要只除根号部分
- 简便公式（$b = 2b'$ 时）：$x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$ —— $b$ 为偶数时使用，减少计算量与错误
- 判別式 $D = b^2 - 4ac$：$D > 0$ 有两个不同的实数解，$D = 0$ 为重解，$D < 0$ 无实数解 —— 与图像和 $x$ 轴的交点个数一致
- 解と係数の関係：$\alpha + \beta = -\dfrac{b}{a}$、$\alpha\beta = \dfrac{c}{a}$ —— 不解方程、只用两根的和与积时使用
- 2次不等式的解（$a > 0$，两根 $\alpha < \beta$）：$ax^2 + bx + c > 0$ 的解是 $x < \alpha$ 或 $x > \beta$，$< 0$ 的解是 $\alpha < x < \beta$ —— 先画简图再读区间
- $D \le 0$ 时的不等式：$> 0$ 的解是全体实数（$D = 0$ 时除去顶点）或无解，$< 0$ 的解是无解或只有顶点一处 —— 不要硬套成区间的形式作答
- 恒成立的翻译：对所有实数 $x$ 都有 $ax^2 + bx + c > 0$ $\iff$ $a > 0$ 且 $D < 0$ —— 把文字条件转化为 $a$ 的符号与 $D$ 的条件

## 解法パターン

- **区间最值三点比较**：给定区间求最大值/最小值 → 比较顶点值与区间两端点值
- **轴含参时分情况**：轴或区间含有字母 → 按顶点在区间内还是区间外分情况，临界点取顶点与端点重合的位置
- **按条件选形式（決定）**：给定顶点（最大值・最小值条件同理）用頂点形，给定与 $x$ 轴的交点用因数形，给定任意 3 点用一般形 → 让未知数的个数与条件的个数相匹配
- **重解・相切即 $D = 0$**：题面出现「重解」「$x$ 軸と接する」「解が 1 つ」→ 立刻列出 $D = 0$ 的方程
- **解方程先试因数分解**：解二次方程 → 先试因数分解（积与和的组合・たすき掛け），不行再用解の公式；只问解的个数时只查 $D$ 即可
- **解不等式步骤固定**：先求左式 $= 0$ 的解 → 画简图 → 按不等号的方向读出范围

## 考前注意

- [ ] 平方完成时没先把 $a$ 括出来就配方，算错常数项
- [ ] 「実数解をもたない」是 $D < 0$、「重解」是 $D = 0$——把日语表述与 $D$ 符号的对应关系弄反
- [ ] $x^2 = 3x$ 两边直接除以 $x$，丢掉解 $x = 0$（应移项后因数分解）
- [ ] $a < 0$ 的不等式两边乘 $-1$ 后让不等号保持原样
- [ ] 含参最值题分情况时取错临界点（顶点与端点重合的位置）
