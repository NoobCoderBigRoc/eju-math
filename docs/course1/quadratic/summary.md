# 2次関数要点总结

Course 1 的出题大户：考前要确认平方完成、頂点・最值、判別式三件套能互相翻译，含参题的分情况（場合分け）临界点找得准。

## 公式・定理清单

### 2次関数とグラフ

- 平方完成：$y = a(x - p)^2 + q$、頂点 $(p, q)$、軸 $x = p$ —— 顶点式是读图的第一步
- 頂点の公式：$\left(-\dfrac{b}{2a},\ \dfrac{4ac - b^2}{4a}\right)$ —— 不配方时直接套，軸は $x = -\dfrac{b}{2a}$
- $a > 0$ のとき下に凸、$a < 0$ のとき上に凸 —— 开口方向只由 $a$ 的符号定（按日语说法记忆，勿按中文直觉读反）
- 2次関数の決定の 3 つの形：頂点形 $y = a(x - p)^2 + q$／因数形 $y = a(x - \alpha)(x - \beta)$／一般形 $y = ax^2 + bx + c$ —— 按已知条件选未知数最少的形

### 2次方程式と2次不等式

- 解の公式：$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ —— $-b \pm \sqrt{D}$ 全体を $2a$ で割る
- $b = 2b'$ のときの簡便形：$x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$ —— $b$ 为偶数时用，减少计算量与ミス
- 判別式 $D = b^2 - 4ac$：$D > 0$ 異なる 2 つの実数解、$D = 0$ 重解、$D < 0$ 実数解なし —— 与 $x$ 軸の交点の個数と一致する
- 解と係数の関係：$\alpha + \beta = -\dfrac{b}{a}$、$\alpha\beta = \dfrac{c}{a}$ —— 不解方程、只用两根的和与积时使用
- 2次不等式の解（$a > 0$、根 $\alpha < \beta$）：$ax^2 + bx + c > 0$ は $x < \alpha$ または $x > \beta$、$< 0$ は $\alpha < x < \beta$ —— 先画简图再读区间
- $D \le 0$ のときの不等式：$> 0$ はすべての実数（$D = 0$ では頂点を除く）か解なし、$< 0$ は解なしか頂点のみ —— 无理に区間の形で答えない
- 恒成立の翻訳：すべての実数 $x$ に対して $ax^2 + bx + c > 0$ $\iff$ $a > 0$ かつ $D < 0$ —— 文字条件を $a$ の符号と $D$ に直す

## 解法パターン

- **区間の最値は 3 点比較**：给定区间求最大・最小 → 比较頂点の値と区間の両端点の値
- **軸が動く場合分け**：軸や区間が文字を含む → 按頂点が区間内か外かで分情况，临界点取頂点と端点が一致する位置
- **条件で形を選ぶ（決定）**：給頂点（最大値・最小値の条件も同じ）用頂点形、給 $x$ 軸との交点用因数形、給任意の 3 点用一般形 → 未知数の個数を条件の個数に合わせる
- **重解・接するは $D = 0$**：题面出现「重解」「$x$ 軸と接する」「解が 1 つ」→ 立刻立てる $D = 0$ の方程式
- **方程式は因数分解を先に試す**：解 2次方程式 → 先试因数分解（積と和の組・たすき掛け），不行再套解の公式；解の個数だけなら $D$ のみ調べる
- **不等式は手順固定**：左辺 $= 0$ の解を求める → 簡易グラフを描く → 不等号の向きに合う範囲を読む

## 考前注意

- [ ] 平方完成で $a$ をくくり出す前に配方して常数项を間違える
- [ ] 「実数解をもたない」は $D < 0$、「重解」は $D = 0$——日语表述と $D$ の符号の対応を取り違える
- [ ] $x^2 = 3x$ を $x$ で割って解 $x = 0$ を落とす（移項して因数分解する）
- [ ] $a < 0$ の不等式で $-1$ を掛けたのに不等号をそのままにする
- [ ] 含参最值题の分情况で臨界点（頂点＝端点の位置）を取り違える
