# 2次方程式の解

## 解き方の判断順序

优先因数分解，其次求根公式：$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$。$b$ 为偶数时可用简便式 $x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$（$b = 2b'$）。

实际解题时按以下顺序判断，能省则省：

1. **共通因数・移項の整理**：まず $ax^2 + bx + c = 0$ の形（右辺 0）に直す。両辺に共通因数があれば割る。
2. **因数分解できるか**：積が $c$（正確には $ac$）・和が $b$ になる数の組、またはたすき掛けを試す。できれば $(x - \alpha)(x - \beta) = 0$ から解は $\alpha, \beta$ と即断できる。
3. **平方の形に直せるか**：$(x + p)^2 = q$ の形（$x^2 - 6x + 9 = 0$ のような完全平方式）は平方根をとって解く。
4. **解の公式**：以上で無理なら公式。因数分解が速く思いつかないときも、迷わず公式に切り替えるのが結果的に速い。

## 解の公式とその出どころ

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

公式は [平方完成](graph-basics.md) を $ax^2 + bx + c = 0$ に適用した結果。根号の中身 $b^2 - 4ac$ が判別式 $D$ で、解の種類（異なる 2 つの実数解 / 重解 / 実数解なし）は $D$ の符号で決まる。解の個数だけを聞かれたら、解かずに [2次関数のグラフと2次方程式](graph-equation.md) で $D$ を調べる。

$b = 2b'$（$b$ が偶数）のときの簡便形 $x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$ は、公式に代入して約分した形で、計算ミスが減る。

## 解と係数の関係（入口）

2 つの解 $\alpha, \beta$ について $\alpha + \beta = -\dfrac{b}{a}$、$\alpha\beta = \dfrac{c}{a}$。因数分解形 $a(x - \alpha)(x - \beta)$ を展開して係数を比べると出てくる関係で、解を実際に求めずに和・積だけを使う問題で使う。詳しい扱いは項目 8 の [解と係数の関係](../../course2/polynomials/vieta.md)。

## 易错点

- [ ] 右辺を 0 にせず因数分解しようとする（$x^2 - 5x = 6$ のままでは分解の形にならない）
- [ ] $x$ で割って解を 1 つ落とす（$x^2 = 3x$ を $x$ で割ると $x = 0$ の解が消える；移項して因数分解する）
- [ ] 解の公式で分母 $2a$ を $\pm$ の後ろだけに付ける（$-b \pm \sqrt{D}$ 全体を $2a$ で割る）
