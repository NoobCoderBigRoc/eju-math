# 2次関数のグラフと2次方程式

判別式 $D = b^2 - 4ac$：$D > 0$ 两个不同实根；$D = 0$ 重根（重解）；$D < 0$ 无实根。与 $x$ 轴交点个数与之一一对应。

**演習：判別式**

$x^2 + kx + 4 = 0$ が重解をもつような定数 $k$ の値を求めよ。

??? example "思路・解答"
    **答案**

    $k = \pm 4$

    **思路**

    重解 ⇔ $D = 0$。

    **解答**

    $$D = k^2 - 16 = 0 \quad\Longrightarrow\quad k = \pm 4$$

## 易错点

- [ ] 把日语条件表述与 $D$ 的符号对应错（「実数解をもたない」是 $D < 0$、「解が 1 つ（重解）」是 $D = 0$）
- [ ] 恒成立问题（「すべての実数 $x$ に対して成り立つ」）要翻译成 $a$ 的符号 + $D$ 的条件
