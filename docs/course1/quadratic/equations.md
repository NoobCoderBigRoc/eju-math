# 2次方程式と2次不等式

## 1. 2次方程式の解

优先因数分解，其次求根公式：$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$。$b$ 为偶数时可用简便式 $x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$（$b = 2b'$）。

## 2. グラフと2次方程式：判別式

判別式 $D = b^2 - 4ac$：$D > 0$ 两个不同实根；$D = 0$ 重根（重解）；$D < 0$ 无实根。与 $x$ 轴交点个数与之一一对应。

## 3. グラフと2次不等式

先看开口方向与交点：$ax^2 + bx + c > 0$（$a > 0$、两根 $\alpha < \beta$）的解为 $x < \alpha$ 或 $x > \beta$；$< 0$ 的解为 $\alpha < x < \beta$。「图像在 $x$ 轴上方/下方」直接读区间最稳妥。

??? example "演習：判別式"
    **问题**

    $x^2 + kx + 4 = 0$ が重解をもつような定数 $k$ の値を求めよ。

    **答案**

    $k = \pm 4$

    **思路**

    重解 ⇔ $D = 0$。

    **解答**

    $$D = k^2 - 16 = 0 \quad\Longrightarrow\quad k = \pm 4$$

## 易错点

- [ ] 把日语条件表述与 $D$ 的符号对应错（「実数解をもたない」是 $D < 0$、「解が 1 つ（重解）」是 $D = 0$）
- [ ] 不等式 $>0$ 与 $<0$ 的区间取反（开口向上先画简图再读）
- [ ] 恒成立问题（「すべての実数 $x$ に対して成り立つ」）要翻译成 $a$ 的符号 + $D$ 的条件
