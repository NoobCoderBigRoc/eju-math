# 2次関数简介（数学I）

Course 1 题量最大的项目之一：图像、顶点与最值、判别式三件事反复组合出题，也是微分法处理极值问题的前身。

本项目的具体内容都在下面的细目页中（左侧导航点开「3. 2次関数」即可逐层展开）。

## 在 EJU 中的位置

Course 1 的核心项目之一，分量属于最重的一档：图像、顶点与最值、判別式三条线反复组合，大题小题都会出现。题型气质以读图与含参讨论为主，場合分け的临界点与书写是主要失分点。与数と式（因数分解・平方完成）紧密联动，并向下衔接 Course 2 的図形と方程式与微分法——极值问题在两个项目里分别用顶点与导数处理，在此分流。
