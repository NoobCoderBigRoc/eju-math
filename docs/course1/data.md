# 数据的统计分析

## 考纲要求

数据的代表值（平均、中位数）、散布度（四分位距、方差、标准差）、两个变量的相关（相关系数、相关表）。EJU 特有的板块，国内教材覆盖较少，**日语术语**需专门记忆。

## 代表值

- 平均值：$\bar{x} = \dfrac{1}{n}\sum x_i$；
- 中位数：排序后位于正中（偶数个取中间两数平均）；
- 最频值（モード）：出现次数最多的值。

## 散布度

**范围（レンジ）**：最大值 − 最小值。

**四分位数**：$Q_1, Q_2, Q_3$，四分位距

$$
IQR = Q_3 - Q_1
$$

**方差**与**标准差**：

$$
s^2 = \frac{1}{n} \sum_{i=1}^{n} (x_i - \bar{x})^2 = \overline{x^2} - \bar{x}^2, \qquad s = \sqrt{s^2}
$$

**变换性质**：$y_i = a x_i + b$ 时

$$
\bar{y} = a\bar{x} + b, \qquad s_y = |a|\, s_x
$$

## 相关

$$
r = \frac{1}{n} \sum_{i=1}^{n} \frac{(x_i-\bar{x})(y_i-\bar{y})}{s_x \, s_y} = \frac{\overline{xy} - \bar x \bar y}{s_x s_y}
$$

$-1 \le r \le 1$；$r > 0$ 正相关，$r < 0$ 负相关，$|r|$ 越大线性关系越强。

## 典型例题

??? example "例题：方差变换"
    数据 $x_1, \dots, x_5$ 的平均为 4、方差为 2。令 $y_i = 3x_i - 1$，求 $y$ 的平均与标准差。

    **解答**：$\bar y = 3 \times 4 - 1 = 11$，标准差 $s_y = 3\sqrt{2}$（方差 $9 \times 2 = 18$）。

## 易错点

- [x] 平移（$+b$）**不改变**标准差，伸缩（$\times a$）**乘 $|a|$**；
- [x] 相关系数只衡量**线性**相关，$r \approx 0$ 不代表无关系；
- [x] 日语术语对照：分散＝方差、標準偏差＝标准差、最頻値＝众数、四分位範囲＝四分位距。
