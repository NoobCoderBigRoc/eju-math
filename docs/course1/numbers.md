## 1. 式の計算

### 展開公式

$$
(a \pm b)^2 = a^2 \pm 2ab + b^2, \qquad (a+b)(a-b) = a^2 - b^2
$$

$$
(a \pm b)^3 = a^3 \pm 3a^2 b + 3ab^2 \pm b^3, \qquad a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)
$$

$$
(a+b+c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ca
$$

### 因数分解

因数分解は「共通因数をくくる → 公式に当てはめる → たすき掛け・置き換え」の順に試すのが基本である。

$$
x^2 + (a+b)x + ab = (x+a)(x+b)
$$

$$
acx^2 + (ad+bc)x + bd = (ax+b)(cx+d) \qquad \text{（たすき掛け）}
$$

複雑な式では、**ある 1 つの文字について整理する**（次数の低い文字について整理すると因数分解しやすくなることが多い）。

## 2. 実数

### 実数の分類

- **有理数**：整数、有限小数、循環小数（分数で表せる数）
- **無理数**：$\sqrt{2}$、$\pi$ のように循環しない無限小数（分数で表せない数）

### 絶対値

$$
|a| = \begin{cases} a & (a \geqq 0) \\ -a & (a < 0) \end{cases}, \qquad \sqrt{a^2} = |a|
$$

$\sqrt{a^2} = a$ と書けるのは $a \geqq 0$ のときだけである。

### 根号を含む式の計算

$$
\sqrt{a}\sqrt{b} = \sqrt{ab}, \qquad \frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}} \qquad (a \geqq 0,\ b > 0)
$$

**有理化**：分母の根号をなくす変形。

$$
\frac{1}{\sqrt{a} \pm \sqrt{b}} = \frac{\sqrt{a} \mp \sqrt{b}}{a - b}
$$

**二重根号**：$a > b > 0$ のとき

$$
\sqrt{a+b \pm 2\sqrt{ab}} = \sqrt{a} \pm \sqrt{b} \qquad (\text{複号同順、} a > b)
$$

## 3. 1次不等式と絶対値

不等式の両辺に**負の数を掛けたり割ったりすると、不等号の向きが変わる**。

絶対値を含む方程式・不等式は、$c > 0$ のとき

$$
|x| = c \iff x = \pm c, \qquad |x| < c \iff -c < x < c, \qquad |x| > c \iff x < -c \ \text{または}\ x > c
$$

一般の形 $|A| = B$ や $|A| < B$ は、絶対値の中身の符号で**場合分け**して解き、得られた解が場合分けの条件を満たすか必ず確認する。

## 例題（演習）

!!! note "例題の扱いについて"
    本ページの例題は、真題の出題形式（穴埋め式）に合わせた演習問題である。出典を特定できた真題は、今後「例題（真題）」として出典（年度・回・問題番号）つきで差し替えていく。

??? example "例題 1：たすき掛け"
    $2x^2 + 5x + 3$ を因数分解せよ。

    **考え方**：$2x^2$ を $2x \times x$、定数項 $3$ を $3 \times 1$ と分解し、たすき掛けで $x$ の係数 $5$ になる組合せを探す。

    **解答**：$2x \cdot 1 + x \cdot 3 = 5x$ となるので

    $$
    2x^2 + 5x + 3 = (2x + 3)(x + 1)
    $$

    **答え**：$(2x + 3)(x + 1)$

??? example "例題 2：二重根号と有理化"
    (1) $\sqrt{5 + 2\sqrt{6}}$ を簡単にせよ。(2) $\dfrac{\sqrt{5} + \sqrt{3}}{\sqrt{5} - \sqrt{3}}$ を $a + b\sqrt{15}$ の形で表せ。

    **考え方**：(1) 和が $5$、積が $6$ になる 2 数 $3, 2$ を探す。(2) 分母の共役を分子・分母に掛ける。

    **解答**：

    $$
    \sqrt{5 + 2\sqrt{6}} = \sqrt{3} + \sqrt{2}, \qquad
    \frac{\sqrt{5} + \sqrt{3}}{\sqrt{5} - \sqrt{3}} = \frac{(\sqrt{5} + \sqrt{3})^2}{5 - 3} = \frac{8 + 2\sqrt{15}}{2} = 4 + \sqrt{15}
    $$

    **答え**：(1) $\sqrt{3} + \sqrt{2}$　(2) $4 + \sqrt{15}$

??? example "例題 3：絶対値を含む方程式"
    $|x - 2| = 2x - 1$ を解け。

    **考え方**：絶対値の中身 $x - 2$ の符号で場合分けし、各場合で得た解がその条件を満たすか確認する。

    **解答**：

    - $x \geqq 2$ のとき：$x - 2 = 2x - 1$ より $x = -1$。これは $x \geqq 2$ を満たさないので不適。
    - $x < 2$ のとき：$-(x - 2) = 2x - 1$ より $x = 1$。これは $x < 2$ を満たし、右辺 $2x - 1 = 1 > 0$ とも矛盾しない。

    **答え**：$x = 1$

## よくあるミス

- [ ] $\sqrt{a^2} = a$ と即断する（正しくは $|a|$。$a < 0$ のとき符号が逆になる）
- [ ] 絶対値の方程式で場合分けした後、**解が場合の条件を満たすか確認しない**（例題 3 の $x = -1$ のような不適解を取り込む）
- [ ] 有理化で共役の符号を間違える（$\sqrt{a} + \sqrt{b}$ の共役は $\sqrt{a} - \sqrt{b}$）
- [ ] 二重根号を外す条件（外側が $+$ のとき大きい方を前に置く）を取り違える
- [ ] 不等式の両辺に負の数を掛けて不等号の向きを変え忘れる
