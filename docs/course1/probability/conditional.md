# 条件付き確率

- 条件付き確率：$P_A(B) = \dfrac{P(A \cap B)}{P(A)}$。

??? example "演習：条件付き確率"
    **问题**

    1個のサイコロを投げて偶数が出たとき、その目が4以上である確率を求めよ。

    **答案**

    $\dfrac{2}{3}$

    **思路**

    条件是「已经知道是偶数」，样本空间缩小为 $\{2, 4, 6\}$，其中 4 以上的是 $\{4, 6\}$。

    **解答**

    $$P = \frac{n(A \cap B)}{n(A)} = \frac{2}{3}$$

## 易错点

- [ ] 条件付き確率で条件となる事象を分母に置き忘れる（条件概率的分母是条件事件）
