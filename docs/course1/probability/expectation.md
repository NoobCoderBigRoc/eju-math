# 期待値

- 期待値（新考纲新增）：随机变量 $X$ 取值 $x_i$ 的概率为 $p_i$ 时，$E(X) = \sum x_i p_i$。体系化的处理见 [確率分布](../../course2/probability-distribution/variables.md)。

??? example "演習：期待値"
    **问题**

    1個のサイコロを投げるとき、出る目の期待値を求めよ。

    **答案**

    $\dfrac{7}{2}$

    **思路**

    每个点数出现的概率都是 $\dfrac{1}{6}$，求加权平均。

    **解答**

    $$E = \frac{1 + 2 + 3 + 4 + 5 + 6}{6} = \frac{21}{6} = \frac{7}{2}$$
