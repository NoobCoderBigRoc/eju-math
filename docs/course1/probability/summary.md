# 場合の数と確率要点总结

先数清、再算概率：考前要确认和の法則・積の法則と順列・組合せの使い分け、余事象を使うタイミング，以及反復試行の公式の構造。

## 公式・定理清单

### 場合の数

- 和の法則：同時に起こらない（排反な）分類は起こり方を足す —— キーワードは「または」、分類が重ならないことが前提
- 積の法則：続けて起こる手順は起こり方を掛ける —— キーワードは「かつ」「続けて」；数え上げの図は樹形図
- 順列：${}_n\mathrm{P}_r = \dfrac{n!}{(n - r)!}$ —— 交換すると結果が変わる（順序を考える）ときに使う
- 組合せ：${}_n\mathrm{C}_r = \dfrac{n!}{r!(n - r)!}$、${}_n\mathrm{C}_r = {}_n\mathrm{C}_{n-r}$ —— 順序を考えない；$r$ が大きいときは対称性で計算を減らす
- 円順列 $(n - 1)!$、同じものを含む順列 $\dfrac{n!}{p!\,q!\cdots}$、重複組合せ ${}_n\mathrm{H}_r = {}_{n+r-1}\mathrm{C}_r$ —— 特殊な並べ方・選び方の定式

### 確率

- 確率の定義：各根元事象が同様に確からしいとき $P(A) = \dfrac{n(A)}{n(U)}$ —— $0 \le P(A) \le 1$、$P(U) = 1$、$P(\varnothing) = 0$
- 余事象の確率：$P(\overline{A}) = 1 - P(A)$ —— 「少なくとも 1 回・1 つ」型の入り口
- 加法定理：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$；$A$ と $B$ が排反なら $P(A \cup B) = P(A) + P(B)$ —— 重なりの分は 1 回だけ引く
- 独立な試行：$P(A \cap B) = P(A)\,P(B)$ —— 一方の結果が他方に影響しない（戻して取り出す等）ときだけ使える
- 反復試行の確率：同じ試行を $n$ 回繰り返し、確率 $p$ の事象がちょうど $r$ 回起こる確率は ${}_n\mathrm{C}_r\, p^r (1 - p)^{n - r}$ —— 「起こる回の選び方 × 確率の冪」
- 条件付き確率：$P_A(B) = \dfrac{P(A \cap B)}{P(A)}$ —— 分母は条件となる事象、標本空間が条件で絞られたと見る
- 期待値：$X$ が値 $x_i$ を確率 $p_i$ でとるとき $E(X) = \sum x_i p_i$ —— 加重平均であり、項目 13 確率分布の入り口

## 解法パターン

- **順序判定を先にする**：数える前に「2 つを交換したら結果が変わるか」→ 変われば順列 P、変わらなければ組合せ C
- **「少なくとも」は余事象**：「少なくとも 1 回起こる」→ 1 回も起こらない確率を出して $1$ から引く（例：$1 - (1 - p)^n$）
- **隣り合うはひとかたまり、隣り合わないは隙間**：相邻条件 → ひとまとめにして 1 つとして並べる；不相邻条件 → 先に他を並べ、その間・両端の隙間に入れる
- **戻す／戻さないで分ける**：取り出して戻す → 独立として確率不変で掛ける；戻さない → 独立でないので、段階ごとに確率を書き直して掛ける
- **ちょうど $r$ 回は反復試行**：繰り返し試行で回数を指定されたら → ${}_n\mathrm{C}_r p^r (1-p)^{n-r}$，${}_n\mathrm{C}_r$ の付け忘れに注意
- **「〜のとき」は条件付き確率**：条件が与えられた下での確率 → $P_A(B) = \dfrac{P(A \cap B)}{P(A)}$，分母を条件の事象に取り替える

## 考前注意

- [ ] 順列と組合せを取り違える（套公式の前に順序判定をする）
- [ ] 分類が重なっているのに和の法則をそのまま使う（排反な分類に分け直すか、重なりを引く）
- [ ] 排反でない事象に $P(A) + P(B)$ だけを使い、$P(A \cap B)$ を引き忘れる
- [ ] 反復試行の公式で ${}_n\mathrm{C}_r$ を付け忘れる
- [ ] 根元事象の取り方が同様に確からしくないまま分数にする（サイコロ 2 つの「目の和」だけを均等な結果として数える）
