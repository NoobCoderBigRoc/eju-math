# 場合の数と確率要点总结

先数清、再算概率：考前要确认和の法則・積の法則与順列・組合せ如何选用、何时该用余事象，以及反復試行公式的结构。

## 公式・定理清单

### 場合の数

- 和の法則：不能同时发生（互斥）的分类，发生方法数相加 —— 关键词是「または」，前提是分类之间不重叠
- 積の法則：接连发生的步骤，发生方法数相乘 —— 关键词是「かつ」「続けて」；枚举时画樹形図
- 順列：${}_n\mathrm{P}_r = \dfrac{n!}{(n - r)!}$ —— 交换后结果会变（要考虑顺序）时使用
- 組合せ：${}_n\mathrm{C}_r = \dfrac{n!}{r!(n - r)!}$、${}_n\mathrm{C}_r = {}_n\mathrm{C}_{n-r}$ —— 不考虑顺序；$r$ 较大时用对称性减少计算
- 円順列 $(n - 1)!$、同じものを含む順列 $\dfrac{n!}{p!\,q!\cdots}$、重複組合せ ${}_n\mathrm{H}_r = {}_{n+r-1}\mathrm{C}_r$ —— 特殊排列与选法的固定公式

### 確率

- 確率的定义：在各根元事象等可能的前提下 $P(A) = \dfrac{n(A)}{n(U)}$ —— $0 \le P(A) \le 1$、$P(U) = 1$、$P(\varnothing) = 0$
- 余事象の確率：$P(\overline{A}) = 1 - P(A)$ —— 是「至少 1 次・1 个」型题目的入口
- 加法定理：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$；若 $A$ 与 $B$ 互斥（排反）则 $P(A \cup B) = P(A) + P(B)$ —— 重叠部分只减一次
- 独立な試行：$P(A \cap B) = P(A)\,P(B)$ —— 只有当一方的结果不影响另一方时（如放回抽取）才能用
- 反復試行の確率：把同一试验重复 $n$ 次，概率为 $p$ 的事件恰好发生 $r$ 次的概率是 ${}_n\mathrm{C}_r\, p^r (1 - p)^{n - r}$ —— 「选出发生的次数 × 概率的幂」
- 条件付き確率：$P_A(B) = \dfrac{P(A \cap B)}{P(A)}$ —— 分母是作为条件的事件，把样本空间看作被条件缩小后的空间
- 期待値：当 $X$ 以概率 $p_i$ 取值 $x_i$ 时 $E(X) = \sum x_i p_i$ —— 它是加权平均，也是项目 13 確率分布的入口

## 解法パターン

- **先做顺序判定**：计数之前先问「交换两个元素，结果会不会变」→ 会变用順列 P，不变用組合せ C
- **「少なくとも」走余事象**：「至少发生 1 次」→ 先求一次都不发生的概率，再用 $1$ 减去它（例：$1 - (1 - p)^n$）
- **相邻捆绑、不相邻插空**：相邻条件 → 把相邻元素捆成一个整体，当作 1 个来排；不相邻条件 → 先排其他元素，再插到它们之间与两端的空隙里
- **按放回与否分开处理**：抽出后放回 → 视为独立，概率不变直接相乘；不放回 → 不独立，每一步都重新写出概率再相乘
- **恰好 $r$ 次用反復試行**：重复试验中指定了发生次数时 → ${}_n\mathrm{C}_r p^r (1-p)^{n-r}$，注意别漏乘 ${}_n\mathrm{C}_r$
- **给定条件用条件付き確率**：在给定条件之下求概率 → $P_A(B) = \dfrac{P(A \cap B)}{P(A)}$，分母换成条件事件

## 考前注意

- [ ] 把順列与組合せ用混（套公式之前先做顺序判定）
- [ ] 分类有重叠却直接用和の法則（要重新分成互斥的分类，或减去重叠部分）
- [ ] 对不互斥的事件只用 $P(A) + P(B)$，忘记减去 $P(A \cap B)$
- [ ] 用反復試行公式时漏乘 ${}_n\mathrm{C}_r$
- [ ] 根元事象的取法并不等可能却直接套分数（例如只把两颗骰子的「点数之和」当作等可能结果来数）
