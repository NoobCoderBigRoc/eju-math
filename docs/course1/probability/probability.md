# 確率

- 基本：$P(A) = \dfrac{n(A)}{n(U)}$（每种结果等可能时）；$P(\overline{A}) = 1 - P(A)$；$P(A \cup B) = P(A) + P(B) - P(A \cap B)$
- 独立な試行：各回结果互不影响，概率相乘。
- 反復試行（重复独立试验）：$n$ 次中恰好 $r$ 次发生的概率 ${}_n\mathrm{C}_r\, p^r (1 - p)^{n - r}$。
- 条件付き確率：$P_A(B) = \dfrac{P(A \cap B)}{P(A)}$。
- 期待値（新考纲新增）：随机变量 $X$ 取值 $x_i$ 的概率为 $p_i$ 时，$E(X) = \sum x_i p_i$。体系化的处理见 [確率分布](../../course2/probability-distribution/index.md)。

??? example "演習：条件付き確率"
    **问题**

    1個のサイコロを投げて偶数が出たとき、その目が4以上である確率を求めよ。

    **答案**

    $\dfrac{2}{3}$

    **思路**

    条件是「已经知道是偶数」，样本空间缩小为 $\{2, 4, 6\}$，其中 4 以上的是 $\{4, 6\}$。

    **解答**

    $$P = \frac{n(A \cap B)}{n(A)} = \frac{2}{3}$$

??? example "演習：期待値"
    **问题**

    1個のサイコロを投げるとき、出る目の期待値を求めよ。

    **答案**

    $\dfrac{7}{2}$

    **思路**

    每个点数出现的概率都是 $\dfrac{1}{6}$，求加权平均。

    **解答**

    $$E = \frac{1 + 2 + 3 + 4 + 5 + 6}{6} = \frac{21}{6} = \frac{7}{2}$$

## 易错点

- [ ] 「取り出して戻す」（放回）与「戻さない」（不放回）时分母的总数没有切换
- [ ] 反復試行の公式で ${}_n\mathrm{C}_r$ を付け忘れる（重复试验公式漏乘组合数）
- [ ] 条件付き確率で条件となる事象を分母に置き忘れる（条件概率的分母是条件事件）
