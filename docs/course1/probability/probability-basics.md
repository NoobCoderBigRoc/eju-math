# 確率とその基本的な性質

## 事象の用語

試行の結果全体の集合を**標本空間** $U$ といい、その部分集合を**事象**という。

| 用語 | 意味 |
| --- | --- |
| 全事象 $U$ | 必ず起こる事象 |
| 空事象 $\varnothing$ | 決して起こらない事象 |
| 積事象 $A \cap B$ | $A$ と $B$ がともに起こる |
| 和事象 $A \cup B$ | $A$ または $B$ が起こる |
| 排反事象 | $A \cap B = \varnothing$ のとき、同時に起こらない 2 つの事象 |
| 余事象 $\overline{A}$ | $A$ が起こらないという事象 |

## 確率の定義と性質

各根元事象が**同様に確からしい**（等可能）とき：

$$P(A) = \frac{n(A)}{n(U)} = \frac{A\ の場合の数}{全体の場合の数}$$

- 基本：$P(A) = \dfrac{n(A)}{n(U)}$（每种结果等可能时）；$P(\overline{A}) = 1 - P(A)$；$P(A \cup B) = P(A) + P(B) - P(A \cap B)$
- 性質のまとめ：
    - $0 \le P(A) \le 1$、$P(U) = 1$、$P(\varnothing) = 0$
    - **加法定理**：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$（重なっている部分を二重に数えないため 1 回引く）
    - $A$ と $B$ が排反なら $P(A \cup B) = P(A) + P(B)$（引く部分が 0）
    - **余事象の確率**：$P(\overline{A}) = 1 - P(A)$。「少なくとも 1 回」型は余事象（1 回も起こらない）から計算するのが定石。
    - $A \subset B$ なら $P(A) \le P(B)$。

## 数え方の前提

確率の計算は場合の数の数え方と一体。「同様に確からしい」が成り立つように根元事象を取ることが前提で、サイコロ 2 つの場合は目の出方を区別した 36 通りを全体とするのが標準的な取り方。[数え上げの原則](counting-principles.md) の数え上げが土台になる。

## 易错点

- [ ] 排反でない事象に $P(A \cup B) = P(A) + P(B)$ を使い、重なりを引き忘れる
- [ ] 「少なくとも」（至少）を見て直接数えにいく（余事象 $1 - P(\overline{A})$ を先に検討する）
- [ ] 根元事象の取り方が同様に確からしくないまま分数にする（サイコロ 2 つの「目の和」だけを均等な結果として数えるなど）
