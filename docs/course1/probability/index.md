# 場合の数と確率简介（数学A）

计数先行、概率随后：先数清有多少种，再谈发生的可能性。2026 年度新考纲在本项目新增了期待値，它也是項目 13 確率分布的入口。

本项目的具体内容都在下面的细目页中（左侧导航点开「5. 場合の数と確率」即可逐层展开）。

## 在 EJU 中的位置

Course 1 的独立大户之一：場合の数与確率常成套出题，从计数小题到条件付き確率・反復試行的应用题都有分布。题型气质是「先建模计数、再算概率」，读题时区分顺序的有无与放回与否是胜负手。前置是集合と命題的要素の個数；2026 年度考纲新增的期待値则把本项目与 Course 2 項目 13 確率分布直接接通。
