# 記数法

$n$ 进制数 $abc_{(n)} = a n^2 + b n + c$。转换：十进制→$n$ 进制用「除以 $n$ 取余倒序」；$n$ 进制→十进制按位权展开。小数部分则反过来：十进制小数乘以 $n$ 取整正序。

**演習：記数法**

10進法の 45 を2進法で表せ。

??? example "思路・解答"
    **答案**

    $101101_{(2)}$

    **思路**

    反复除以 2 记录余数，从最后的余数起倒序读取。

    **解答**

    $$45 = 32 + 8 + 4 + 1 = 101101_{(2)}$$

    （$45 \div 2 = 22 \cdots 1$、$22 \div 2 = 11 \cdots 0$、$11 \div 2 = 5 \cdots 1$、$5 \div 2 = 2 \cdots 1$、$2 \div 2 = 1 \cdots 0$、$1 \div 2 = 0 \cdots 1$，余数倒序为 101101。）

## 易错点

- [ ] 余数の読み順（余数读取方向写反：整数部分倒序、小数部分正序）
