# 整数の性質要点总结

整数の整除结构环环相扣：考前要确认素因数分解这把钥匙的用法、互除法と不定方程式のつながり，以及余りによる分類という証明の定石。

## 公式・定理清单

### 約数と倍数

- 割り算の基本式：$a = bq + r$（$0 \le r < |b|$）で商 $q$ と余り $r$ が一通りに決まる —— 余りは負でなく、除数の絶対値未満；$r = 0$ が「$a$ は $b$ の倍数」と同値
- 倍数の判定法：3・9 は各位の数の和、4 は下 2 桁、8 は下 3 桁、5 は一の位が 0 か 5、11 は奇数桁と偶数桁の和の差、6 は「2 の倍数かつ 3 の倍数」—— 大きな数の素因数分解の出発点
- 素数：正の約数が 1 とその数自身の 2 つだけの数；1 は素数でも合成数でもない —— 分類の頻出ポイント
- 素数の判定：$\sqrt{n}$ 以下の素数で試し割りすれば十分（大きい約数には小さい相方が必ずある）
- 素因数分解の一意性：$n = \prod p_i^{a_i}$ の形は順序を除いて 1 通り —— 以下すべての公式の土台
- 約数の個数 $\prod (a_i + 1)$、約数の総和 $\prod (1 + p_i + p_i^2 + \cdots + p_i^{a_i})$ —— 個数は指数に 1 を足すのを忘れない
- 最大公約数 $g$・最小公倍数 $l$：素因数分解から $g$ は共通素因数の小さい指数、$l$ は大きい指数で作る；2 数では $a \times b = g \times l$（3 数以上では成り立たない）

### ユークリッドの互除法・1次不定方程式

- 互除法：$\gcd(a, b) = \gcd(b,\ a \bmod b)$ を余りが 0 になるまで繰り返す —— 余り 0 の直前の除数が最大公約数；大きな数では分解より速い
- 互除法の逆戻り：割り算の式を逆にたどると $ax + by = \gcd(a, b)$ の整数解が得られる —— 不定方程式の解法の入り口
- 1次不定方程式 $ax + by = c$：整数解がある $\iff$ $c$ が $g = \gcd(a, b)$ の倍数 —— まず存在を判定してから解く
- 一般解：特殊解 $(x_0, y_0)$ に対し $x = x_0 + \dfrac{b}{g}t$、$y = y_0 - \dfrac{a}{g}t$（$t$ は整数）—— 2 変数の步长の符号は一正一负

### 記数法

- $n$ 進法の位取り：$abc_{(n)} = a n^2 + b n + c$ —— $n$ 進法から 10 進法へは位の重みで展開する
- 10 進法から $n$ 進法へ：整数部分は「$n$ で割り、余りを逆の順に読む」、小数部分は「$n$ を掛け、整数部分を順に読む」—— 読む向きが正反対

## 解法パターン

- **素因数分解が起点**：約数の個数・最大公約数・最小公倍数を聞かれたら → まず両数を分解し、指数の大小で組み立てる
- **大きな数の gcd は互除法**：数が大きく分解しにくい → 余りで置き換える互除法を回し、最後の割り切れる除数を取る
- **不定方程式の定石**：$ax + by = c$ → $\gcd$ で解の存在を確認 → 互除法の逆戻り（または見当）で特殊解を 1 つ → 一般解を書き、「正の解」等の条件があれば不等式で $t$ の範囲を絞る
- **余りで分類する証明**：「$n^2$ を 3 で割った余りは 0 か 1」のような主張 → $n = mk + r$（$r = 0, 1, \dots, m - 1$）と場合分けして各場合を計算する
- **進法の換算**：基数を換える → 整数部分は割って余りを逆順、小数部分は掛けて整数部分を正順、方向を取り違えない

## 考前注意

- [ ] 負の数の割り算で余りを負のままにする（商を調整して $0 \le r < |b|$ にする）
- [ ] 6 の倍数を「偶数だから」だけで判定する；4 の倍数を一の位だけで見る
- [ ] 約数の個数で指数への $+1$ を忘れる；1 を素数に数える
- [ ] $a \times b = g \times l$ を 3 つ以上の数に使う
- [ ] 不定方程式の一般解で 2 変数の符号を同じ向きに書く（代入して検算する）
