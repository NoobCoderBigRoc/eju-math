# 整数の性質要点总结

整数的整除结构环环相扣：考前要确认素因数分解这把钥匙的用法、互除法与不定方程式之间的联系，以及「按余数分类」这一证明的固定套路。

## 公式・定理清单

### 約数と倍数

- 割り算の基本式：由 $a = bq + r$（$0 \le r < |b|$），商 $q$ 与余数 $r$ 被唯一确定 —— 余数非负且小于除数的绝对值；$r = 0$ 与「$a$ 是 $b$ 的倍数」等价
- 倍数的判定法：3、9 看各位数字之和，4 看末 2 位，8 看末 3 位，5 看个位是 0 或 5，11 看奇数位与偶数位数字和之差，6 是「2 的倍数且是 3 的倍数」—— 是分解大数时的出发点
- 素数：正的約数只有 1 与它本身、共 2 个的数；1 既不是素数也不是合成数 —— 分类的常考点
- 素数的判定：只需用不超过 $\sqrt{n}$ 的素数逐个试除就够了（大約数必然配着一个小約数）
- 素因数分解的唯一性：$n = \prod p_i^{a_i}$ 的形式除顺序外只有一种 —— 是下面所有公式的基础
- 約数的个数 $\prod (a_i + 1)$、約数的总和 $\prod (1 + p_i + p_i^2 + \cdots + p_i^{a_i})$ —— 求个数时别忘给每个指数加 1
- 最大公約数 $g$・最小公倍数 $l$：由素因数分解，$g$ 取公共素因数的较小指数、$l$ 取较大指数；两个数时有 $a \times b = g \times l$（三个以上不成立）

### ユークリッドの互除法・1次不定方程式

- 互除法：$\gcd(a, b) = \gcd(b,\ a \bmod b)$，反复用余数替换直到余数为 0 —— 余数变 0 之前一步的除数就是最大公約数；数大时比分解更快
- 互除法的回代：把除法式子反着往回代，就能得到 $ax + by = \gcd(a, b)$ 的整数解 —— 是解不定方程式的入口
- 1次不定方程式 $ax + by = c$：有整数解 $\iff$ $c$ 是 $g = \gcd(a, b)$ 的倍数 —— 先判定解是否存在再动手解
- 一般解：对一组特解 $(x_0, y_0)$，有 $x = x_0 + \dfrac{b}{g}t$、$y = y_0 - \dfrac{a}{g}t$（$t$ 为整数）—— 两个变量步长的符号一正一负

### 記数法

- $n$ 进制的位值：$abc_{(n)} = a n^2 + b n + c$ —— 从 $n$ 进制换到 10 进制时按位的权展开
- 从 10 进制换到 $n$ 进制：整数部分「除以 $n$ 取余，逆序读」，小数部分「乘以 $n$ 取整，顺序读」—— 读取方向正好相反

## 解法パターン

- **以素因数分解为起点**：问到約数的个数、最大公約数、最小公倍数时 → 先把两个数都分解，再按指数的大小拼出结果
- **大数求 gcd 用互除法**：数太大难以分解时 → 反复用余数替换做互除法，取最后能除尽的那个除数
- **不定方程式的固定套路**：$ax + by = c$ → 先用 $\gcd$ 确认解存在 → 用互除法回代（或试凑）找出一组特解 → 写出一般解，若有「正的解」等条件再用不等式缩小 $t$ 的范围
- **按余数分类的证明**：形如「$n^2$ を 3 で割った余りは 0 か 1」的主张 → 把 $n$ 写成 $n = mk + r$（$r = 0, 1, \dots, m - 1$）按余数分情况，逐个计算
- **进制换算**：换基数时 → 整数部分除基取余、逆序读，小数部分乘基取整、顺序读，不要把方向弄反

## 考前注意

- [ ] 负数除法时把余数留成负数（应调整商，使 $0 \le r < |b|$）
- [ ] 只凭「是偶数」就判定为 6 的倍数；只看个位就判定 4 的倍数
- [ ] 求約数个数时忘记给指数 $+1$；把 1 算作素数
- [ ] 把 $a \times b = g \times l$ 用到三个以上的数上
- [ ] 写不定方程式的一般解时，把两个变量步长的符号写成同号（要代回验算）
