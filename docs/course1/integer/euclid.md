# ユークリッドの互除法

$\gcd(a, b) = \gcd(b, a \bmod b)$，反复用余数替换直到余数为 0。对大数求最大公约数比分解法快得多。

倒着回代（割り算の式を逆にたどる）可以求出 $ax + by = \gcd(a, b)$ 的一组整数解 $(x, y)$——这是一次不定方程式的通用解法入口。

**演習：互除法**

1071 と 462 の最大公約数を互除法で求めよ。

??? example "思路・解答"
    **答案**

    21

    **思路**

    用余数反复替换两个数：$(1071, 462) \to (462, 147) \to (147, 21) \to (21, 0)$。

    **解答**

    $$1071 = 462 \cdot 2 + 147,\quad 462 = 147 \cdot 3 + 21,\quad 147 = 21 \cdot 7$$

    余数变为 0 的前一步的除数即最大公约数：21。
