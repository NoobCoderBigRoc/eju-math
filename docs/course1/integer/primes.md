# 素数と素因数分解

## 素数とは

- **素数**：2 以上の自然数で、正の約数が 1 とその数自身の 2 つだけである数。2, 3, 5, 7, 11, 13, … と続く。
- **合成数**：素数でない 2 以上の自然数（約数が 3 つ以上ある）。
- **1 は素数でも合成数でもない**。这是最常被问到的分类点。

## 素数の判定

$n$ が素数かどうかは、小さい素数で順に割って確かめる。割り切れる数が見つからなければ素数だが、試すのは $\sqrt{n}$ 以下の素数までで十分（$\sqrt{n}$ より大きい約数があれば、対になる $\sqrt{n}$ より小さい約数も必ずあるため）。

小さい範囲ならエラトステネスの篩（筛法）も有効：2 以上の数を並べ、最小の素数の倍数を消していく作業を繰り返すと、残った数が素数になる。

## 素因数分解

- **素因数分解**：自然数を素数の積に分解すること。順序を除いて一通りしかない（素因数分解の一意性）。
- 手順（短除法）：小さい素数で割れるかどうか [倍数の判定法](divisibility.md) で確かめながら割り続け、商が素数になったら止める。結果は指数を使って $n = \prod p_i^{a_i}$ の形に整理する。

## 約数の個数と総和

$n = \prod p_i^{a_i}$ と素因数分解できるとき：

- 約数の**個数**：$\prod (a_i + 1)$
- 約数の**総和**：$\prod (1 + p_i + p_i^2 + \cdots + p_i^{a_i})$

- 素数（质数）与素因数分解：$n = \prod p_i^{a_i}$ 时约数个数 $\prod (a_i + 1)$。个数公式的理由是：每个素因子的指数可以从 0 到 $a_i$ 任选，选法的总数即约数个数；总和公式则是把每个素因子的幂次和相乘展开，恰好每个约数出现一次。

## 易错点

- [ ] 1 を素数に数える（1 は素数でも合成数でもない）
- [ ] 素数判定で試し割りをする範囲を $\sqrt{n}$ より手前で止めてしまう
- [ ] 約数の個数で指数に 1 を足し忘れる（$a_i$ ではなく $a_i + 1$）
