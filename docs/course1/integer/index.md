# 整数の性質简介（数学A）

整数的整除结构：约数与倍数、互除法、一次不定方程、进制，四组内容彼此衔接（不定方程的解法正建立在互除法之上）。

本项目的具体内容都在下面的细目页中（左侧导航点开「6. 整数の性質」即可逐层展开）。

## 在 EJU 中的位置

在 Course 1 中以小题与证明题为主：倍数の判定法・素因数分解是速算型小题，互除法与 1次不定方程式是成套的方法题，余りによる分類は整数证明的定式写法。题型气质偏逻辑与结构，计算量不大，但步骤环环相扣，一步错位后面全错。与数と式（割り算の基本式の読み替え）衔接，并为 Course 2 数列等涉及整数结构的问题、確率での数え上げ提供工具。
