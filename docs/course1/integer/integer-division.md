# 整数の割り算

## 割り算の基本式

整数 $a$ を 0 でない整数 $b$ で割ると、商 $q$ と余り $r$ が**一通りに**決まり、次が成り立つ。

$$a = bq + r \qquad (0 \le r < |b|)$$

- 整数の割り算：$a = bq + r$（$0 \le r < |b|$），余数必须非负且小于除数的绝对值。
- 「余りが負でない」ことがポイント。たとえば $-17$ を $5$ で割るとき、$-17 = 5 \times (-3) - 2$ とは書かず、商を 1 つ下げて $-17 = 5 \times (-4) + 3$ とし、余り $3$（$0 \le 3 < 5$）とする。

## 余りによる分類

余りに着目すると、すべての整数は割る数ごとに分類できる。

- 2 で割った余り：偶数は $2k$、奇数は $2k + 1$（$k$ は整数）と表せる。
- 3 で割った余り：$3k$、$3k + 1$、$3k + 2$ のいずれか。
- 一般に、$m$ で割った余りは $0, 1, \dots, m - 1$ の $m$ 通りで、整数は $mk + r$ の形に分類できる。

この分類は「$n^2$ を 3 で割った余りは 0 か 1」のような証明の定石：余りの場合分けをして各場合を計算する。倍数であることの証明では、[倍数の判定法](divisibility.md) と併せて使う。

## 商と余りの読み取り

- $a$ が $b$ の倍数 $\iff$ 余り $r = 0$（割り切れる）。
- 余りが等しい 2 数は、その差が割る数の倍数になる（$a - a' = b(q - q')$ から分かる）。
- 連続する整数・連続する偶数などを置くとき、$n, n+1, n+2$ や $2k, 2k+2$ のように文字で表す出発点になる。

## 易错点

- [ ] 带负数做除法时余数仍须满足 $0 \le r < |b|$
- [ ] 余りの範囲を $0 \le r \le |b|$ と書く（$r = |b|$ は商にもう 1 入るので不可、等号は右側につかない）
- [ ] 余りで分類するとき、場合の数（割る数 $m$ に対して $m$ 通り）を数え落とす
