# 因数分解

顺序：①提公因式 → ②套公式 → ③十字相乘（たすき掛け）→ ④最低次整理（次数の低い文字について整理）。

??? example "演習：因数分解"
    **问题**

    $x^2 - 5x + 6$ と $2x^2 + 7x + 3$ を因数分解せよ。

    **答案**

    $(x - 2)(x - 3)$；$(2x + 1)(x + 3)$

    **思路**

    前者找「和 $-5$、积 $6$」的数对：$-2, -3$。后者用十字相乘：$2x^2$ 拆 $2x \times x$、常数 $3 = 1 \times 3$，交叉相乘求和 $2x \cdot 3 + x \cdot 1 = 7x$，与一次项一致。

    **解答**

    $$x^2 - 5x + 6 = (x - 2)(x - 3), \qquad 2x^2 + 7x + 3 = (2x + 1)(x + 3)$$

## 易错点

- [ ] 展开时漏掉中间项符号（特に $(a-b)^2$）
- [ ] 因数分解前先看公因式；含参数时按最低次的文字整理
- [ ] たすき掛け后要验算一次项系数
