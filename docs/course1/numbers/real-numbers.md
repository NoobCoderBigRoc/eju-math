# 実数

## 数の分類

実数 = 有理数（整数・分数・有限/循环小数）与无理数（$\sqrt{2}$、$\pi$ 等）的全体。数轴与实数一一对应。

| 分類 | 定義 | 例 |
| --- | --- | --- |
| 自然数 | 正の整数 | $1, 2, 3, \dots$ |
| 整数 | 自然数と 0 と負の整数 | $\dots, -1, 0, 1, \dots$ |
| 有理数 | 整数 $m$ と 0 でない整数 $n$ を使って $\dfrac{m}{n}$ と書ける数 | $\dfrac{2}{3}$、$-1.25$、$0.333\dots$ |
| 無理数 | 分数で書けない実数（循環しない無限小数） | $\sqrt{2}$、$\pi$ |
| 実数 | 有理数と無理数の全体 | 数直線上のすべての点 |

- 小数の形で見ると：有理数は**有限小数**か**循環小数**（无限循环小数）になり、無理数は循環しない無限小数になる。循環節（繰り返し部分）を点や線で示す記法が日本の教科書の標準。
- 循環小数を分数に直す手順：$x = 0.777\dots$ なら $10x - x = 7$ のように、循環節の桁数だけずらした式との引き算で無限部分を消す。一般に、循環節が $k$ 桁なら $10^k$ 倍した式と引き算する。

## 数直線と大小

- 実数は数直線上の点と 1 対 1 に対応する。右にある数ほど大きい。
- 大小比較の基本は「差の符号」：$a > b \iff a - b > 0$。平方根どうしの比較は、両辺を 2 乗して比べる（正の数どうしなら大小は保存される）。

## 絶対値

絶対值：$|a|$ 是数轴上原点到 $a$ 的距离；$|a| = a\ (a \ge 0)$、$|a| = -a\ (a < 0)$。解法见 [1次不等式](inequalities.md)。

基本性質（計算でよく使う）：

- $|a| \ge 0$、$|a| = 0 \iff a = 0$
- $|-a| = |a|$、$|a|^2 = a^2$
- $|ab| = |a||b|$、$\left|\dfrac{a}{b}\right| = \dfrac{|a|}{|b|}$（$b \ne 0$）
- 2 点 $a, b$ の距離は $|a - b|$ と書ける（絶対値は「距離」の言葉で覚えると応用が効く）。

## 易错点

- [ ] 循環小数を無理数に分類する（循環すれば有理数；無理数は循環しない無限小数）
- [ ] $0$ を自然数に含める（日本の高校数学では自然数は正の整数、$0$ を含まない）
- [ ] $|a|$ の場合分けで $a = 0$ の側を取り違える（$a \ge 0$ の側に入れる）
