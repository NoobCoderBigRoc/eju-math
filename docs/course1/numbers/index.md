# 数と式简介（数学I）

一切计算的出发点：式的变形、实数的处理、一次不等式。本项目是 Course 1 与 Course 2 的共同地基，后续所有章节的计算都建立在这里。

本项目的具体内容都在下面的细目页中（左侧导航点开「1. 数と式」即可逐层展开）。

## 在 EJU 中的位置

本项目很少独立成大题，却是 Course 1 全部计算题的地基：展开、因数分解、根号与絶対値的处理速度直接决定后面项目的得分效率。题型气质以纯计算为主，常以小题或大题的第一问出现。与集合と命題（解集的表述）、2次関数（平方完成・解の公式的计算）紧密联动，并向下衔接 Course 2 的いろいろな式，是复习时最先过一遍的项目。
