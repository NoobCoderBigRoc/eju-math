# 1次不等式

一次不等式的解法与一次方程相同，唯一区别：**两边乘（除）负数时不等号反向**。

## 絶対値を含む方程式・不等式

- $|x| = a \iff x = \pm a$（$a > 0$）
- $|x| < a \iff -a < x < a$
- $|x| > a \iff x < -a$ または $x > a$
- 一般情形 $|A| = B$ 等：按 $A \ge 0$、$A < 0$ 分情况去掉绝对值（場合分け）。

??? example "演習：絶対値の方程式"
    **问题**

    $|x - 2| = 3$ を解け。

    **答案**

    $x = 5, -1$

    **思路**

    $|x - 2|$ 表示数轴上到 2 的距离；距离为 3 的点是 $2 \pm 3$。

    **解答**

    $$x - 2 = \pm 3 \quad\Longrightarrow\quad x = 5, \ -1$$

## 易错点

- [ ] 不等式两边乘负数忘记变号
- [ ] 場合分けした後は、各場合の条件と解の共通範囲を必ず確認する（去掉绝对值后要检查解是否落在该情况的范围内）
- [ ] 连立不等式は数直線で共通部分を取る（多个不等式联立时在数轴上取公共部分）
