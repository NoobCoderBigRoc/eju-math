# 実数

## 1. 実数

实数 = 有理数（整数・分数・有限/循环小数）与无理数（$\sqrt{2}$、$\pi$ 等）的全体。数轴与实数一一对应。

绝对值：$|a|$ 是数轴上原点到 $a$ 的距离；$|a| = a\ (a \ge 0)$、$|a| = -a\ (a < 0)$。解法见 [1次不等式](inequalities.md)。

## 2. 根号を含む式の計算

- $\sqrt{a^2} = |a|$；$\sqrt{ab} = \sqrt{a}\sqrt{b}$（$a, b \ge 0$）
- 分母有理化：$\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}$；$\dfrac{1}{\sqrt{a} + \sqrt{b}} = \dfrac{\sqrt{a} - \sqrt{b}}{a - b}$
- 二重根号：$\sqrt{(p + q) + 2\sqrt{pq}} = \sqrt{p} + \sqrt{q}$（$p > q > 0$）

??? example "演習：分母の有理化"
    **问题**

    $\dfrac{1}{\sqrt{3} - 1}$ の分母を有理化せよ。

    **答案**

    $\dfrac{\sqrt{3} + 1}{2}$

    **思路**

    分子分母同乘共轭式 $\sqrt{3} + 1$，分母用平方差化为 $3 - 1 = 2$。

    **解答**

    $$\frac{1}{\sqrt{3} - 1} = \frac{\sqrt{3} + 1}{(\sqrt{3} - 1)(\sqrt{3} + 1)} = \frac{\sqrt{3} + 1}{2}$$

## 易错点

- [ ] $\sqrt{a^2} = a$ 只在 $a \ge 0$ 时成立，一般要写 $|a|$
- [ ] 二重根号要先把根号内的数凑成 $p + q$ 与 $2\sqrt{pq}$ 的形
