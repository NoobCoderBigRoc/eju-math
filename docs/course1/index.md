# 数学コース1（項目 1〜7）

コース1 は現行シラバスの出題項目 **1〜7** のすべてが出題範囲である。項目 1〜7 はコース2 の範囲にも含まれる（コース2 は 1〜20 のすべて）。

| 番号 | 章节 | 核心内容 | 考频 |
| --- | --- | --- | --- |
| 1 | [数と式](numbers.md) | 式の計算、実数、根号、絶対値を含む方程式・不等式 | ★★★ |
| 2 | [集合と命題](sets.md) | 集合の演算、要素の個数、命題と条件（必要・十分） | ★★★ |
| 3 | [2次関数](quadratic.md) | グラフ、判別式、最大・最小、場合分け | ★★★★★ |
| 4 | [図形と計量](measure.md) | 三角比、正弦定理・余弦定理、面積 | ★★★★ |
| 5 | [場合の数と確率](probability.md) | 順列・組合せ、条件付き確率、独立試行、期待値（2026 年度追加） | ★★★★ |
| 6 | [整数の性質](integer.md) | 約数・倍数、素因数分解、ユークリッドの互除法、記数法 | ★★★★ |
| 7 | [図形の性質](geometry.md) | 三角形の五心、円の性質、方べきの定理、空間図形 | ★★★★ |
| 補充 | [データの分析](data.md) | 四分位数、分散・標準偏差、相関係数（項目 13 の基礎） | ★★★ |
