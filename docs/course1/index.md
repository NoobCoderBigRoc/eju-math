# 数学 Course 1（文科数学）

Course 1 覆盖初中衔接内容与基础高中数学，难度低于国内高考，但**覆盖面广、题干为日语**。

| 章节 | 核心内容 | 考频 |
| --- | --- | --- |
| [数与式](numbers.md) | 实数运算、多项式展开因式分解、绝对值、集合与命题 | ★★★ |
| [二次函数](quadratic.md) | 图像、判别式、最大最小、含参问题 | ★★★★★ |
| [图形与计量](measure.md) | 三角比、正弦定理、余弦定理、面积 | ★★★★ |
| [概率](probability.md) | 排列组合、条件概率、独立 | ★★★★ |
| [数据的统计分析](data.md) | 四分位数、方差标准差、相关 | ★★★ |
| [整数的性质](integer.md) | 约数倍数、素因数分解、进制 | ★★★★ |
| [图形的性质](geometry.md) | 五心、圆周角、方幂定理、相似与面积比 | ★★★★ |
