# 三角比と図形

三角形 $ABC$ 中边 $a = BC$、$b = CA$、$c = AB$，外接圆半径 $R$、内切圆半径 $r$。

## 1. 正弦定理・余弦定理

- 正弦定理：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$
- 余弦定理：$a^2 = b^2 + c^2 - 2bc\cos A$（变形 $\cos A = \dfrac{b^2 + c^2 - a^2}{2bc}$）

选用口诀：已知一角及其对边与另一边/角 → 正弦定理；已知两边夹角或三边 → 余弦定理。

## 2. 図形の計量

- 面积：$S = \dfrac{1}{2}bc\sin A = \dfrac{abc}{4R} = \dfrac{r(a + b + c)}{2}$
- 空间图形：先把问题归结到一个平面三角形上（截面、投影），再用上两定理；正四面体、球等常与体积累联考。

??? example "演習：余弦定理"
    **问题**

    $b = 3$、$c = 5$、$A = 60^\circ$ のとき、$a$ を求めよ。

    **答案**

    $a = \sqrt{19}$

    **思路**

    已知两边及其夹角，直接用余弦定理。

    **解答**

    $$a^2 = 3^2 + 5^2 - 2 \cdot 3 \cdot 5 \cos 60^\circ = 9 + 25 - 15 = 19 \quad\Longrightarrow\quad a = \sqrt{19}$$

??? example "演習：正弦定理と外接円"
    **问题**

    $a = 2\sqrt{3}$、$A = 60^\circ$ のとき、外接円の半径 $R$ を求めよ。

    **答案**

    $R = 2$

    **思路**

    由正弦定理 $\dfrac{a}{\sin A} = 2R$。

    **解答**

    $$2R = \frac{2\sqrt{3}}{\sin 60^\circ} = \frac{2\sqrt{3}}{\sqrt{3}/2} = 4 \quad\Longrightarrow\quad R = 2$$

??? example "演習：三角形の面積"
    **问题**

    $b = 4$、$c = 6$、$A = 30^\circ$ のとき、$\triangle ABC$ の面積を求めよ。

    **答案**

    $S = 6$

    **思路**

    两边夹角给定时：面积 $= \dfrac{1}{2} \times$ 两边之积 $\times \sin(\text{夹角})$。

    **解答**

    $$S = \frac{1}{2} \cdot 4 \cdot 6 \cdot \sin 30^\circ = 12 \cdot \frac{1}{2} = 6$$

## 易错点

- [ ] 钝角三角形中 $\cos A$ 由余弦定理求出后别急着取「锐角」的直觉答案
- [ ] 正弦定理求角时可能有两个解（$\sin$ 在 $(0^\circ, 180^\circ)$ 不单调），要检验与已知边大小的相容性
- [ ] 空间图形题先画出关键平面的截面图再算
