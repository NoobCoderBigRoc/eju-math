# 図形と計量要点总结

解三角形的工具箱：考前要确认三角比の定義と符号、正弦定理・余弦定理の使い分け，以及面積公式と空間計量の落とし方。

## 公式・定理清单

### 三角比

- 鋭角の定義（直角三角形）：$\sin\theta = \dfrac{対辺}{斜辺}$、$\cos\theta = \dfrac{底辺}{斜辺}$、$\tan\theta = \dfrac{対辺}{底辺}$ —— 相似な三角形なら辺の比は $\theta$ のみで決まる
- 座標による定義：半円上の点 $(x, y)$（半径 $r$）で $\sin\theta = \dfrac{y}{r}$、$\cos\theta = \dfrac{x}{r}$、$\tan\theta = \dfrac{y}{x}$ —— 钝角靠此定义；$\theta = 90^\circ$ のとき $\tan\theta$ は定義されない
- 補角の関係：$\sin(180^\circ - \theta) = \sin\theta$、$\cos(180^\circ - \theta) = -\cos\theta$、$\tan(180^\circ - \theta) = -\tan\theta$ —— 钝角的值由锐角侧导出，只记锐角侧即可
- $\sin^2\theta + \cos^2\theta = 1$ —— 単位円上の点が $x^2 + y^2 = 1$ を満たすこと（三平方の定理）そのもの
- 変形形：$\sin^2\theta = 1 - \cos^2\theta$、$\cos^2\theta = 1 - \sin^2\theta$ —— 式の変形ではこちらの形で使うことが多い
- 覚えるべき値の出どころ：$30^\circ, 60^\circ, 90^\circ$ の直角三角形（辺の比 $1 : 2 : \sqrt{3}$）と $45^\circ, 45^\circ, 90^\circ$ の直角二等辺三角形（辺の比 $1 : 1 : \sqrt{2}$）—— 特別な角の値はこの 2 図形から読み取る
- $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$、$1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$ —— 第 3 式は第 1 式の両辺を $\cos^2\theta$ で割れば出る
- 符号：鈍角（$90^\circ < \theta < 180^\circ$）では $\sin$ のみ正、$\cos$・$\tan$ は負 —— 座標の符号から直接読む

### 三角比と図形

- 正弦定理：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$（$R$ は外接円の半径）—— 辺と対角の組、外接円が出たらこれ
- 余弦定理：$a^2 = b^2 + c^2 - 2bc\cos A$、変形して $\cos A = \dfrac{b^2 + c^2 - a^2}{2bc}$ —— 2 辺と夾角、または 3 辺が分かったらこれ
- 三角形の面積：$S = \dfrac{1}{2}bc\sin A$ —— 2 辺と夾角から面積
- 面積の別形：$S = \dfrac{abc}{4R} = \dfrac{r(a + b + c)}{2}$（$r$ は内接円の半径）—— 外接円・内接円の半径と聯動させるときに換える

## 解法パターン

- **定理の選択**：已知一角とその対辺（または $R$ を聞く）→ 正弦定理；已知 2 辺と夾角または 3 辺 → 余弦定理
- **1 つ分かれば残りが決まる**：$\sin$・$\cos$・$\tan$ の 1 つが与えられたら → $\sin^2\theta + \cos^2\theta = 1$ で絶対値を求め、$\theta$ の範囲で符号を決め、割り算で $\tan$ を出す（順序を逆にしない）
- **正弦定理で角を求める**：辺から角を逆算する → $\sin$ の値に対し鋭角と鈍角の 2 解がありうるので、已知の辺の大小・内角の和と照らして検べる
- **空間は平面に落とす**：空間図形の計量 → 截面や投影で关键の平面三角形を取り出し、2 定理と面積公式で処理する（正四面体・球などが典型）
- **$R$・$r$ が出たら面積を経由**：外接円・内接円の半径を聞く／与える問題 → $S = \dfrac{abc}{4R}$、$S = \dfrac{r(a + b + c)}{2}$ で面積を仲介にして辺と結ぶ

## 考前注意

- [ ] $\tan 90^\circ$ を 0 や無限大として扱う（定義されない）
- [ ] 鈍角の $\sin$ まで負になると思う（$\sin$ は $180^\circ$ まで正）
- [ ] 余弦定理で求めた $\cos A$ が負なら角は鈍角——鋭角の直感で答えを取り違える
- [ ] 本项目は度（°）で扱う——数学IIの弧度法（三角関数）と混用しない
- [ ] $\sin^2\theta$ の読み違い（$(\sin\theta)^2$ の意味で、$\sin(\theta^2)$ ではない）
