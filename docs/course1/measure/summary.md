# 図形と計量要点总结

解三角形的工具箱：考前要确认三角比的定义与符号、正弦定理・余弦定理如何选用，以及面积公式与空间计量的处理方法。

## 公式・定理清单

### 三角比

- 鋭角の定義（直角三角形）：$\sin\theta = \dfrac{対辺}{斜辺}$、$\cos\theta = \dfrac{底辺}{斜辺}$、$\tan\theta = \dfrac{対辺}{底辺}$ —— 只要三角形相似，边之比只由 $\theta$ 决定
- 用坐标的定义：在半圆上的点 $(x, y)$（半径 $r$）处 $\sin\theta = \dfrac{y}{r}$、$\cos\theta = \dfrac{x}{r}$、$\tan\theta = \dfrac{y}{x}$ —— 钝角靠此定义；$\theta = 90^\circ$ 时 $\tan\theta$ 没有定义
- 補角の関係：$\sin(180^\circ - \theta) = \sin\theta$、$\cos(180^\circ - \theta) = -\cos\theta$、$\tan(180^\circ - \theta) = -\tan\theta$ —— 钝角的值由锐角侧导出，只记锐角侧即可
- $\sin^2\theta + \cos^2\theta = 1$ —— 本质就是单位圆上的点满足 $x^2 + y^2 = 1$，即三平方の定理
- 変形形：$\sin^2\theta = 1 - \cos^2\theta$、$\cos^2\theta = 1 - \sin^2\theta$ —— 做变形时常用这种形式
- 须记的特殊值从哪来：$30^\circ, 60^\circ, 90^\circ$ 的直角三角形（边之比 $1 : 2 : \sqrt{3}$）与 $45^\circ, 45^\circ, 90^\circ$ 的等腰直角三角形（边之比 $1 : 1 : \sqrt{2}$）—— 特殊角的值都从这两个图形读出
- $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$、$1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$ —— 第三个式子由第一个式子两边同除以 $\cos^2\theta$ 得到
- 符号：在钝角（$90^\circ < \theta < 180^\circ$）范围内只有 $\sin$ 为正，$\cos$、$\tan$ 为负 —— 直接按坐标符号读

### 三角比と図形

- 正弦定理：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$（$R$ 为外接円的半径）—— 出现边与对角的组合、或外接円时用它
- 余弦定理：$a^2 = b^2 + c^2 - 2bc\cos A$，变形得 $\cos A = \dfrac{b^2 + c^2 - a^2}{2bc}$ —— 已知两边与夹角、或三边时用它
- 三角形の面積：$S = \dfrac{1}{2}bc\sin A$ —— 由两边与夹角求面积
- 面积的另一形式：$S = \dfrac{abc}{4R} = \dfrac{r(a + b + c)}{2}$（$r$ 为内接円的半径）—— 需要与外接円・内接円的半径联动时换用

## 解法パターン

- **选定理**：已知一个角与它的对边（或问 $R$）→ 用正弦定理；已知两边与夹角或三边 → 用余弦定理
- **知一求余**：给出 $\sin$、$\cos$、$\tan$ 中的一个 → 先用 $\sin^2\theta + \cos^2\theta = 1$ 求绝对值，再按 $\theta$ 的范围定符号，最后用除法求 $\tan$（顺序不要颠倒）
- **用正弦定理反求角**：由边反求角时 → 一个 $\sin$ 值可能对应锐角与钝角两个解，要结合已知边的大小与内角和来核对取舍
- **空间问题落到平面**：空间图形的计量 → 用截面或投影取出关键的平面三角形，再用两个定理与面积公式处理（正四面体、球等是典型）
- **见 $R$、$r$ 就经由面积**：题目问到或给出外接円・内接円的半径时 → 用 $S = \dfrac{abc}{4R}$、$S = \dfrac{r(a + b + c)}{2}$ 以面积为中介，把半径与边联系起来

## 考前注意

- [ ] 把 $\tan 90^\circ$ 当作 0 或无穷大（它没有定义）
- [ ] 以为钝角的 $\sin$ 也是负的（$\sin$ 到 $180^\circ$ 为止都是正的）
- [ ] 用余弦定理求出的 $\cos A$ 为负时角是钝角——凭锐角的直觉把答案取错
- [ ] 本项目用度（°）——不要与数学II的弧度法（三角関数）混用
- [ ] 读错 $\sin^2\theta$（它表示 $(\sin\theta)^2$，不是 $\sin(\theta^2)$）
