# 正弦定理・余弦定理

三角形 $ABC$ 中边 $a = BC$、$b = CA$、$c = AB$，外接圆半径 $R$、内切圆半径 $r$。

- 正弦定理：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$
- 余弦定理：$a^2 = b^2 + c^2 - 2bc\cos A$（变形 $\cos A = \dfrac{b^2 + c^2 - a^2}{2bc}$）

选用口诀：已知一角及其对边与另一边/角 → 正弦定理；已知两边夹角或三边 → 余弦定理。

**演習：余弦定理**

$b = 3$、$c = 5$、$A = 60^\circ$ のとき、$a$ を求めよ。

??? example "思路・解答"
    **答案**

    $a = \sqrt{19}$

    **思路**

    已知两边及其夹角，直接用余弦定理。

    **解答**

    $$a^2 = 3^2 + 5^2 - 2 \cdot 3 \cdot 5 \cos 60^\circ = 9 + 25 - 15 = 19 \quad\Longrightarrow\quad a = \sqrt{19}$$

**演習：正弦定理と外接円**

$a = 2\sqrt{3}$、$A = 60^\circ$ のとき、外接円の半径 $R$ を求めよ。

??? example "思路・解答"
    **答案**

    $R = 2$

    **思路**

    由正弦定理 $\dfrac{a}{\sin A} = 2R$。

    **解答**

    $$2R = \frac{2\sqrt{3}}{\sin 60^\circ} = \frac{2\sqrt{3}}{\sqrt{3}/2} = 4 \quad\Longrightarrow\quad R = 2$$
