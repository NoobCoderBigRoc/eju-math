# ベクトルと図形

ベクトルで図形を扱う要点は二つ：**面積を内積・成分で計算すること**と、**証明を「基点を決めて位置ベクトルに書き直す」定型手順で進めること**。

## 三角形の面積

$\overrightarrow{OA} = \vec{a}$、$\overrightarrow{OB} = \vec{b}$ とする三角形 $OAB$ の面積は、一般の形では：

$$S = \frac{1}{2}\sqrt{|\vec{a}|^2 |\vec{b}|^2 - (\vec{a} \cdot \vec{b})^2}$$

これは $S = \dfrac{1}{2}|\vec{a}||\vec{b}|\sin\theta$ に $\sin\theta = \sqrt{1 - \cos^2\theta}$ と $\cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$ を入れたもので、角度が分からなくても成分だけで面積が出る。空間でもそのまま使える。

成分が $\vec{a} = (a_1, a_2)$、$\vec{b} = (b_1, b_2)$ の平面では、根号の中が平方の差に整理できて：

$$S = \frac{1}{2}\left|a_1 b_2 - a_2 b_1\right|$$

（$\vec{a}, \vec{b}$ 为两边向量时）。3 点 $A$、$B$、$C$ の座標が直接与えられたら、1 点を始点として $\overrightarrow{AB}$、$\overrightarrow{AC}$ を作ってからこの式を使う。この値が $0$ になるのは 3 点が一直線上にあるときで、共線判定にも流用できる。

## 平行四辺形の面積

$\vec{a}$、$\vec{b}$ を隣り合う 2 辺とする平行四辺形の面積は三角形の 2 倍：$\left|a_1 b_2 - a_2 b_1\right|$（絶対値の中身は行列式の値）。空間では上の根号の形 $\sqrt{|\vec{a}|^2|\vec{b}|^2 - (\vec{a} \cdot \vec{b})^2}$ に戻す。

## ベクトルによる証明の手順

長さ・垂直・中点・比に関する証明は、次の定型で処理できる：

1. 基点を取る（図形の頂点の一つを基点にすると、その点の位置ベクトルが $\vec{0}$ になって式が短くなる）
2. 各点を位置ベクトルで表し、辺を差 $\vec{b} - \vec{a}$ の形に直す
3. 主張をベクトルの言葉に翻訳する：垂直 ⇔ 内積 $= 0$；中点 ⇔ $\dfrac{\vec{a} + \vec{b}}{2}$；平行 ⇔ 一方が他方の実数倍；長さの比較 ⇔ $|\vec{b} - \vec{a}|^2$ を展開して比べる
4. $|\vec{a} - \vec{b}|^2 = |\vec{a}|^2 - 2\vec{a} \cdot \vec{b} + |\vec{b}|^2$ の展開を軸に整理し、結論の形に合わせる

面積比は「同じ高さなら底辺の比、同じ底辺なら高さの比」に帰着させるのが基本で、[位置ベクトル](position-vectors.md) の分点公式とセットで使う。

## 易错点

- [ ] 共線条件の $s + t = 1$ は基点をどこに取るかで形が変わる（共线条件的形式随基点选取而变，写前先声明基点）
- [ ] 面積公式の絶対値と順序（面積公式里行列式差的符号与顺序，取绝对值）
- [ ] 面積の公式に点の座標をそのまま代入する（3 点坐标求面积要先作差得到两边向量；直接代坐标只在其中一点恰为原点时成立）
