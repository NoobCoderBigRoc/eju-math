# ベクトル方程式

ベクトル方程式とは、図形を「点 $P$ の位置ベクトル $\vec{p}$ が満たす関係式」で表したもの。坐标を使わず図形そのものを式にできるので、証明や軌跡の問題で特に強力。基本形は直線・円の二つと、その空間への拡張。

## 直線の方程式

点 $A(\vec{a})$ を通り方向向量 $\vec{d}$ 的直线：$\vec{p} = \vec{a} + t\vec{d}$（$t \in \mathbb{R}$）。

- 2 点形：$A$、$B$ を通る直線は $\vec{d} = \vec{b} - \vec{a}$ を代入して $\vec{p} = (1 - t)\vec{a} + t\vec{b}$。パラメータの範囲を $0 \le t \le 1$ に限れば線分 $AB$、$t \ge 0$ なら $A$ を端点とする半直線になる（範囲の付け方で直線／線分／半直線が切り替わる）。
- 法線形：法向量 $\vec{n}$ を使うと $\vec{n} \cdot (\vec{p} - \vec{a}) = 0$。これは「$\overrightarrow{AP}$ が $\vec{n}$ と垂直」という条件そのもので、成分で書けば通常の直線の方程式 $ax + by + c = 0$ になる。垂直条件が絡む問題ではこちらが速い。

## 円の方程式

中心 $C(\vec{c})$、半径 $r$ の円：$|\vec{p} - \vec{c}| = r$（中心からの距離が一定、という円の定義そのまま）。平方すれば $|\vec{p}|^2 - 2\vec{c} \cdot \vec{p} + |\vec{c}|^2 = r^2$ となり、坐标版の一般式と対応する。

直径の両端が $A$、$B$ の円にはもう一つの形がある：円周角の定理より、$P$ が円上（$P \ne A, B$）⇔ $\angle APB = 90^\circ$ ⇔

$$(\vec{p} - \vec{a}) \cdot (\vec{p} - \vec{b}) = 0$$

展開すると標準形と一致する。与えられた条件が「直径」ならこの形、「中心と半径」なら標準形を選ぶのが解法の分岐点。

## アポロニウスの円

2 定点 $A$、$B$ に対して $PA : PB = m : n$（$m \ne n$）を満たす点 $P$ の軌跡は円（アポロニウスの円）。处理手順：

1. 条件を $n|\vec{p} - \vec{a}| = m|\vec{p} - \vec{b}|$ と絶対値の式に直す
2. 両辺を 2 乗し、$|\vec{p} - \vec{a}|^2 = |\vec{p}|^2 - 2\vec{a} \cdot \vec{p} + |\vec{a}|^2$ の展開で整理する（$m \ne n$ なので $|\vec{p}|^2$ の係数が消えず、円の形が残る）
3. $|\vec{p} - \vec{c}| = r$ の形に平方完成する。中心は直線 $AB$ 上にあり、線分 $AB$ を $m : n$ に内分・外分する 2 点が直径の両端になる

$m = n$ の場合は円ではなく線分 $AB$ の垂直二等分線になるので、最初に切り分ける。

## 空間への拡張

同じ書き方で空間図形も表せる：球面 $|\vec{p} - \vec{c}| = r$；平面 $\vec{n} \cdot (\vec{p} - \vec{a}) = 0$（$\vec{n}$ は法線ベクトル）；空間の直線 $\vec{p} = \vec{a} + t\vec{d}$。

## 易错点

- [ ] 直線のパラメータ表示で $t$ の範囲を付け忘れ、線分の問題を直線として答える（参数范围决定直线/线分/射线，题问线分必须限 $0 \le t \le 1$）
- [ ] アポロニウスの円で $m = n$ の場合（垂直二等分線）を円として処理する（距离比为 $1:1$ 时轨迹不是圆，要先分开）
- [ ] 直径の円の式を展開するとき $|\vec{p}|^2$ の処理を飛ばす（展开 $(\vec{p} - \vec{a}) \cdot (\vec{p} - \vec{b})$ 时按模平方公式逐项展开，不要把内积当成普通乘积漏项）
