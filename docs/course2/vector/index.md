# ベクトル简介（数学C）

向量把几何变成可计算的代数：成分与内积是全部工具，平面与空间用同一套语言处理。

本项目的具体内容都在下面的细目页中（左侧导航点开「14. ベクトル」即可逐层展开）。

## 在 EJU 中的位置

本项目分量大，题型气质是「把几何翻译成代数」的计算型：成分と内積を道具に、図形の条件を式に直して処理する進め方が全編を貫き、空間図形の部分は特にこの言語への依存度が高い。
它与図形と方程式项目互为表里（同内容の座標版とベクトル版），与複素数平面项目也在「平面上の点を数で表す」という発想で並行しており、両者を並べて理解すると定着が良い。
