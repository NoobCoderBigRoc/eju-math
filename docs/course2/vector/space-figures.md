# ベクトルと空間図形

空间图形的处理原则与平面相同：取基点、把点写成位置ベクトル、把「共面・垂直・距離」翻译成向量条件。平面里多出来的核心道具是**法線ベクトル**（法向量）$\vec{n}$：平面由 $\vec{n}$ 定方向，点 $P$ 在过点 $A$、法向量 $\vec{n}$ 的平面上 ⇔ $\vec{n} \cdot (\vec{p} - \vec{a}) = 0$。直線の方向ベクトル $\vec{d}$ と法線ベクトル $\vec{n}$ の関係で、直線と平面の平行（$\vec{d} \cdot \vec{n} = 0$）・垂直（$\vec{d}$ が $\vec{n}$ と平行）も判定できる。

## 四点共面条件

四点 $A$、$B$、$C$、$D$ 共面 ⇔ $\overrightarrow{AD} = s\overrightarrow{AB} + t\overrightarrow{AC}$（$D$ 能被同平面内的两边向量线性表示）；用位置向量写即 $\vec{d} = s\vec{a} + t\vec{b} + u\vec{c}$ 且 $s + t + u = 1$（参见 [位置ベクトル](position-vectors.md)）。空间中不共线的三点定一个平面，第四点是否在上面，就看这个表示是否存在。

## 点と平面の距離

平面 $ax + by + cz + d = 0$（法向量 $(a, b, c)$）与点 $(x_0, y_0, z_0)$ 的距离：

$$h = \frac{|a x_0 + b y_0 + c z_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$$

与平面版点到直线距离公式同形，只是法向量多了 $z$ 分量。用法：求以该平面为底面的四面体（三角锥）的高时，先由底面三点定出平面方程（法向量可由 $\vec{n} \cdot \overrightarrow{AB} = 0$、$\vec{n} \cdot \overrightarrow{AC} = 0$ 联立求出），再把顶点代入这条公式。

## 四面体の体積

四面体 $ABCD$ 的体积有两条路：

- 底面積 × 高：$V = \dfrac{1}{3} \times (\text{底面 } \triangle BCD \text{ の面積}) \times (A \text{ から底面への距離})$。底面积用 [ベクトルと図形](vector-figures.md) 的面积公式推广到空间（$\dfrac{1}{2}\sqrt{|\vec{a}|^2|\vec{b}|^2 - (\vec{a} \cdot \vec{b})^2}$），距离用上面的点到平面距离，这是 EJU での標準的な手順。
- 行列式（det）：以同一点出发的三条棱向量 $\overrightarrow{AB}$、$\overrightarrow{AC}$、$\overrightarrow{AD}$ 的成分排成 $3 \times 3$ 行列式时，$V = \dfrac{1}{6}\left|\det\right|$ 级别的处理。本质是平行六面体体积（スカラー三重積の絶対値）的 $\dfrac{1}{6}$：先 $\dfrac{1}{2}$ 把底面平行四边形变三角形，再 $\dfrac{1}{3}$ 把柱体变锥体。坐标都是整数时这一条往往算得更快。在 EJU 中多以「底面积 × 高 / 3」归结（参见 [項目 7 空間図形](../../course1/geometry/lines-planes.md)）。

## 球と平面

球面 $(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2$ 被平面截出的图形，由「球心到平面的距离 $h$」与 $r$ 的大小决定：$h < r$ 时截面是圆（截面圆半径 $\sqrt{r^2 - h^2}$）；$h = r$ 时相切于一点；$h > r$ 时无公共点。先求 $h$ 再判断，是这类问题的固定顺序。

## 易错点

- [ ] 四面体の体積で $\dfrac{1}{6}$ と $\dfrac{1}{3}$ を取り違える（行列式公式是 1/6；底面积×高公式里是 1/3 乘三角形面积，两条路的系数不同别混）
- [ ] 点と平面の距離は平面の方程式を $ax + by + cz + d = 0$ の形にしてから（求距离前先整理平面方程，法向量系数与常数项要对齐，符号错一位全错）
- [ ] 共面条件の前提として $\overrightarrow{AB}$ と $\overrightarrow{AC}$ が平行でないことを確認する（底面三点共线时根本定不出平面，后面的表示也就不存在）
