# ベクトル要点总结

考前确认本页：成分と内積の計算規則、分点と係数和の条件、ベクトル方程式の形の選び方、空間図形の体積までの手順。

## 公式・定理清单

### 平面上のベクトル

- 成分と大きさ：$\vec{a} = (a_1, a_2)$、$|\vec{a}| = \sqrt{a_1^2 + a_2^2}$ —— 加法・実数倍は成分ごとに計算する
- 平行条件：$\vec{b} = k\vec{a}$（$k$ は実数）と書けること —— 成分が比例することと同値
- 内積：$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta = a_1 b_1 + a_2 b_2$ —— 定義式と成分式の両方を使い分ける
- 垂直条件：$\vec{a} \cdot \vec{b} = 0$；なす角：$\cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$ —— 垂直判定は内積が最速

### ベクトルと平面図形

- 分点公式：内分点 $\dfrac{n\vec{a} + m\vec{b}}{m + n}$、外分点 $\dfrac{-n\vec{a} + m\vec{b}}{m - n}$、中点 $\dfrac{\vec{a} + \vec{b}}{2}$、重心 $\dfrac{\vec{a} + \vec{b} + \vec{c}}{3}$ —— 内分の重みは交叉対応
- 共線条件：$P$ が直線 $AB$ 上 $\iff \vec{p} = s\vec{a} + u\vec{b}$ かつ $s + u = 1$ —— 係数和が判定の核心
- 三角形の面積：$S = \dfrac{1}{2}\sqrt{|\vec{a}|^2 |\vec{b}|^2 - (\vec{a} \cdot \vec{b})^2}$、成分では $S = \dfrac{1}{2}\left|a_1 b_2 - a_2 b_1\right|$ —— 3 点の座標からは先に辺ベクトルを作る
- 直線のベクトル方程式：$\vec{p} = \vec{a} + t\vec{d}$、法線形 $\vec{n} \cdot (\vec{p} - \vec{a}) = 0$ —— $t$ の範囲で直線・線分・半直線が切り替わる
- 円のベクトル方程式：$|\vec{p} - \vec{c}| = r$；直径の両端形 $(\vec{p} - \vec{a}) \cdot (\vec{p} - \vec{b}) = 0$

### 空間座標とベクトル

- 空間の距離：$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$；球面の方程式 $(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2$ —— 内積と垂直条件は平面と同じ形
- 共面条件：$P$ が平面 $ABC$ 上 $\iff \vec{p} = s\vec{a} + t\vec{b} + u\vec{c}$ かつ $s + t + u = 1$
- 点と平面の距離：$h = \dfrac{|a x_0 + b y_0 + c z_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$ —— 平面を $ax + by + cz + d = 0$ の形にしてから使う
- 四面体の体積：底面積 × 高さ × $\dfrac{1}{3}$；同一点から出る 3 棱の行列式では $\dfrac{1}{6}|\det|$ —— 2 つの路で係数が違う
- 球と平面：球心から平面への距離 $h$ と $r$ を比べ、$h < r$ なら截面は半径 $\sqrt{r^2 - h^2}$ の円、$h = r$ で接する、$h > r$ で交わらない

## 解法パターン

- **垂直・角度**：成分が与えられたら → 内積を計算し、垂直なら $= 0$、角度なら $\cos\theta$ の式に代入する
- **図形の証明**：長さ・垂直・中点・比の主張は → 1 頂点を基点に取り位置ベクトルで書き直し、主張を内積・中点公式・実数倍の言葉に翻訳して展開する
- **共線・共面の判定**：点の位置関係を聞かれたら → 係数和が 1 になる表示が作れるかを探す
- **軌跡と図形の方程式**：中心と半径なら $|\vec{p} - \vec{c}| = r$、直径の両端なら内積形、距離の比ならアポロニウスの円（比が $1 : 1$ なら垂直二等分線に切り分ける）
- **四面体の体積**：底面 3 点から法線ベクトルで平面の方程式を作り → 点と平面の距離で高さを求め → 底面積 × 高さ ÷ 3

## 考前注意

- [ ] 内分点の重みは交叉対応（分点に近い端点ほど重みが小さい）で、中点の場合で検算できる
- [ ] 係数和 $= 1$ の条件は基点をそろえて書いたときにだけ使える
- [ ] 面積公式に点の座標を直接代入せず、先に 2 本の辺ベクトルを作る
- [ ] 線分のベクトル方程式では $0 \le t \le 1$ の範囲を付け忘れない
- [ ] 四面体の体積で、行列式の $\dfrac{1}{6}$ と底面積 × 高さの $\dfrac{1}{3}$ を混同しない
