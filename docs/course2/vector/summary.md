# ベクトル要点总结

考前确认本页：成分与内積的计算规则、分点与系数和的条件、ベクトル方程式形式的选用、空間図形求体积的步骤。

## 公式・定理清单

### 平面上のベクトル

- 成分と大きさ：$\vec{a} = (a_1, a_2)$、$|\vec{a}| = \sqrt{a_1^2 + a_2^2}$ —— 加法与実数倍都逐成分计算
- 平行条件：能写成 $\vec{b} = k\vec{a}$（$k$ 为実数）—— 与成分成比例等价
- 内積：$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta = a_1 b_1 + a_2 b_2$ —— 定义式与成分式要分场合使用
- 垂直条件：$\vec{a} \cdot \vec{b} = 0$；なす角：$\cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$ —— 判垂直用内積最快

### ベクトルと平面図形

- 分点公式：内分点 $\dfrac{n\vec{a} + m\vec{b}}{m + n}$、外分点 $\dfrac{-n\vec{a} + m\vec{b}}{m - n}$、中点 $\dfrac{\vec{a} + \vec{b}}{2}$、重心 $\dfrac{\vec{a} + \vec{b} + \vec{c}}{3}$ —— 内分的权重交叉对应
- 共線条件：$P$ 在直線 $AB$ 上 $\iff \vec{p} = s\vec{a} + u\vec{b}$ 且 $s + u = 1$ —— 系数和是判定的核心
- 三角形の面積：$S = \dfrac{1}{2}\sqrt{|\vec{a}|^2 |\vec{b}|^2 - (\vec{a} \cdot \vec{b})^2}$，成分形式为 $S = \dfrac{1}{2}\left|a_1 b_2 - a_2 b_1\right|$ —— 由三点坐标求时先作辺ベクトル
- 直線のベクトル方程式：$\vec{p} = \vec{a} + t\vec{d}$、法線形 $\vec{n} \cdot (\vec{p} - \vec{a}) = 0$ —— 由 $t$ 的范围切换直線・線分・半直線
- 円のベクトル方程式：$|\vec{p} - \vec{c}| = r$；直径の両端形 $(\vec{p} - \vec{a}) \cdot (\vec{p} - \vec{b}) = 0$

### 空間座標とベクトル

- 空間の距離：$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$；球面の方程式 $(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2$ —— 内積与垂直条件与平面情形同形
- 共面条件：$P$ 在平面 $ABC$ 上 $\iff \vec{p} = s\vec{a} + t\vec{b} + u\vec{c}$ 且 $s + t + u = 1$
- 点と平面の距離：$h = \dfrac{|a x_0 + b y_0 + c z_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$ —— 先把平面写成 $ax + by + cz + d = 0$ 的形式再用
- 四面体の体積：底面積 × 高さ × $\dfrac{1}{3}$；同一点出发的三条棱用行列式时是 $\dfrac{1}{6}|\det|$ —— 两条路径的系数不同
- 球と平面：比较球心到平面的距离 $h$ 与 $r$：$h < r$ 时截面是半径 $\sqrt{r^2 - h^2}$ 的円，$h = r$ 时相切，$h > r$ 时不相交

## 解法パターン

- **垂直・角度**：给出成分时 → 计算内積，垂直代入 $= 0$，角度代入 $\cos\theta$ 的公式
- **图形证明**：长度・垂直・中点・比这类主张 → 以一个頂点为基点用位置ベクトル改写，把主张翻译成内積・中点公式・実数倍的语言再展开
- **共線・共面的判定**：问点的位置关系时 → 看能否作出系数和为 $1$ 的表示
- **轨迹与图形方程式**：中心与半径用 $|\vec{p} - \vec{c}| = r$，直径両端用内積形，距离比用アポロニウスの円（比为 $1 : 1$ 时切换为垂直二等分線）
- **四面体の体積**：由底面三点作法線ベクトル得到平面的方程式 → 用点到平面的距离求高 → 底面積 × 高さ ÷ 3

## 考前注意

- [ ] 内分点的权重交叉对应（离分点越近的端点权重越小），可用中点的情形验算
- [ ] 系数和 $= 1$ 的条件只在对齐了基点写出时才能用
- [ ] 不要把点坐标直接代入面積公式，先作两条辺ベクトル
- [ ] 線分的ベクトル方程式不要漏写 $0 \le t \le 1$ 的范围
- [ ] 四面体の体積不要混淆行列式の $\dfrac{1}{6}$ 与底面積 × 高さの $\dfrac{1}{3}$
