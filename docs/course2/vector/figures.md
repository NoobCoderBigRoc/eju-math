# ベクトルと平面図形

## 1. 位置ベクトルと図形

分点公式：分 $AB$ 为 $m : n$ 的点的位置向量 $\dfrac{n\vec{a} + m\vec{b}}{m + n}$（与坐标版同一形式）。三点共线条件：$\vec{c} = s\vec{a} + t\vec{b}$ 且 $s + t = 1$（原点任意时的表示法）。面积比用底边比与高之比转换。

三角形面积（坐标/向量版）：$S = \dfrac{1}{2}\left|a_1 b_2 - a_2 b_1\right|$（$\vec{a}, \vec{b}$ 为两边向量时）。

## 2. ベクトル方程式

- 直线：$\vec{p} = \vec{a} + t\vec{d}$（方向向量 $\vec{d}$）；法向量形式：$\vec{n} \cdot (\vec{p} - \vec{a}) = 0$
- 圆：$|\vec{p} - \vec{c}| = r$
- 阿波罗尼斯圆（アポロニウスの円）：$PA : PB = m : n$（$m \ne n$）的轨迹是圆，用位置向量平方展开整理。

## 易错点

- [ ] 共線条件の $s + t = 1$ は基点をどこに取るかで形が変わる（共线条件的形式随基点选取而变，写前先声明基点）
- [ ] 面積公式の絶対値と順序（面積公式里行列式差的符号与顺序，取绝对值）
