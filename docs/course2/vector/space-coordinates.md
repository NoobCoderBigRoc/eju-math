# 空間座標とベクトル

平面的全部概念平移到三维：成分变 3 个，内积与垂直条件形式不变。

- 两点间距离 $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$；球面方程 $(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2$
- 空间直线：$\vec{p} = \vec{a} + t\vec{d}$；平面：$\vec{n} \cdot (\vec{p} - \vec{a}) = 0$（法向量 $\vec{n}$）；点到平面的距离公式与平面直线版同形（含 $\sqrt{a^2 + b^2 + c^2}$）

**演習：空間の内積**

$\vec{a} = (1, 2, 2)$、$\vec{b} = (2, -1, 0)$ の内積と、それぞれの大きさを求めよ。

??? example "思路・解答"
    **答案**

    内積 $0$（垂直）、$|\vec{a}| = 3$、$|\vec{b}| = \sqrt{5}$

    **思路**

    内积按成分对应相乘求和；出现 0 即两向量垂直，不必再求角度。

    **解答**

    $$\vec{a} \cdot \vec{b} = 2 - 2 + 0 = 0, \qquad |\vec{a}| = \sqrt{1 + 4 + 4} = 3, \qquad |\vec{b}| = \sqrt{4 + 1} = \sqrt{5}$$
