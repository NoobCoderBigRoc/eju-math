# ベクトルとその演算・成分

$\vec{a} = (a_1, a_2)$；加法/数乘按成分运算；大小 $|\vec{a}| = \sqrt{a_1^2 + a_2^2}$。平行条件：$\vec{b} = k\vec{a}$（成分成比例）。

??? example "演習：内積と垂直条件"
    **问题**

    $\vec{a} = (2, 1)$、$\vec{b} = (1, k)$ が垂直であるような $k$ の値を求めよ。

    **答案**

    $k = -2$

    **思路**

    垂直 ⇔ 内积为 0。

    **解答**

    $$\vec{a} \cdot \vec{b} = 2 \cdot 1 + 1 \cdot k = 0 \quad\Longrightarrow\quad k = -2$$
