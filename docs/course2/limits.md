## 1. 数列の極限

$a_n$ の極限は、分子・分母を**最高次の項で割る**のが基本操作である。無限等比数列 $r^n$ は $|r| < 1$ で $0$ に収束し、$r = 1$ で $1$、それ以外では発散する。

**無限級数**：部分和 $S_n$ の極限が収束するとき、その値が級数の和。無限等比級数（初項 $a$、公比 $r$、$|r| < 1$）の和は

$$
S = \frac{a}{1 - r}
$$

級数が収束するには一般項 $a_n \to 0$ が必要である（十分ではない）。

## 2. 関数の極限と連続性

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1 \qquad (x \text{ は弧度法})
$$

$\dfrac{0}{0}$ 型は、約分・有理化・公式の利用で不定形を解消してから値を判定する。

**連続性**：関数 $f$ が $x = a$ で連続であるのは $\displaystyle\lim_{x \to a} f(x) = f(a)$ のとき。初等関数は定義域の各点で連続である。

## 例題（演習）

??? example "例題 1：数列の極限"
    $\displaystyle\lim_{n \to \infty} \frac{2n^2 + 3n}{n^2 + 1}$ を求めよ。

    **考え方**：分子・分母を $n^2$ で割る。

    **解答**：$\dfrac{2 + \frac{3}{n}}{1 + \frac{1}{n^2}}$ となり、$n \to \infty$ で $\dfrac{3}{n} \to 0$、$\dfrac{1}{n^2} \to 0$ なので、極限は $2$。

    **答え**：$2$

??? example "例題 2：無限級数"
    無限級数 $\dfrac{1}{2} + \dfrac{1}{4} + \dfrac{1}{8} + \dots$ の和を求めよ。

    **考え方**：初項 $\dfrac{1}{2}$、公比 $\dfrac{1}{2}$ の無限等比級数であり、$|r| < 1$ を確認して公式を使う。

    **解答**：$S = \dfrac{\frac{1}{2}}{1 - \frac{1}{2}} = 1$。

    **答え**：$1$

??? example "例題 3：関数の極限"
    (1) $\displaystyle\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$　(2) $\displaystyle\lim_{x \to 0} \frac{\sin 3x}{x}$ を求めよ。

    **考え方**：(1) は因数分解して約分、(2) は $\dfrac{\sin x}{x} \to 1$ の形に直す。

    **解答**：(1) $\dfrac{(x - 2)(x + 2)}{x - 2} = x + 2 \to 4$。(2) $\dfrac{\sin 3x}{x} = 3 \cdot \dfrac{\sin 3x}{3x} \to 3 \times 1 = 3$。

    **答え**：(1) $4$　(2) $3$

## よくあるミス

- [ ] $\dfrac{0}{0}$ 型を「0」や「存在しない」と即断する（不定形は解消してから判定）
- [ ] 無限等比級数で $|r| < 1$ の収束条件を確認せずに公式を使う
- [ ] 左右の極限が一致しない点で「極限が存在する」としてしまう
- [ ] $\dfrac{\sin x}{x}$ の公式を度数法のまま使う（弧度法が前提）
