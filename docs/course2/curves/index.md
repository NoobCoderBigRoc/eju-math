# 式と曲線简介（数学C）

二次曲线（抛物线・椭圆・双曲线）与两种新的曲线描述法：媒介変数表示与極座標。

本项目的具体内容都在下面的细目页中（左侧导航点开「16. 式と曲線」即可逐层展开）。

## 在 EJU 中的位置

本项以读图与图形识别为主：2次曲線靠标准形定焦点、漸近線，媒介変数表示与極座標则是给后面留的「曲线描述法」。它单独出题多为标准形读写与軌跡，但真正的分量在联动——項目 20 積分法里的極座標面積、媒介変数曲線的弧長都以这里为入口，微分法的接線处理也常借媒介変数表示出题。
