# 式と曲線要点总结

考前确认三件事：2次曲線の標準形から焦点・準線・漸近線を即答できること、媒介変数の消去と範囲の確認、極方程式と直交座標の相互変換。

## 公式・定理清单

### 2次曲線

- 放物線 $y^2 = 4px$：焦点 $(p, 0)$、準線 $x = -p$ —— 焦点と準線からの距離が等しい点の軌跡
- 楕円 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b$）：焦点 $(\pm\sqrt{a^2 - b^2}, 0)$ —— 2焦点からの距離の和が $2a$ 一定
- 双曲線 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$：焦点 $(\pm\sqrt{a^2 + b^2}, 0)$、漸近線 $y = \pm\dfrac{b}{a}x$ —— 距離の差が $2a$ 一定
- 焦点距離の符号：楕円は $a^2 - b^2$、双曲線は $a^2 + b^2$ —— 減か加かを取り違えない
- 離心率 $e = \dfrac{\sqrt{a^2 - b^2}}{a}$（楕円で $e < 1$、双曲線で $e > 1$）—— 形の潰れ具合を表す

### 媒介変数表示

- 円：$x = p + r\cos t$、$y = q + r\sin t$；楕円：$x = a\cos t$、$y = b\sin t$ —— パラメータは中心角・離心角
- 双曲線（右枝）：$x = \dfrac{a}{\cos t}$、$y = b\tan t$ —— $\cos t$ の符号で左右の枝が替わる
- 放物線 $y^2 = 4px$：$x = pt^2$、$y = 2pt$；サイクロイド：$x = a(t - \sin t)$、$y = a(1 - \cos t)$ —— 頻出の定番形
- 消去の恒等式：$\sin^2 t + \cos^2 t = 1$、双曲線では $\dfrac{1}{\cos^2 t} - \tan^2 t = 1$ —— 三角パラメータはこの形に持ち込む
- $\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}$ —— 接線の傾きは媒介変数のまま求められる

### 極座標と極方程式

- $x = r\cos\theta$、$y = r\sin\theta$、$r = \sqrt{x^2 + y^2}$ —— 直交座標との変換の基本
- 円 $x^2 + y^2 = ax$ は $r = a\cos\theta$、直線 $x = a$ は $r\cos\theta = a$ —— 変換は両辺に $r$ を掛けるのが定石
- カージオイド $r = a(1 + \cos\theta)$、螺旋 $r = a\theta$ —— 典型の極方程式曲線
- 極座標の面積 $S = \dfrac{1}{2}\int r^2 \, d\theta$ —— 扇形の集積として読む（積分法と連携）

## 解法パターン

- **標準形の読み取り型**：2次曲線の方程式が与えられた → 平方完成で標準形に直し、焦点・頂点・漸近線を読み取る
- **媒介変数の消去型**：$x = f(t)$、$y = g(t)$ の関係式を求める → 代入消去か三角恒等式で消し、最後にパラメータの範囲が定める図形の範囲を確認する
- **極方程式の変換型**：$r$、$\theta$ の式を直交座標に直す → 両辺に $r$ を掛けて $r^2 = x^2 + y^2$、$r\cos\theta = x$ に帰着させる
- **軌跡の範囲型**：消去後の方程式が全体を示しても、実際の軌跡はその一部 → パラメータの範囲から描く部分を切り取る

## 考前注意

- [ ] 楕円と双曲線で焦点距離の式の符号を取り違える（椭圆减、双曲线加）
- [ ] 長軸が $y$ 軸側のとき焦点の向きも $y$ 軸側に替わる
- [ ] 媒介変数を消去しただけで終え、パラメータの範囲が定める図形の範囲を落とす
- [ ] 双曲線の媒介変数表示で $\cos t$ の符号（左右どちらの分枝か）を確認しない
- [ ] $r$ が負の場合の点の取り方の約束を確認する
