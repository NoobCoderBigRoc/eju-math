# 式と曲線要点总结

考前确认三件事：能从2次曲線的标准形立即答出焦点・準線・漸近線、媒介変数的消去与范围确认、極方程式与直角坐标之间的相互转换。

## 公式・定理清单

### 2次曲線

- 放物線 $y^2 = 4px$：焦点 $(p, 0)$、準線 $x = -p$ —— 到焦点和準線距离相等的点的軌跡
- 楕円 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b$）：焦点 $(\pm\sqrt{a^2 - b^2}, 0)$ —— 到两个焦点的距离之和恒为 $2a$
- 双曲線 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$：焦点 $(\pm\sqrt{a^2 + b^2}, 0)$、漸近線 $y = \pm\dfrac{b}{a}x$ —— 到两个焦点的距离之差恒为 $2a$
- 焦点距离的符号：楕円用 $a^2 - b^2$、双曲線用 $a^2 + b^2$ —— 别把该减还是该加弄反
- 離心率 $e = \dfrac{\sqrt{a^2 - b^2}}{a}$（楕円的 $e < 1$、双曲線的 $e > 1$）—— 表示图形被压扁的程度

### 媒介変数表示

- 円：$x = p + r\cos t$、$y = q + r\sin t$；楕円：$x = a\cos t$、$y = b\sin t$ —— 参数是中心角・離心角
- 双曲線（右枝）：$x = \dfrac{a}{\cos t}$、$y = b\tan t$ —— 左右两枝由 $\cos t$ 的符号决定
- 放物線 $y^2 = 4px$：$x = pt^2$、$y = 2pt$；サイクロイド：$x = a(t - \sin t)$、$y = a(1 - \cos t)$ —— 高频出现的标准形式
- 消去用的恒等式：$\sin^2 t + \cos^2 t = 1$，双曲線则用 $\dfrac{1}{\cos^2 t} - \tan^2 t = 1$ —— 含三角函数的参数式都化归到这一形式
- $\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}$ —— 切线的斜率可以直接用参数形式求出

### 極座標と極方程式

- $x = r\cos\theta$、$y = r\sin\theta$、$r = \sqrt{x^2 + y^2}$ —— 与直角坐标相互转换的基础
- 圆 $x^2 + y^2 = ax$ 化为 $r = a\cos\theta$，直线 $x = a$ 化为 $r\cos\theta = a$ —— 转换的定式是两边同乘 $r$
- カージオイド $r = a(1 + \cos\theta)$、螺旋 $r = a\theta$ —— 典型的極方程式曲线
- 極座標下的面积 $S = \dfrac{1}{2}\int r^2 \, d\theta$ —— 看作扇形的累积（与積分法联动）

## 解法パターン

- **读标准形型**：给出2次曲線的方程 → 用平方完成化为标准形，读出焦点・頂点・漸近線
- **消去参数型**：求 $x = f(t)$、$y = g(t)$ 的关系式 → 用代入消去或三角恒等式消去参数，最后确认参数范围所限定的图形范围
- **極方程式转换型**：把 $r$、$\theta$ 的式子化为直角坐标 → 两边同乘 $r$，归结到 $r^2 = x^2 + y^2$、$r\cos\theta = x$
- **轨迹范围型**：消去后方程表示整条曲线，但实际轨迹只是其中一部分 → 按参数的范围截取要画的部分

## 考前注意

- [ ] 把楕円与双曲線焦点距离公式的符号弄反（楕円减、双曲線加）
- [ ] 长轴在 $y$ 轴一侧时，焦点的朝向也随之转到 $y$ 轴一侧
- [ ] 只消去参数就收尾，漏掉参数范围所限定的图形范围
- [ ] 双曲線的参数表示中不确认 $\cos t$ 的符号（是左枝还是右枝）
- [ ] $r$ 取负值时点的取法约定没有确认
