# 媒介変数表示

曲線上の点の座標を、第三の変数（媒介変数、パラメータ）$t$ を使って $x = f(t)$、$y = g(t)$ と表す方法。$t$ が動くにつれて点が曲線をたどるので、「点の運動」として曲線を捉えられるのが強み。円・楕円のように $y$ が $x$ の 1 価関数でない曲線もそのまま表せる。

## よく使う曲線の媒介変数表示

| 曲線 | 媒介変数表示 | パラメータの意味 |
| --- | --- | --- |
| 直線（点 $(x_0, y_0)$、方向 $(a, b)$） | $x = x_0 + at$、$y = y_0 + bt$ | 始点からの移動量 |
| 円（中心 $(p, q)$、半径 $r$） | $x = p + r\cos t$、$y = q + r\sin t$ | 中心角 |
| 楕円 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ | $x = a\cos t$、$y = b\sin t$ | 離心角（円のときの中心角に相当） |
| 双曲線 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$（右半分） | $x = \dfrac{a}{\cos t}$、$y = b\tan t$ | 漸近線との位置関係を決める角 |
| 放物線 $y^2 = 4px$ | $x = pt^2$、$y = 2pt$ | 接線の傾きの逆数 |
| 放物線 $y = ax^2$ | $x = t$、$y = at^2$ | $x$ 座標そのもの |
| サイクロイド | $x = a(t - \sin t)$、$y = a(1 - \cos t)$ | 転がした円の回転角 |

代表例として、半径 $a$ の円が $x$ 軸上を転がるときの円周上の 1 点の軌跡が摆线（サイクロイド）で、$t$ は転がした角を表す。

## 媒介変数の消去

$x$、$y$ の関係式（通常の方程式）に戻す操作が媒介変数の消去。方法は表示の形で使い分ける：

1. **代入消去**：一方の式を $t = \cdots$ の形に解き、他方へ代入する（直線や $x = t$ 型はこちら）
2. **恒等式の利用**：$\cos t$、$\sin t$ を含むときは $\sin^2 t + \cos^2 t = 1$ に持ち込む（円：$\left(\dfrac{x - p}{r}\right)^2 + \left(\dfrac{y - q}{r}\right)^2 = 1$、楕円も同様；双曲線では $\dfrac{1}{\cos^2 t} - \tan^2 t = 1$ を使う）
3. **加減・変形**：$t$ を含む項を移項してから 2 乗・加減し、$t$ を消す

消去した後は、**パラメータの範囲が決める図形の範囲**を必ず確認する。たとえば $x = \cos t$、$y = \sin t$（$0 \le t \le \dfrac{\pi}{2}$）を消去すると $x^2 + y^2 = 1$ になるが、実際に描くのは第 1 象限の 4 分の 1 の弧だけ。この「方程式は全体、軌跡はその一部」というずれが頻出の論点。

## 微分との接続

分析或微积分处理时可消参数化为 $x, y$ 的关系式，或直接对参数求导（$\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}$，见 [微分法](../differentiation/derivative-definition.md)）。接線の傾き・増減・曲線の長さなど、媒介変数のまま処理する方が簡単な場面も多い。媒介変数で表された関数の 2 次導関数や面積の公式は [積分法](../integration/integral-techniques.md) と合わせて使う。

## 易错点

- [ ] 媒介変数を消去しただけで安心し、パラメータの範囲が定める図形の範囲（定義域）を落とす（消去后得到的只是候选方程，必须回头核对参数范围限定的那一段）
- [ ] 双曲線の媒介変数表示で $\cos t$ の符号（左右どちらの分枝か）を確認しない（$x = a/\cos t$ は $\cos t$ の符号で右枝・左枝が替わる）
- [ ] $\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}$ で $dx/dt = 0$ の点（接線が垂直になる点）を通常の点と混ぜて処理する（参数求导在 $dx/dt = 0$ 处要单独讨论）
