# 媒介変数表示

曲线用参数 $t$ 表示：$x = f(t)$、$y = g(t)$。常见：圆 $(\cos t, \sin t)$、椭圆 $(a\cos t, b\sin t)$、摆线（サイクロイド）$x = a(t - \sin t)$、$y = a(1 - \cos t)$。

分析或微积分处理时可消参数化为 $x, y$ 的关系式，或直接对参数求导（$\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}$，见 [微分法](../differentiation/derivative-definition.md)）。
