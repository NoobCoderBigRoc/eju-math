# 解と係数の関係

$ax^2 + bx + c = 0$ 的两根 $\alpha, \beta$：$\alpha + \beta = -\dfrac{b}{a}$、$\alpha\beta = \dfrac{c}{a}$。三次方程中同样有三根和、两两积和、三根积与系数的关系。对称式（対称式）的值都可以由基本对称式算出。

??? example "演習：解と係数の関係"
    **问题**

    2次方程式 $x^2 - 3x + 1 = 0$ の2つの解を $\alpha$、$\beta$ とするとき、$\alpha^2 + \beta^2$ の値を求めよ。

    **答案**

    7

    **思路**

    不求出根本身（根是无理数），把 $\alpha^2 + \beta^2$ 改写成对称式：$(\alpha + \beta)^2 - 2\alpha\beta$。

    **解答**

    $$\alpha + \beta = 3, \quad \alpha\beta = 1 \quad\Longrightarrow\quad \alpha^2 + \beta^2 = 3^2 - 2 \cdot 1 = 7$$

## 易错点

- [ ] 解と係数の関係の符号（$\alpha + \beta = -b/a$ のマイナス）
