# 等式と不等式の証明

## 1. 等式の証明

等式 $A = B$ の証明方法は3通りある。

1. **一方の辺を変形**して他方を導く（左辺から右辺へ、が最も一般的。複雑な側から簡単な側へ変形する）
2. **両辺をそれぞれ変形**して、同じ式になることを示す
3. **差を作る**：$A - B = 0$ を示す

証明の書き方では「$=$」で式をつなぐ変形の過程を明示し、結論（示したい等式）を途中で仮定してはならない。恒等式の証明も同じ方法で行うが、恒等式であることの証明には「すべての $x$ で成り立つ」ことが本質であり、係数比較法はそのための十分条件を与える方法である。

## 2. 不等式の証明

不等式 $A \ge B$ は、多くの場合 **差 $A - B \ge 0$ を示す** ことに帰着させる。差を処理する代表的な方法：

1. **因数分解**：差が積の形になれば、各因数の符号から全体の符号が分かる
2. **平方完成**：差を $(\quad)^2 + (\text{正の数})$ の形にすれば $\ge 0$ が明らかになる。実数の2乗は $\ge 0$ であることが不等式証明の基本原理である
3. **相加平均・相乗平均の関係**：$a, b > 0$ のとき $a + b \ge 2\sqrt{ab}$（等号は $a = b$ のとき）。和と積が両方現れる式で有効
4. **両辺を2乗する**：両辺がともに $\ge 0$ のときに限り使える（根号を含む不等式で有効）。両辺の符号が分からないまま2乗すると不等号の向きが保証されない

証明の流れは「条件の確認（正であること等）→ 差を作る → 変形して符号を確定する → 等号成立条件を述べる」の順に書くとよい。

## 3. 相加平均・相乗平均を使うときの注意

- 前提は $a, b > 0$（実数であるだけでなく正であること）。負の数には使えない
- 使った後は必ず **等号成立条件**（$a = b$）を確認し、問題が最小値を問うている場合は等号が実際に達成可能かまで述べる
- 式の形を整えてから使う：$\dfrac{x}{2} + \dfrac{2}{x}$ のように「積が定数になる」組み合わせを見つけるのがコツ

## 易错点

- [ ] 相加・相乗平均を使うとき等号成立条件の確認を忘れる（用 AM-GM 后要验证等号条件）
- [ ] 両辺の符号を確認せずに2乗する（負の辺があると不等号の向きが保たれない）
- [ ] 示したい等式・不等式自体を変形し続けて $0 = 0$ や自明な形に到達し、それを証明とみなす（結論を仮定してはいけない；変形は一方の辺だけ、または両辺別々に行う）
- [ ] 相加・相乗平均を負の数に適用する
