# いろいろな式要点总结

考前确认本页：二項定理与恒等式的公式骨架、証明的书写定式，以及複素数・判別式・解と係数の関係这套高次方程式工具。

## 公式・定理清单

### 式と証明

- 二項定理：$(a + b)^n = \sum_{r=0}^{n} {}_n\mathrm{C}_r\, a^{n-r} b^r$ —— 一般項 ${}_n\mathrm{C}_r a^{n-r} b^r$ 是求指定幂次系数的入口
- 多項式の除法：$A = BQ + R$（$\deg R < \deg B$）—— 商与余式唯一；笔算时缺失的次数项要用系数 $0$ 补上
- 恒等式の決定法：係数比較法与数値代入法 —— $n$ 次恒等式只要在 $n + 1$ 个不同取值处成立，就在全体上成立
- 不等式証明の基本：$A \ge B \iff A - B \ge 0$ —— 证明不等式归结为证明差非负，用因数分解・平方完成确定符号
- 相加平均・相乗平均：$a + b \ge 2\sqrt{ab}$（$a, b > 0$，等号在 $a = b$ 时成立）—— 前提是正数，用完必须确认等号成立条件

### 高次方程式

- 複素数：$i^2 = -1$、$a + bi$ —— 求商时分子分母同乘分母的共役来实数化，并利用 $(a + bi)(a - bi) = a^2 + b^2$
- $i$ の冪：$i, -1, -i, 1$ 的 4 周期 —— 按指数除以 4 的余数化归
- 判別式 $D = b^2 - 4ac$：$D > 0$ 时两个不同实数解、$D = 0$ 时重解、$D < 0$ 时一对共役虚数解 —— 在複素数范围内恒有 2 个解
- 解と係数の関係：对两根 $\alpha, \beta$，$\alpha + \beta = -\dfrac{b}{a}$、$\alpha\beta = \dfrac{c}{a}$ —— 对称式都能用这两个量表示
- 剰余の定理：$P(x)$ 除以 $x - a$ 的余式是 $P(a)$ —— 不用笔算除法就能得到余式
- 因数定理：$P(a) = 0 \iff (x - a)$ 是 $P(x)$ 的因数 —— 是给高次方程式降次的工具
- $n$ 次方程式の解の個数：在複素数范围内计重数恰有 $n$ 个解 —— 实系数方程式若有虚数解，其共役也必是解

## 解法パターン

- **求指定项的系数**：问展开式中某一项的系数时 → 用二項定理的一般項对齐指数，再乘 ${}_n\mathrm{C}_r$ 与其余系数
- **只求余式**：多項式除法不需要商时 → 用剰余の定理代入计算 $P(a)$
- **分数式计算**：出现約分・通分・乘除时 → 先把分子、分母因数分解，只消去公共因式
- **等式与不等式证明**：给出要证明的式子时 → 从三种写法中选：只变形一侧、两侧分别变形、作差
- **求对称式的值**：遇到 $\alpha^2 + \beta^2$ 这类根的式子 → 不解方程式，改写成基本対称式 $\alpha + \beta$、$\alpha\beta$
- **解高次方程式**：3 次以上 → 先试有理根候选（常数项的約数 ÷ 最高次系数的約数），用因数定理逐次降一次，最后用解の公式

## 考前注意

- [ ] 解と係数の関係的符号：不要漏掉 $\alpha + \beta = -b/a$ 中的负号
- [ ] 负数的根号：不要把 $\sqrt{-2}\,\sqrt{-3}$ 算成 $\sqrt{6}$；先化成 $i\sqrt{2}$、$i\sqrt{3}$ 的形式再计算
- [ ] 相加・相乗平均只对正数可用，用后要确认等号成立条件
- [ ] 証明中把结论本身一路变形到 $0 = 0$，也不算证明
- [ ] 分数式的約分要先因数分解再进行，不能逐项约掉
