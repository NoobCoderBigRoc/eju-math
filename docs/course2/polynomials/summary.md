# いろいろな式要点总结

考前确认本页：二項定理与恒等式的公式骨架、証明的书写定式，以及複素数・判別式・解と係数の関係这套高次方程式工具。

## 公式・定理清单

### 式と証明

- 二項定理：$(a + b)^n = \sum_{r=0}^{n} {}_n\mathrm{C}_r\, a^{n-r} b^r$ —— 一般項 ${}_n\mathrm{C}_r a^{n-r} b^r$ 是求指定幂次系数的入口
- 多項式の除法：$A = BQ + R$（$\deg R < \deg B$）—— 商与余式唯一，筆算は欠けた次数の項を係数 $0$ で補う
- 恒等式の決定法：係数比較法と数値代入法 —— $n$ 次の恒等式は $n + 1$ 個の値で成り立てば全体で成立
- 不等式証明の基本：$A \ge B$ は差 $A - B \ge 0$ を示すことに帰着 —— 因数分解・平方完成で符号を確定する
- 相加平均・相乗平均：$a, b > 0$ のとき $a + b \ge 2\sqrt{ab}$（等号は $a = b$）—— 前提は正の数、等号条件の確認までがセット

### 高次方程式

- 複素数：$i^2 = -1$、$a + bi$ の形 —— 商は分母の共役を分母分子に掛けて実数化し、$(a + bi)(a - bi) = a^2 + b^2$ を使う
- $i$ の冪：$i, -1, -i, 1$ の 4 周期 —— 指数を 4 で割った余りで帰着させる
- 判別式 $D = b^2 - 4ac$：$D > 0$ で異なる 2 実数解、$D = 0$ で重解、$D < 0$ で共役な虚数解のペア —— 複素数範囲では常に 2 解を持つ
- 解と係数の関係：2 解 $\alpha, \beta$ について $\alpha + \beta = -\dfrac{b}{a}$、$\alpha\beta = \dfrac{c}{a}$ —— 対称式はこの 2 つで表せる
- 剰余の定理：$P(x)$ を $x - a$ で割った余りは $P(a)$ —— 筆算せずに余りが出る
- 因数定理：$P(a) = 0 \iff (x - a)$ は $P(x)$ の因数 —— 高次方程式を降次する道具
- $n$ 次方程式は複素数の範囲で重解を含めてちょうど $n$ 個の解をもつ —— 実係数で虚数解があれば共役も解

## 解法パターン

- **指定項の係数**：展開式の特定の項の係数を聞かれたら → 二項定理の一般項で指数を合わせ、${}_n\mathrm{C}_r$ と残りの係数を掛ける
- **余りだけ求める**：多項式の割り算で商が不要なら → 剰余の定理で $P(a)$ を代入計算する
- **分数式の計算**：約分・通分・乗除が出たら → まず分子・分母を因数分解し、共通因数だけを消す
- **等式・不等式の証明**：示すべき式が与えられたら → 一方の辺だけを変形する、両辺を別々に変形する、差を作る、の 3 通りから選ぶ
- **対称式の値を求める**：$\alpha^2 + \beta^2$ のような根の式は → 根を求めず基本対称式 $\alpha + \beta$、$\alpha\beta$ に書き直す
- **高次方程式を解く**：3 次以上は → 有理根候補（定数項の約数／最高次の係数の約数）を試し、因数定理で 1 次ずつ降次して最後は解の公式

## 考前注意

- [ ] 解と係数の関係の符号：$\alpha + \beta = -b/a$ のマイナスを落とさない
- [ ] 負の数の根号：$\sqrt{-2}\,\sqrt{-3} = \sqrt{6}$ とせず、先に $i\sqrt{2}$、$i\sqrt{3}$ の形に直してから計算する
- [ ] 相加・相乗平均は正の数にしか使えず、使った後は等号成立条件を確認する
- [ ] 証明で結論自体を変形し続けて $0 = 0$ に到達しても証明にはならない
- [ ] 分数式の約分は因数分解してから行い、項ごとに消すことはできない
