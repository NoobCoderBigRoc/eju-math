# 複素数と2次方程式の解

## 1. 複素数と四則

虚数単位 $i$ は $i^2 = -1$ を満たす数であり、実数 $a, b$ を用いた $a + bi$ の形の数を **複素数** という。$a$ を実部、$b$ を虚部と呼ぶ。$i$ の冪は $i, -1, -i, 1$ の4つを周期的に繰り返す。

- 和・差・積：実数と同様に計算し、$i^2 = -1$ で置き換える
- 商：分母の **共役複素数**（$\overline{a + bi} = a - bi$）を分母分子に掛けて分母を実数化する。$(a + bi)(a - bi) = a^2 + b^2$ が鍵になる

複素数 $\alpha$ に対して、$\alpha$ の共役 $\bar{\alpha}$ とは実部が同じで虚部の符号が逆の数であり、$\alpha + \bar{\alpha} = 2\mathrm{Re}\,\alpha$、$\alpha \bar{\alpha} = |\alpha|^2$ の関係がある。

## 2. 2次方程式の解の分類

実数係数の2次方程式 $ax^2 + bx + c = 0$（$a \ne 0$）は、判別式 $D = b^2 - 4ac$ の符号によって解が完全に分類される。複素数の範囲では **$D$ の符号によらず常に2解を持つ**（重解は1つに数える）ことが実数範囲との大きな違いである。

| 判別式 | 解 | 解の公式での形 |
| --- | --- | --- |
| $D > 0$ | 異なる2つの実数解 | $x = \dfrac{-b \pm \sqrt{D}}{2a}$ |
| $D = 0$ | 重解（実数解1つ） | $x = -\dfrac{b}{2a}$ |
| $D < 0$ | 共役な虚数解のペア | $x = \dfrac{-b \pm i\sqrt{-D}}{2a}$ |

$D < 0$ のとき解は必ず共役ペア $\alpha + \beta i$、$\alpha - \beta i$（$\alpha, \beta$ は実数）になる。これは、実数係数の方程式に虚数解を代入し、その共役を取っても式が成り立つためである。また複素数の範囲では因数分解が常に行えて、$ax^2 + bx + c = a(x - \alpha)(x - \beta)$ と書ける（$\alpha, \beta$ は2解）。

## 易错点

- [ ] 虚数解の「共役ペア」で片方だけを答える（虚根成对，勿漏一）
- [ ] 根号の計算規則の誤用（$\sqrt{-2}\,\sqrt{-3} = \sqrt{6}$ としてしまう誤り；負の数では $\sqrt{p}\,\sqrt{q} = \sqrt{pq}$ は成り立たない。$\sqrt{-2} = i\sqrt{2}$ と直してから計算する）
- [ ] 商の計算で共役を掛ける相手を取り違える（分母分子の両方に分母の共役を掛ける）
- [ ] $i$ の高冪の処理（4で割った余りで $i, -1, -i, 1$ に帰着させる）
