# 剰余の定理と因数定理

多项式 $P(x)$ 除以 $x - a$ 的余数是 $P(a)$；$P(a) = 0 \iff (x - a)$ 是 $P(x)$ 的因式。高次方程的解法即反复找有理根试除降次（有理数解の候補は「定数項の約数／最高次の係数の約数」）。

**演習：剰余の定理**

$P(x) = x^3 - 2x^2 + 3x - 5$ を $x - 2$ で割った余りを求めよ。

??? example "思路・解答"
    **答案**

    1

    **思路**

    不用真除，用剰余の定理：余数 $= P(2)$。

    **解答**

    $$P(2) = 8 - 8 + 6 - 5 = 1$$
