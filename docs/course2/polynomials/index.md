# いろいろな式简介（数学II）

证明的方法论与高次方程：恒等式、二项定理、不等式证明，以及复数的引入与解と係数の関係。

本项目的具体内容都在下面的细目页中（左侧导航点开「8. いろいろな式」即可逐层展开）。

## 在 EJU 中的位置

本项目是 Course 2 代数运算的根基，分量中上，题型气质是计算与证明各半：前半「式と証明」的方法论（二項定理、恒等式、不等式証明的书写定式）在整张试卷里都会回用，证明题的失分多在书写规范而不在思路。
后半「高次方程式」是后续複素数平面项目的直接前置，解と係数の関係与恒等式的係数比較法也会在微分法等项目中反复出现。
