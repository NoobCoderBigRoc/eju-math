# 高次方程式の解法と性質

三次以上的高次方程式没有通用求根公式可套，解法的主线只有一条：找有理根试除、降次，再重复——也就是反复用[因数定理](remainder-factor.md)把方程拆回低次。

解法步骤：

1. 列出有理数解の候補：有理数解の候補は「定数項の約数／最高次の係数の約数」。候補只有有限个，逐个代入 $P(x)$ 试根。
2. 找到使 $P(a) = 0$ 的 $a$ 后，由因数定理知 $(x - a)$ 是因式，用筆算（或組立除法）做多项式除法，把方程降一次。
3. 对商式重复上述过程，直到降为 2 次方程式为止，最后用解の公式收尾。

性質として押さえる点：

- $n$ 次方程式は複素数の範囲で重解を含めてちょうど $n$ 個の解をもつ（$n$ 次方程在复数范围内、计重根恰有 $n$ 个解）。
- 実係数の方程式が虚数解をもてば、その共役（共役）も必ず解になる（虚根成对出现）。
