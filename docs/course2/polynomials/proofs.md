# 式と証明

## 1. 多項式の除法・分数式・恒等式

- 除法：$A = BQ + R$（$\deg R < \deg B$），用竖式除法（筆算）求商与余式。
- 分数式：先因数分解再约分；通分时找最小公倍式作分母。
- 恒等式：两边系数对应相等（係数比較法），或代入足够多个数值定系数（数値代入法）。

## 2. 二項定理

$$(a + b)^n = \sum_{r=0}^{n} {}_n\mathrm{C}_r\, a^{n-r} b^r$$

一般项 ${}_n\mathrm{C}_r a^{n-r} b^r$ 是求「指定幂次的系数」的入口。

## 3. 等式と不等式の証明

- 等式：从一边变形到另一边，或两边减差为 0。
- 不等式：作差因数分解、用平方完成，或用相加平均与相乘平均（相加平均・相乗平均の関係）$a + b \ge 2\sqrt{ab}$（$a, b > 0$，等号在 $a = b$ 时成立）。

??? example "演習：二項定理"
    **问题**

    $(x + 2)^5$ の展開式における $x^3$ の係数を求めよ。

    **答案**

    40

    **思路**

    $x^3$ 出现在「5 个因子中 3 个取 $x$、2 个取 2」的项里：${}_5\mathrm{C}_3 x^3 \cdot 2^2$——注意组合数选的是「哪 3 个取 x」，与选「哪 2 个取 2」等价。

    **解答**

    $${}_5\mathrm{C}_3 \cdot 2^2 = 10 \cdot 4 = 40$$

## 易错点

- [ ] 相加・相乗平均を使うとき等号成立条件の確認を忘れる（用 AM-GM 后要验证等号条件）
- [ ] 恒等式の係数比較は同類項どうしで（系数比较要按同类项一一对应）
