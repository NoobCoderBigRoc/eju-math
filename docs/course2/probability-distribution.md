## 1. 確率変数と確率分布

**確率変数**（随机变量）$X$ 以概率 $p_1, \dots, p_n$ 取值 $x_1, \dots, x_n$（$p_k \geqq 0$、$p_1 + \dots + p_n = 1$）时，这个对应关系称为 $X$ 的**確率分布**（概率分布）。

## 2. 期待値・分散・標準偏差

$$
E(X) = \sum_{k} x_k p_k, \qquad V(X) = E\left((X - E(X))^2\right) = E(X^2) - \{E(X)\}^2, \qquad \sigma(X) = \sqrt{V(X)}
$$

分散（方差）衡量「离平均的离散程度」，计算时用 $E(X^2) - \{E(X)\}^2$ 这个形式最快。

## 3. 確率変数の変換と和

当 $Y = aX + b$（$a$、$b$ 为常数）时：

$$
E(Y) = aE(X) + b, \qquad V(Y) = a^2 V(X), \qquad \sigma(Y) = |a|\,\sigma(X)
$$

随机变量的和：无论是否独立，**期待値的和**都成立：

$$
E(X + Y) = E(X) + E(Y)
$$

而分散的和 $V(X + Y) = V(X) + V(Y)$ 只在 $X$ 与 $Y$ **独立**时成立。这一对区别是本章最高频的考点。

## 4. 共分散と相関係数

对两个变量（随机变量）$X$、$Y$：

$$
\mathrm{Cov}(X, Y) = E(XY) - E(X)E(Y), \qquad r = \frac{\mathrm{Cov}(X, Y)}{\sigma(X)\,\sigma(Y)} \quad (-1 \leqq r \leqq 1)
$$

$r$ 越接近 1 正相关越强，越接近 $-1$ 负相关越强。作为数据分析的处理方式见 [データの分析（補充）](../course1/data.md)。

## 例题（演习）

??? example "例题 1：期待値と分散"
    コインを 3 回投げるとき、表が出る回数 $X$ の確率分布を求め、$E(X)$、$V(X)$、$\sigma(X)$ を計算せよ。

    **思路**：先用反复试验的概率列出分布，再代入定义式。

    **解答**：分布为 $P(X = 0) = \dfrac{1}{8}$、$P(X = 1) = \dfrac{3}{8}$、$P(X = 2) = \dfrac{3}{8}$、$P(X = 3) = \dfrac{1}{8}$。

    $$
    E(X) = \frac{0 \cdot 1 + 1 \cdot 3 + 2 \cdot 3 + 3 \cdot 1}{8} = \frac{3}{2}, \qquad E(X^2) = \frac{0 + 3 + 12 + 9}{8} = 3
    $$

    $$
    V(X) = 3 - \left(\frac{3}{2}\right)^2 = \frac{3}{4}, \qquad \sigma(X) = \frac{\sqrt{3}}{2}
    $$

    **答案**：$E(X) = \dfrac{3}{2}$、$V(X) = \dfrac{3}{4}$、$\sigma(X) = \dfrac{\sqrt{3}}{2}$

??? example "例题 2：確率変数の変換"
    例題 1 の $X$ について、$Y = 2X + 1$ の期待値と分散・標準偏差を求めよ。

    **思路**：直接套变换公式，不需要重新列分布。

    **解答**：$E(Y) = 2 \times \dfrac{3}{2} + 1 = 4$、$V(Y) = 4 \times \dfrac{3}{4} = 3$、$\sigma(Y) = \sqrt{3}$。

    **答案**：$E(Y) = 4$、$V(Y) = 3$、$\sigma(Y) = \sqrt{3}$

??? example "例题 3：相関係数"
    4 組のデータ $(x, y) = (1, 2), (2, 3), (3, 5), (4, 6)$ について、$x$ と $y$ の相関係数を求めよ。

    **思路**：先算平均 $\bar{x} = 2.5$、$\bar{y} = 4$，再算共分散与各自的标准偏差。

    **解答**：共分散是 $\dfrac{(-1.5)(-2) + (-0.5)(-1) + (0.5)(1) + (1.5)(2)}{4} = \dfrac{7}{4}$。分散是 $s_x^2 = \dfrac{5}{4}$、$s_y^2 = \dfrac{10}{4}$，所以

    $$
    r = \frac{7/4}{\sqrt{5/4}\,\sqrt{10/4}} = \frac{7}{\sqrt{50}} = \frac{7\sqrt{2}}{10} \approx 0.99
    $$

    是很强的正相关。

    **答案**：$r = \dfrac{7\sqrt{2}}{10} \approx 0.99$

## 易错点

- [ ] 计算 $V(X)$ 时混淆 $E(X^2)$ 与 $\{E(X)\}^2$
- [ ] 以为变换 $Y = aX + b$ 中 $b$ 会影响分散（分散对平移不变；$\sigma$ 要乘 $|a|$）
- [ ] 以为 $E(X + Y) = E(X) + E(Y)$ 需要独立性（恒成立；需要独立性的是分散的和）
- [ ] 算出的相関係数超出 $-1$ 到 $1$ 还照写（这是算错的信号）
