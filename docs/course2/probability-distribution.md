## 1. 確率変数と確率分布

**確率変数** $X$ が値 $x_1, \dots, x_n$ を確率 $p_1, \dots, p_n$ でとるとき（$p_k \geqq 0$、$p_1 + \dots + p_n = 1$）、この対応を $X$ の**確率分布**という。

## 2. 期待値・分散・標準偏差

$$
E(X) = \sum_{k} x_k p_k, \qquad V(X) = E\left((X - E(X))^2\right) = E(X^2) - \{E(X)\}^2, \qquad \sigma(X) = \sqrt{V(X)}
$$

分散は「平均からの散らばり」を測る量で、計算は $E(X^2) - \{E(X)\}^2$ の形が速い。

## 3. 確率変数の変換と和

$Y = aX + b$（$a$, $b$ は定数）のとき：

$$
E(Y) = aE(X) + b, \qquad V(Y) = a^2 V(X), \qquad \sigma(Y) = |a|\,\sigma(X)
$$

確率変数の和については、独立でなくても**期待値の和**が成り立つ：

$$
E(X + Y) = E(X) + E(Y)
$$

分散の和 $V(X + Y) = V(X) + V(Y)$ は $X$ と $Y$ が**独立**のときのみ成り立つ。

## 4. 共分散と相関係数

2 つの変量（確率変数）$X$, $Y$ について：

$$
\mathrm{Cov}(X, Y) = E(XY) - E(X)E(Y), \qquad r = \frac{\mathrm{Cov}(X, Y)}{\sigma(X)\,\sigma(Y)} \quad (-1 \leqq r \leqq 1)
$$

$r$ が 1 に近いほど強い正の相関、$-1$ に近いほど強い負の相関がある。データの分析としての扱いは [データの分析（補充）](../course1/data.md) を参照。

## 例題（演習）

??? example "例題 1：期待値と分散"
    コインを 3 回投げるとき、表が出る回数 $X$ の確率分布を求め、$E(X)$、$V(X)$、$\sigma(X)$ を計算せよ。

    **考え方**：反復試行の確率で分布を作り、定義式に代入する。

    **解答**：分布は $P(X = 0) = \dfrac{1}{8}$、$P(X = 1) = \dfrac{3}{8}$、$P(X = 2) = \dfrac{3}{8}$、$P(X = 3) = \dfrac{1}{8}$。

    $$
    E(X) = \frac{0 \cdot 1 + 1 \cdot 3 + 2 \cdot 3 + 3 \cdot 1}{8} = \frac{3}{2}, \qquad E(X^2) = \frac{0 + 3 + 12 + 9}{8} = 3
    $$

    $$
    V(X) = 3 - \left(\frac{3}{2}\right)^2 = \frac{3}{4}, \qquad \sigma(X) = \frac{\sqrt{3}}{2}
    $$

    **答え**：$E(X) = \dfrac{3}{2}$、$V(X) = \dfrac{3}{4}$、$\sigma(X) = \dfrac{\sqrt{3}}{2}$

??? example "例題 2：確率変数の変換"
    例題 1 の $X$ について、$Y = 2X + 1$ の期待値と分散・標準偏差を求めよ。

    **考え方**：変換の公式をそのまま適用する。分布を作り直す必要はない。

    **解答**：$E(Y) = 2 \times \dfrac{3}{2} + 1 = 4$、$V(Y) = 4 \times \dfrac{3}{4} = 3$、$\sigma(Y) = \sqrt{3}$。

    **答え**：$E(Y) = 4$、$V(Y) = 3$、$\sigma(Y) = \sqrt{3}$

??? example "例題 3：相関係数"
    4 組のデータ $(x, y) = (1, 2), (2, 3), (3, 5), (4, 6)$ について、$x$ と $y$ の相関係数を求めよ。

    **考え方**：平均 $\bar{x} = 2.5$、$\bar{y} = 4$ を求め、共分散と各標準偏差を計算する。

    **解答**：共分散は $\dfrac{(-1.5)(-2) + (-0.5)(-1) + (0.5)(1) + (1.5)(2)}{4} = \dfrac{7}{4}$。分散は $s_x^2 = \dfrac{5}{4}$、$s_y^2 = \dfrac{10}{4}$ だから、

    $$
    r = \frac{7/4}{\sqrt{5/4}\,\sqrt{10/4}} = \frac{7}{\sqrt{50}} = \frac{7\sqrt{2}}{10} \approx 0.99
    $$

    強い正の相関がある。

    **答え**：$r = \dfrac{7\sqrt{2}}{10} \approx 0.99$

## よくあるミス

- [ ] $V(X)$ の計算で $E(X^2)$ と $\{E(X)\}^2$ を取り違える
- [ ] 変換 $Y = aX + b$ で分散に $b$ が影響すると思い込む（分散は平行移動で不変、$\sigma$ には $|a|$ が掛かる）
- [ ] $E(X + Y) = E(X) + E(Y)$ に独立性が必要だと思い込む（常に成立。独立性が必要なのは分散の和）
- [ ] 相関係数の値域（$-1$ から $1$）を超えた答えをそのままにする（計算ミスのサイン）
