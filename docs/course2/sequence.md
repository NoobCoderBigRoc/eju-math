## 1. 等差数列・等比数列

$$
\text{等差：} \quad a_n = a + (n - 1)d, \qquad S_n = \frac{n\{2a + (n - 1)d\}}{2} = \frac{n(a_1 + a_n)}{2}
$$

$$
\text{等比：} \quad a_n = a r^{n-1}, \qquad S_n = \frac{a(r^n - 1)}{r - 1} \ (r \ne 1), \qquad S_n = na \ (r = 1)
$$

## 2. いろいろな数列の和

$$
\sum_{k=1}^{n} k = \frac{n(n + 1)}{2}, \qquad \sum_{k=1}^{n} k^2 = \frac{n(n + 1)(2n + 1)}{6}, \qquad \sum_{k=1}^{n} k^3 = \left\{\frac{n(n + 1)}{2}\right\}^2
$$

部分分数分解による和（$\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$ の telescoping）と、等差×等比型の和（公比を掛けて引く）が代表的な技巧である。

## 3. 漸化式

| 型 | 解法 |
| --- | --- |
| $a_{n+1} = a_n + f(n)$ | 階差数列として累加する |
| $a_{n+1} = p a_n + q$ | 特性方程式 $x = px + q$ の解 $\alpha$ で平行移動し、$a_n - \alpha$ を等比数列にする |
| $a_{n+1} = p a_n + r^n$ 型 | $r^{n+1}$ で割って階差の形に帰着させる |

**階差数列**：$b_n = a_{n+1} - a_n$ とすると、$n \geqq 2$ で $a_n = a_1 + \sum_{k=1}^{n-1} b_k$。

## 4. 数学的帰納法

$n$ に関する命題 $P(n)$ の証明は：(i) $n = 1$ のとき $P(1)$ が成り立つことを示す。(ii) $n = k$ のとき成り立つと**仮定して**、$n = k + 1$ のときも成り立つことを示す。第 2 段階で仮定を実際に使うことが本質である。

## 例題（演習）

??? example "例題 1：漸化式（平行移動型）"
    $a_1 = 1$、$a_{n+1} = 2a_n + 3$ で定まる数列の一般項を求めよ。

    **考え方**：特性方程式 $x = 2x + 3$ の解 $x = -3$ で平行移動する。

    **解答**：$a_{n+1} + 3 = 2(a_n + 3)$。数列 $a_n + 3$ は初項 $4$、公比 $2$ の等比数列なので $a_n + 3 = 4 \cdot 2^{n-1} = 2^{n+1}$。

    **答え**：$a_n = 2^{n+1} - 3$

??? example "例題 2：階差数列"
    $a_1 = 1$、$a_{n+1} = a_n + 2n$ で定まる数列の一般項を求めよ。

    **考え方**：階差は $b_n = 2n$。累加する。

    **解答**：$n \geqq 2$ で $a_n = a_1 + \sum_{k=1}^{n-1} 2k = 1 + 2 \cdot \dfrac{(n - 1)n}{2} = n^2 - n + 1$。$n = 1$ でもこの式は $1$ を与えるので、すべての $n$ で成り立つ。

    **答え**：$a_n = n^2 - n + 1$

??? example "例題 3：数学的帰納法"
    すべての正の整数 $n$ に対して $1 + 3 + 5 + \dots + (2n - 1) = n^2$ を証明せよ。

    **考え方**：数学的帰納法の 2 段階で示す。

    **解答**：(i) $n = 1$ のとき、左辺は $1$、右辺は $1$ で成り立つ。(ii) $n = k$ のとき成り立つと仮定すると、$n = k + 1$ の左辺は $k^2 + (2k + 1) = (k + 1)^2$ となり、$n = k + 1$ でも成り立つ。よって、すべての正の整数 $n$ で成り立つ。

    **答え**：証明終わり

## よくあるミス

- [ ] 階差から一般項を出すとき $n = 1$ の確認を省く（累加の式は $n \geqq 2$ 用）
