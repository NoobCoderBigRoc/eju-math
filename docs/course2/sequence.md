## 1. 等差数列・等比数列

$$
\text{等差：} \quad a_n = a + (n - 1)d, \qquad S_n = \frac{n\{2a + (n - 1)d\}}{2} = \frac{n(a_1 + a_n)}{2}
$$

$$
\text{等比：} \quad a_n = a r^{n-1}, \qquad S_n = \frac{a(r^n - 1)}{r - 1} \ (r \ne 1), \qquad S_n = na \ (r = 1)
$$

## 2. いろいろな数列の和

$$
\sum_{k=1}^{n} k = \frac{n(n + 1)}{2}, \qquad \sum_{k=1}^{n} k^2 = \frac{n(n + 1)(2n + 1)}{6}, \qquad \sum_{k=1}^{n} k^3 = \left\{\frac{n(n + 1)}{2}\right\}^2
$$

代表性技巧有两个：部分分数分解求和（$\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$ 的 telescoping，相邻项抵消），以及等差×等比型求和（乘公比后错位相减）。

## 3. 漸化式

| 型 | 解法 |
| --- | --- |
| $a_{n+1} = a_n + f(n)$ | 作为階差数列累加 |
| $a_{n+1} = p a_n + q$ | 用特性方程式 $x = px + q$ 的解 $\alpha$ 平移，把 $a_n - \alpha$ 化为等比数列 |
| $a_{n+1} = p a_n + r^n$ 型 | 两边除以 $r^{n+1}$，化为階差的形 |

**階差数列**（阶差数列）：令 $b_n = a_{n+1} - a_n$，则 $n \geqq 2$ 时 $a_n = a_1 + \sum_{k=1}^{n-1} b_k$。注意这个式子只对 $n \geqq 2$ 成立，最后要单独验 $n = 1$。

## 4. 数学的帰納法

关于 $n$ 的命题 $P(n)$ 的证明分两步：(i) 证明 $n = 1$ 时 $P(1)$ 成立；(ii) **假设** $n = k$ 时成立，推出 $n = k + 1$ 时也成立。第二步必须真正用上假设，这是归纳法的本质，只做式子变形不算证明。

## 例题（演习）

??? example "例题 1：漸化式（平行移動型）"
    $a_1 = 1$、$a_{n+1} = 2a_n + 3$ で定まる数列の一般項を求めよ。

    **思路**：用特性方程式 $x = 2x + 3$ 的解 $x = -3$ 作平移。

    **解答**：$a_{n+1} + 3 = 2(a_n + 3)$。数列 $a_n + 3$ 是首项 $4$、公比 $2$ 的等比数列，所以 $a_n + 3 = 4 \cdot 2^{n-1} = 2^{n+1}$。

    **答案**：$a_n = 2^{n+1} - 3$

??? example "例题 2：階差数列"
    $a_1 = 1$、$a_{n+1} = a_n + 2n$ で定まる数列の一般項を求めよ。

    **思路**：阶差是 $b_n = 2n$，累加求和。

    **解答**：$n \geqq 2$ 时 $a_n = a_1 + \sum_{k=1}^{n-1} 2k = 1 + 2 \cdot \dfrac{(n - 1)n}{2} = n^2 - n + 1$。$n = 1$ 时此式也给出 $1$，所以对所有 $n$ 成立。

    **答案**：$a_n = n^2 - n + 1$

??? example "例题 3：数学的帰納法"
    すべての正の整数 $n$ に対して $1 + 3 + 5 + \dots + (2n - 1) = n^2$ を証明せよ。

    **思路**：按数学归纳法的两步写，第二步要明确用上假设。

    **解答**：(i) $n = 1$ 时左边 $1$、右边 $1$，成立。(ii) 设 $n = k$ 时成立，则 $n = k + 1$ 的左边为 $k^2 + (2k + 1) = (k + 1)^2$（这里用了假设把前 $k$ 项的和换成 $k^2$），即 $n = k + 1$ 时也成立。因此对所有正整数 $n$ 成立。

    **答案**：证明完毕

## 易错点

- [ ] 等比数列求和不分 $r = 1$ 的情形
- [ ] 由阶差求通项时漏验 $n = 1$（累加式只适用于 $n \geqq 2$）
- [ ] 归纳法第二步不用假设、只做变形
- [ ] 混淆 $\left(\sum a_k\right)^2$ 与 $\sum a_k^2$
