# 数列

## 考纲要求

等差/等比数列、递推关系、$\Sigma$ 记号与数列求和、数学归纳法。Course 2 压轴题常客，常与微积分、取模综合出题。

## 等差数列

首项 $a$、公差 $d$：

$$
a_n = a + (n-1)d, \qquad S_n = \frac{n\{2a + (n-1)d\}}{2} = \frac{n(a_1 + a_n)}{2}
$$

## 等比数列

首项 $a$、公比 $r\ (r \ne 1)$：

$$
a_n = ar^{n-1}, \qquad S_n = \frac{a(r^n - 1)}{r - 1}
$$

无穷等比级数（$|r| < 1$）：

$$
S = \frac{a}{1 - r}
$$

## $\Sigma$ 运算

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}, \quad \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}, \quad \sum_{k=1}^{n} k^3 = \left\{\frac{n(n+1)}{2}\right\}^2
$$

## 递推数列

| 递推形式 | 处理方法 |
| --- | --- |
| $a_{n+1} = a_n + f(n)$ | 阶差法（累加） |
| $a_{n+1} = p\,a_n + q$ | 特征方程 $x = px + q$ 平移构造等比 |
| $a_{n+1} = p\,a_n + r^n$ | 两边除以 $r^{n+1}$ |
| $a_{n+1} = f(a_n)$ 型不动点 | 求不动点 $\alpha$，研究 $\dfrac{a_{n+1}-\alpha}{a_n - \alpha}$ |

## 数学归纳法

1. $n = 1$ 时成立；
2. 设 $n = k$ 时成立，推出 $n = k+1$ 时成立。

## 典型例题

??? example "例题：递推构造"
    $a_1 = 1$，$a_{n+1} = 2a_n + 3$，求通项。

    **解答**：特征方程 $x = 2x + 3$，得 $x = -3$。构造

    $$
    a_{n+1} + 3 = 2(a_n + 3) \implies a_n + 3 = 2^{n-1}(a_1 + 3) = 2^{n+1}
    $$

    故 $a_n = 2^{n+1} - 3$。

## 易错点

- [x] 等比数列求和忘记讨论 $r = 1$；
- [x] 数学归纳法第二步**只验证式子变形正确**，没有用上"假设"；
- [x] $\Sigma$ 的平方展开 $\left(\sum a_k\right)^2 \ne \sum a_k^2$。
