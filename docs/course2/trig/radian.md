# 一般角と弧度法

弧度（ラジアン）：$\pi\ \mathrm{rad} = 180^\circ$；弧长 $l = r\theta$、扇形面积 $S = \dfrac{1}{2}r^2\theta$。

- [ ] 弧度法なのに度（°）の感覚で計算する（用了弧度制却按角度直觉计算）
