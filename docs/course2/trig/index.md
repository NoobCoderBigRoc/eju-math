# 三角関数简介（数学II）

把項目 4 的三角比推广到任意角与弧度制；加法定理是本项目的核心，由它派生 2 倍角、半角与合成。

本项目的具体内容都在下面的细目页中（左侧导航点开「11. 三角関数」即可逐层展开）。

## 在 EJU 中的位置

本项目分量大，题型气质是公式驱动的计算型：加法定理是核心，由它向外辐射出 2 倍角、半角、合成与グラフ，公式之间的派生关系比逐个死记更重要。
它同时是微分法・積分法项目的直接前置——三角関数的微積分在后续项目中按例出题，極限项目里与 $\sin$ 相关的極限也建立在本项目的弧度法与単位円的理解之上。
