| [三角函数](trig.md) | 加法定理、和差化积、图像 | ★★★★ |
| [指数函数·对数函数](explog.md) | 对数运算、方程不等式 | ★★★ |
| [数列](sequence.md) | 等差等比、递推、Σ、数学归纳法 | ★★★★★ |
| [向量](vector.md) | 内积、位置向量、图形应用 | ★★★★ |
| [复数平面](complex.md) | 极形式、棣莫弗定理、旋转 | ★★★ |
| [微分与积分](calculus.md) | 导数与切线、不定/定积分、面积体积 | ★★★★★ |
