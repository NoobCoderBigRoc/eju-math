# 期待値・分散・標準偏差

- 期待値：$E(X) = \sum x_i p_i$
- 分散：$V(X) = E\left((X - E(X))^2\right) = E(X^2) - \{E(X)\}^2$（计算时用后式更省事；$E(X^2)$ 是「平方的期待值」，不是「期待值的平方」）
- 標準偏差：$\sigma(X) = \sqrt{V(X)}$，与 $X$ 单位相同

二項分布 $B(n, p)$：$E(X) = np$、$V(X) = np(1 - p)$。

**演習：期待値と分散**

確率変数 $X$ の分布が $P(X = 0) = \dfrac{1}{2}$、$P(X = 1) = \dfrac{1}{3}$、$P(X = 2) = \dfrac{1}{6}$ のとき、$E(X)$ と $V(X)$ を求めよ。

??? example "思路・解答"
    **答案**

    $E(X) = \dfrac{2}{3}$、$V(X) = \dfrac{5}{9}$

    **思路**

    先算 $E(X)$ 与 $E(X^2)$，再用 $V(X) = E(X^2) - \{E(X)\}^2$。

    **解答**

    $$E(X) = 0 \cdot \frac{1}{2} + 1 \cdot \frac{1}{3} + 2 \cdot \frac{1}{6} = \frac{2}{3}$$

    $$E(X^2) = 0 + 1 \cdot \frac{1}{3} + 4 \cdot \frac{1}{6} = 1, \qquad V(X) = 1 - \left(\frac{2}{3}\right)^2 = \frac{5}{9}$$

## 易错点

- [ ] $E(X^2)$ と $\{E(X)\}^2$ の混同（平方的期待值与期待值的平方搞混）
- [ ] 二項分布の平均・分散の公式適用時に $n$、$p$ の対応ミス（二项分布代公式时 n、p 对应错）
