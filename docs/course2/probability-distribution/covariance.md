# 共分散と相関係数

两个随机变量 $X, Y$：

- 共分散（协方差）：$\mathrm{Cov}(X, Y) = E\left((X - E(X))(Y - E(Y))\right) = E(XY) - E(X)E(Y)$，表示同向/反向联动的程度。
- 相関係数（相关系数）：$r = \dfrac{\mathrm{Cov}(X, Y)}{\sigma(X)\sigma(Y)}$，必在 $-1 \le r \le 1$；接近 1 正相关、接近 −1 负相关、接近 0 无（线性）相关。
- 独立 $\Rightarrow$ 共分散 0（逆不成立）。

**演習：相関係数**

5人の生徒の数学と英語の得点がそれぞれ (60, 70)、(70, 65)、(80, 90)、(90, 85)、(50, 55) のとき、相関係数を求めよ。

??? example "思路・解答"
    **答案**

    約 $0.88$

    **思路**

    两科各求平均与共分散，再除以标准差之积。

    **解答**

    $\bar{x} = 70$、$\bar{y} = 73$。偏差积和 $= (-10)(-3) + 0 \cdot (-8) + 10 \cdot 17 + 20 \cdot 12 + (-20)(-18) = 30 + 0 + 170 + 240 + 360 = 800$，共分散 $= 800 / 5 = 160$。

    $s_x^2 = (100 + 0 + 100 + 400 + 400)/5 = 200$、$s_y^2 = (9 + 64 + 289 + 144 + 324)/5 = 166$。

    $$r = \frac{160}{\sqrt{200} \cdot \sqrt{166}} = \frac{160}{\sqrt{33200}} \approx \frac{160}{182.2} \approx 0.88$$

    ※ 用 $n$ 与 $n - 1$ 哪种定义分母会互相抵消，相关系数不变。
