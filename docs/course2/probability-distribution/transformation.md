# 確率変数の変換と和

## 1. 確率変数の変換

对 $Y = aX + b$：

$$E(Y) = aE(X) + b, \qquad V(Y) = a^2 V(X), \qquad \sigma(Y) = |a|\,\sigma(X)$$

注意：分散乘的是 $a^2$（平移 $b$ 不影响分散），标准偏差乘 $|a|$。

## 2. 確率変数の和と期待値

任意随机变量（不论独立与否）：$E(X + Y) = E(X) + E(Y)$。分散则需要独立性：$X, Y$ 独立时 $V(X + Y) = V(X) + V(Y)$（且 $V(X - Y) = V(X) + V(Y)$，符号是**加**）。

样本均值 $\bar{X} = \dfrac{X_1 + \cdots + X_n}{n}$（各 $X_i$ 独立同分布）：$E(\bar{X}) = \mu$、$V(\bar{X}) = \dfrac{\sigma^2}{n}$。

## 易错点

- [ ] $V(aX + b)$ で $a^2$ でなく $a$ を掛ける（变换后分散乘的是 a 的平方）
- [ ] 独立でない変数の和に分散の加法を適用する（不独立时乱用分散加法）
- [ ] $V(X - Y)$ を $V(X) - V(Y)$ にする（差的分散仍是加，不是减）
