# 確率分布と統計的な推測要点总结

考前确认三件事：分布表の検算（確率の総和 1）、$E$・$V$・$\sigma$ の公式の使い分け、変換と和で「独立かどうか」を先に判定する習慣。

## 公式・定理清单

### 確率変数と確率分布

- 確率分布：$\displaystyle \sum_i p_i = 1$、$0 \le p_i \le 1$ —— 分布を作ったらまず総和を検算する
- 区間の確率 $P(a \le X \le b)$ は該当する $x_i$ の確率の和 —— 端の外の値は含めない
- 二項分布 $B(n, p)$：$P(X = k) = {}_n\mathrm{C}_k\, p^k (1 - p)^{n - k}$ —— 適用条件は「各試行が独立」「$p$ が毎回一定」
- 連続型：$P(a \le X \le b) = \int_a^b f(x)\, dx$、$P(X = a) = 0$ —— 確率は密度関数の面積で与えられる

### 期待値・分散・標準偏差

- $E(X) = \sum x_i p_i$ —— 確率で重み付けした平均
- $V(X) = E(X^2) - \{E(X)\}^2$ —— 計算はこの形が速い。$E(X^2)$ は「平方の期待値」であって「期待値の平方」ではない
- $\sigma(X) = \sqrt{V(X)}$ —— 単位が $X$ とそろうのは標準偏差の方
- 二項分布：$E(X) = np$、$V(X) = np(1 - p)$ —— $n$ と $p$ の対応を取り違えない

### 共分散と相関係数

- $\mathrm{Cov}(X, Y) = E(XY) - E(X)E(Y)$ —— 同向・反向の連動の程度
- 相関係数 $r = \dfrac{\mathrm{Cov}(X, Y)}{\sigma(X)\sigma(Y)}$、$-1 \le r \le 1$ —— 1 に近いほど強い正の相関
- 独立 $\Rightarrow$ 共分散 0（逆は成り立たない）—— 無相関でも独立とは限らない

### 確率変数の変換と和

- $Y = aX + b$：$E(Y) = aE(X) + b$、$V(Y) = a^2 V(X)$、$\sigma(Y) = |a|\,\sigma(X)$ —— 平移 $b$ は分散に影響しない
- $E(X + Y) = E(X) + E(Y)$ —— 期待値の和は独立でなくても常に成立
- $X, Y$ 独立のとき $V(X + Y) = V(X) + V(Y)$、$V(X - Y)$ も和 —— 差でも分散は加える
- 標本平均：$E(\bar{X}) = \mu$、$V(\bar{X}) = \dfrac{\sigma^2}{n}$ —— $n$ が大きいほど平均は安定する

## 解法パターン

- **分布表を作る型**：試行の結果を確率変数に置き換える → 値を列挙して確率を対応させ、総和 1 を検算してから $E$・$V$ を計算する
- **二項分布の判定型**：回数を数える問題 → 独立性と $p$ 一定を確認できたら公式 $E = np$、$V = np(1 - p)$ に直行する
- **変換の型**：$Y = aX + b$ の $E$・$V$・$\sigma$ を求める → 分布を作り直さず変換公式で処理し、分散は $a^2$ 倍を忘れない
- **和の分散型**：$X \pm Y$ の分散を求める → 先に独立かどうかを確認し、独立なら差でも足す

## 考前注意

- [ ] 確率の総和が1になるかの検算を省く（列完分布后先验概率总和是否为 1）
- [ ] $E(X^2)$ と $\{E(X)\}^2$ の混同（平方的期待值与期待值的平方搞混）
- [ ] $V(aX + b)$ で $a^2$ でなく $a$ を掛ける（变换后分散乘的是 a 的平方）
- [ ] 独立でない変数の和に分散の加法を適用する（不独立时乱用分散加法）
- [ ] 二項分布の適用条件（独立・$p$ 一定）を確認しない
