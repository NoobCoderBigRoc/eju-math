# 確率分布と統計的な推測要点总结

考前确认三件事：分布表的验算（確率总和为 1）、$E$・$V$・$\sigma$ 各公式的选用、处理变换与和时先判定「是否独立」的习惯。

## 公式・定理清单

### 確率変数と確率分布

- 確率分布：$\displaystyle \sum_i p_i = 1$、$0 \le p_i \le 1$ —— 列完分布先验算总和
- 区间概率 $P(a \le X \le b)$ 是相应 $x_i$ 的概率之和 —— 区间外的值不计入
- 二項分布 $B(n, p)$：$P(X = k) = {}_n\mathrm{C}_k\, p^k (1 - p)^{n - k}$ —— 适用条件是「各次试验独立」「$p$ 每次恒定」
- 連続型：$P(a \le X \le b) = \int_a^b f(x)\, dx$、$P(X = a) = 0$ —— 概率由密度函数的面积给出

### 期待値・分散・標準偏差

- $E(X) = \sum x_i p_i$ —— 以概率为权重的平均
- $V(X) = E(X^2) - \{E(X)\}^2$ —— 计算用这个形式最快；$E(X^2)$ 是「平方的期待值」，不是「期待值的平方」
- $\sigma(X) = \sqrt{V(X)}$ —— 与 $X$ 单位一致的是標準偏差
- 二項分布：$E(X) = np$、$V(X) = np(1 - p)$ —— 不要把 $n$ 与 $p$ 的对应弄反

### 共分散と相関係数

- $\mathrm{Cov}(X, Y) = E(XY) - E(X)E(Y)$ —— 衡量同向・反向联动的程度
- 相関係数 $r = \dfrac{\mathrm{Cov}(X, Y)}{\sigma(X)\sigma(Y)}$、$-1 \le r \le 1$ —— 越接近 1 正相关越强
- 独立 $\Rightarrow$ 共分散为 0（逆命题不成立）—— 不相关不等于独立

### 確率変数の変換と和

- $Y = aX + b$：$E(Y) = aE(X) + b$、$V(Y) = a^2 V(X)$、$\sigma(Y) = |a|\,\sigma(X)$ —— 平移量 $b$ 不影响分散
- $E(X + Y) = E(X) + E(Y)$ —— 期待值的和不要求独立，恒成立
- $X, Y$ 独立时 $V(X + Y) = V(X) + V(Y)$，$V(X - Y)$ 也取和 —— 作差时分散仍然相加
- 標本平均：$E(\bar{X}) = \mu$、$V(\bar{X}) = \dfrac{\sigma^2}{n}$ —— $n$ 越大，平均越稳定

## 解法パターン

- **列分布表型**：把试验结果换成確率変数 → 列出取值并配上概率，先验算总和为 1，再算 $E$・$V$
- **二項分布判定型**：数次数的问题 → 确认独立且 $p$ 恒定后，直接套公式 $E = np$、$V = np(1 - p)$
- **变换型**：求 $Y = aX + b$ 的 $E$・$V$・$\sigma$ → 不重列分布、直接用变换公式，分散乘 $a^2$ 别忘
- **和的分散型**：求 $X \pm Y$ 的分散 → 先确认是否独立，独立时作差也相加

## 考前注意

- [ ] 列完分布不验算概率总和是否为 1
- [ ] 混淆 $E(X^2)$ 与 $\{E(X)\}^2$（平方的期待值与期待值的平方）
- [ ] $V(aX + b)$ 误乘 $a$ 而不是 $a^2$（变换后分散乘的是 $a$ 的平方）
- [ ] 不独立时对变量之和乱用分散加法
- [ ] 不确认二項分布的适用条件（独立、$p$ 恒定）
