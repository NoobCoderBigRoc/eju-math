## 1. 複素数平面と極形式

複素数 $z = a + bi$ を点 $(a, b)$ に対応させる平面を複素数平面（ガウス平面）という。極形式は

$$
z = r(\cos\theta + i\sin\theta), \qquad r = |z| = \sqrt{a^2 + b^2}, \quad \theta = \arg z
$$

共役複素数 $\overline{z} = a - bi$ について、$z\overline{z} = |z|^2$、実軸対称の点が $\overline{z}$ である。

**積と商の幾何的意味**：$z_1 z_2$ は「絶対値は積、偏角は和」。複素数を掛けることは、原点中心の回転と拡大・縮小の合成である。特に $i$ を掛けると原点中心に $90^\circ$ 回転する。

## 2. ド・モアブルの定理

$$
(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta
$$

$n$ 乗根の計算と、回転を繰り返す問題の基礎になる。

## 3. 複素数と図形

- $|z - z_0| = r$：$z_0$ を中心とする半径 $r$ の円
- $|z - z_1| = |z - z_2|$：$z_1, z_2$ を結ぶ線分の垂直二等分線
- 2 点 $z_1, z_2$ を結ぶ線分を $m : n$ に内分する点：$\dfrac{n z_1 + m z_2}{m + n}$（ベクトルと同じ形）
- 点 $z$ を原点中心に角 $\theta$ だけ回転した点：$z(\cos\theta + i\sin\theta)$

## 例題（演習）

??? example "例題 1：回転"
    点 $P$ に対応する複素数を $z = 1 + i$ とする。$P$ を原点のまわりに $90^\circ$ 回転した点に対応する複素数を求めよ。

    **考え方**：$90^\circ$ 回転は $i$ を掛けることに対応する。

    **解答**：$iz = i(1 + i) = -1 + i$。

    **答え**：$-1 + i$

??? example "例題 2：ド・モアブルの定理"
    $(1 + i)^8$ を計算せよ。

    **考え方**：極形式に直す。$1 + i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$。

    **解答**：$(1 + i)^8 = (\sqrt{2})^8 \left(\cos 2\pi + i\sin 2\pi\right) = 16 \times 1 = 16$。

    **答え**：$16$

??? example "例題 3：軌跡"
    複素数 $z$ が $|z - 1| = |z + 1|$ を満たすとき、$z$ の表す点全体はどのような図形か。

    **考え方**：$|z - z_1| = |z - z_2|$ は 2 点 $z_1, z_2$ からの距離が等しい点の軌跡。

    **解答**：点 $1$ と点 $-1$ の垂直二等分線、すなわち虚軸（$x = 0$）。

    **答え**：虚軸

## よくあるミス

- [ ] 偏角の主値の範囲を取り違える（問題文の指定を確認する）
- [ ] 回転の方向（正の角は反時計回り）を取り違える
- [ ] $|z_1 + z_2| = |z_1| + |z_2|$ と即断する（三角不等式であり、等号は同方向のときだけ）
