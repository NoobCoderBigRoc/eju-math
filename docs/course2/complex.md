## 1. 複素数平面と極形式

把复数 $z = a + bi$ 对应到点 $(a, b)$ 的平面称为複素数平面（ガウス平面，高斯平面）。極形式（极形式）是

$$
z = r(\cos\theta + i\sin\theta), \qquad r = |z| = \sqrt{a^2 + b^2}, \quad \theta = \arg z
$$

关于共轭复数 $\overline{z} = a - bi$：$z\overline{z} = |z|^2$，且 $\overline{z}$ 是 $z$ 关于实轴的对称点。

**積と商の幾何的意味**（乘除的几何意义）：$z_1 z_2$ 是「模长相乘、辐角相加」。乘一个复数 = 以原点为中心的旋转与伸缩的合成；特别地，乘 $i$ 就是绕原点旋转 $90^\circ$——旋转类问题优先想到复数乘法。

## 2. ド・モアブルの定理

$$
(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta
$$

这是求 $n$ 次幂与 $n$ 次方根、以及反复旋转问题的基础。先把复数化成极形式再套定理，不要直接展开硬算。

## 3. 複素数と図形

- $|z - z_0| = r$：以 $z_0$ 为中心、半径 $r$ 的圆
- $|z - z_1| = |z - z_2|$：连接 $z_1, z_2$ 的线段的垂直二等分线
- 把线段 $z_1 z_2$ 按 $m : n$ 内分的点：$\dfrac{n z_1 + m z_2}{m + n}$（与向量同形）
- 点 $z$ 绕原点旋转角 $\theta$ 后的点：$z(\cos\theta + i\sin\theta)$

## 例题（演习）

??? example "例题 1：回転"
    点 $P$ に対応する複素数を $z = 1 + i$ とする。$P$ を原点のまわりに $90^\circ$ 回転した点に対応する複素数を求めよ。

    **思路**：旋转 $90^\circ$ 对应乘以 $i$。

    **解答**：$iz = i(1 + i) = -1 + i$。

    **答案**：$-1 + i$

??? example "例题 2：ド・モアブルの定理"
    $(1 + i)^8$ を計算せよ。

    **思路**：先化极形式。$1 + i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$。

    **解答**：$(1 + i)^8 = (\sqrt{2})^8 \left(\cos 2\pi + i\sin 2\pi\right) = 16 \times 1 = 16$。

    **答案**：$16$

??? example "例题 3：軌跡"
    複素数 $z$ が $|z - 1| = |z + 1|$ を満たすとき、$z$ の表す点全体はどのような図形か。

    **思路**：$|z - z_1| = |z - z_2|$ 是到两点距离相等的点的轨迹。

    **解答**：点 $1$ 与点 $-1$ 的垂直二等分线，即虚轴（$x = 0$）。

    **答案**：虚軸

## 易错点

- [ ] 辐角主值的范围取错（看清题目指定的范围）
- [ ] 旋转方向取反（正角是逆时针）
- [ ] 直接断定 $|z_1 + z_2| = |z_1| + |z_2|$（这是三角不等式，等号仅在同方向时成立）
