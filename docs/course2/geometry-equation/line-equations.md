# 直線の方程式

## 直線の表し方

- 形式：$y = mx + n$（斜截式、傾き $m$・切片 $n$）、$ax + by + c = 0$（一般式）
- 点斜式：点 $(x_1, y_1)$ を通り傾き $m$ の直線は $y - y_1 = m(x - x_1)$
- 2 点式：2 点 $(x_1, y_1)$、$(x_2, y_2)$ を通る直線は $(y_2 - y_1)(x - x_1) = (x_2 - x_1)(y - y_1)$（傾きが定義できない鉛直線 $x = x_1$ の場合もこの形なら扱える）
- 切片式：$x$ 切片 $a$、$y$ 切片 $b$（ともに $0$ でない）の直線は $\dfrac{x}{a} + \dfrac{y}{b} = 1$
- 特殊な直線：鉛直線 $x = p$（傾きなし）、水平線 $y = q$（傾き $0$）。傾きを使う式では表せないので、最初に切り分ける。

一般形 $ax + by + c = 0$ は全ての直線を表せる万能形で、法線ベクトル $(a, b)$ が直線に垂直、方向ベクトルは $(b, -a)$（または $(-b, a)$）と読める。

## 平行・垂直の判定

- 傾きで判定：平行 ⇔ 斜率相等；垂直 ⇔ 斜率之积 $= -1$（直线斜率不存在时单独处理）
- 一般形で判定：$a_1 x + b_1 y + c_1 = 0$ と $a_2 x + b_2 y + c_2 = 0$ について、平行 ⇔ $a_1 b_2 - a_2 b_1 = 0$、垂直 ⇔ $a_1 a_2 + b_1 b_2 = 0$（法線ベクトルの内積）。鉛直線を含む場合でもそのまま使えるのが一般形判定の利点。
- 平行と一致の区別：係数が比例していても、定数項まで同じ比例なら 2 直線は一致（重なる）し、比例でなければ平行。判定では「係数の比例」と「定数項の比例」を分けて確認する。

## 定点と直線の束

パラメータ $k$ を含む直線の方程式 $f(x, y) + k\, g(x, y) = 0$ は、$k$ の値によらず 2 直線 $f = 0$、$g = 0$ の交点を通る（直線束）。応用二つ：

- 2 直線の交点を通る直線は、交点の座標を求めなくても $f + k g = 0$ の形で置ける（あと 1 条件で $k$ を決める）
- 逆に、パラメータを含む式が「$k$ によらず常に通る定点」を聞かれたら、$k$ の係数部分と残りの部分を**両方 0** にする連立方程式を解く

## 点の対称移動

点 $P$ の直線 $\ell$ に関する対称点 $P'$ は、① 線分 $PP'$ の中点が $\ell$ 上にある、② 直線 $PP'$ が $\ell$ と垂直、の 2 条件で求める。中点の条件と傾き（または法線ベクトル）の条件を連立させるのが定型手順で、[点と直線の距離](point-line-distance.md) と並んで一般形の係数を読む練習になる。

## 易错点

- [ ] 垂直条件を「傾きの積 $= -1$」で済ませ、垂直な直線（$x = $ 定数）を落とす（注意斜率不存在的竖直直线；鉛直線が絡むなら一般形の判定 $a_1 a_2 + b_1 b_2 = 0$ を使う）
- [ ] 切片式 $\dfrac{x}{a} + \dfrac{y}{b} = 1$ を原点を通る直線や軸に平行な直線に使う（截距式要求两个截距都存在且非零，原点を通る直線には使えない）
- [ ] 平行条件と一致条件を取り違える（系数成比例只是平行或重合，还要再看常数项是否同比例）
