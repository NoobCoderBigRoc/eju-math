# 点の座標

- 两点间距离：$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
- 内分点：分 $AB$ 为 $m : n$ 的点 $\left(\dfrac{n x_A + m x_B}{m + n}, \dfrac{n y_A + m y_B}{m + n}\right)$（分点坐标是**远端权重在前**:别把 $m, n$ 放反）
- 重心：$\left(\dfrac{x_A + x_B + x_C}{3}, \dfrac{y_A + y_B + y_C}{3}\right)$

## 易错点

- [ ] 内分点の公式で $m$、$n$ の位置を取り違える（内分点权重与端点是"交叉对应"）
