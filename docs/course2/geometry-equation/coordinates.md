# 点の座標

## 距離と分点

- 两点间距离：$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
- 内分点：分 $AB$ 为 $m : n$ 的点 $\left(\dfrac{n x_A + m x_B}{m + n}, \dfrac{n y_A + m y_B}{m + n}\right)$（分点坐标是**远端权重在前**：别把 $m, n$ 放反）。内分点は「$B$ からの距離 $n$ の側にある $A$ の座標に重み $n$」という加重平均で、座標版も [位置ベクトル](../vector/position-vectors.md) の分点公式も同形。
- 外分点：分 $AB$ 为 $m : n$（$m \ne n$）的点 $\left(\dfrac{-n x_A + m x_B}{m - n}, \dfrac{-n y_A + m y_B}{m - n}\right)$。内分公式の $n$ を $-n$ に置き換えた形で、符号と分母 $m - n$ が変わる。$m = n$ のとき外分点は存在しない。
- 中点：内分 $1 : 1$ の場合で $\left(\dfrac{x_A + x_B}{2}, \dfrac{y_A + y_B}{2}\right)$。

## 重心

- 重心：$\left(\dfrac{x_A + x_B + x_C}{3}, \dfrac{y_A + y_B + y_C}{3}\right)$、3 頂点の座標の平均。中线（頂点と対辺の中点を結ぶ線）が 1 点で交わり、その点が中線を $2 : 1$ に内分することの帰結で、逆に重心の座標から未知の頂点座標を逆算する問題もこの平均の形で処理できる。

## 距離の計算のコツ

- 根号を避けたい場面（距離の大小比較、等しい距離の条件）では、2 乗した $AB^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$ のまま処理する。$PA = PB$ 型の軌跡条件も 2 乗同士で引くと 1 次式に落ちる（[軌跡と方程式](locus.md)）。
- 3 点が一直線上にある ⇔ 最も長い辺の長さが他の 2 辺の長さの和に等しい。距離公式で 3 辺を出して判定する。

## 座標による証明の置き方

図形の性質を座標で証明するときは、計算が楽になるよう座標軸を置くのが第一歩：頂点を原点に、1 辺を $x$ 軸上に置く；対称な図形（二等辺三角形・正方形など）は対称軸を $y$ 軸に合わせると座標が $\pm$ の対になり、式が対称で短くなる。置き方で計算量が大きく変わるので、計算に入る前に 30 秒使う価値がある。

## 易错点

- [ ] 内分点の公式で $m$、$n$ の位置を取り違える（内分点权重与端点是"交叉对应"，用中点或某一端点的极端情形代入验算最稳）
- [ ] 外分点の分母と符号（分母は $m - n$、$x_A$ 側の係数は $-n$。内分公式の流用ミスが多い）
- [ ] 重心は 3 頂点の「平均」であって中点の繰り返しではない（先に一辺の中点を求めてから $2:1$ に内分しても同じ結果になるが、平均の形が速くて確実）
