# 軌跡と方程式

求轨迹的标准流程：设动点 $P(x, y)$ → 把条件翻译成 $x, y$ 的等式 → 整理。最后要检查**范围限制**：条件中有分母、长度、参数范围时，轨迹可能只是曲线的一部分（除外点の確認）。

**演習：軌跡**

2点 $A(-1, 0)$、$B(1, 0)$ に対して $PA = PB$ を満たす点 $P$ の軌跡を求めよ。

??? example "思路・解答"
    **答案**

    $y$ 軸（直線 $x = 0$）

    **思路**

    设 $P(x, y)$，由 $PA^2 = PB^2$ 列式，平方项会消掉。

    **解答**

    $$(x + 1)^2 + y^2 = (x - 1)^2 + y^2 \quad\Longrightarrow\quad 4x = 0 \quad\Longrightarrow\quad x = 0$$

## 易错点

- [ ] 軌跡の除外点（軌跡から外れる点）を確認しない（求轨迹后未检查剔除点）
