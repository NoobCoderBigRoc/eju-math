# 不等式の表す領域

不等式が表す領域とは、その不等式を満たす点 $(x, y)$ 全体の集合。境界線（等号の場合の方程式の図形）によって平面がいくつかの部分に分かれ、不等式はそのうちの一つ（または境界を含むもの）を選び出す、と理解する。

## 基本形

- 直线 $y = mx + n$：不等式 $y > mx + n$ 是直线上方、$<$ 是下方。一般式 $ax + by + c > 0$ では、境界上にないテスト点（原点が境界上になければ $(0, 0)$ が便利）を代入し、符号が成り立つ側が求める領域。
- 圆 $(x - a)^2 + (y - b)^2 < r^2$ 是圆内、$>$ 是圆外。中心をテスト点にすると判定が速い（中心では左辺 $0 < r^2$ で内側と分かる）。
- 放物線 $y > x^2$ は放物線の内側（焦点を含む側、上向きの「お椀」の中）、$y < x^2$ はその外側。$x$ の 2 次式を $y$ と比べる形は、境界を $y = f(x)$ とみて「グラフの上側・下側」で判定する。

## 連立不等式の領域の求め方

1. 不等式ごとに境界線を描く（境界含む＝実線、含まない＝破線）
2. 各不等式について、テスト点の代入でどちらの側かを確定する
3. 全ての不等式を同時に満たす共通部分が求める領域

図示の問題では、領域に斜線を入れる・頂点を明示するなど、答えの範囲が読み取れる形で仕上げる。

## 領域と最大・最小（線形計画法）

多角形の領域（連立 1 次不等式で囲まれた部分）の上で、1 次式 $ax + by$ の最大値・最小値を考えるのが線形計画法の基本形。結論：**最大値・最小値は必ず領域の頂点（境界線同士の交点）のどれかで取る**。手順は：

1. 領域を図示し、頂点を全て求める（境界線の交点を連立方程式で解く）
2. 各頂点での $ax + by$ の値を計算し、最大・最小を選ぶ

等高線 $ax + by = k$ が領域を最後に離れる点が最適点、という見方をすると、頂点だけ調べればよい理由が納得できる。領域が有界でない場合は最大値・最小値が存在しないこともあるので、図示の段階で有界かどうかを確認する。

## 易错点

- [ ] 領域図示で境界の含む/含まない（実線/破線）を取り違える（边界含否与实线/虚线搞反：$\le$、$\ge$ は実線、$<$、$>$ は破線）
- [ ] テスト点に境界線上の点を選んでしまう（テスト点は境界上にない点を選ぶ。原点が境界上にある場合は $(1, 0)$ など別の点を使う）
- [ ] 線形計画法で頂点以外の点（辺の途中）を調べようとする（線形の目的関数の最大最小は顶点的みで十分。逆に領域が有界でないのに最大値ありと答えるミスにも注意）
