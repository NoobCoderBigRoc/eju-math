# 点と直線の距離

点 $(x_0, y_0)$ 到直线 $ax + by + c = 0$ 的距离：

$$d = \frac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}$$

## 公式の意味と導出の要点

直線 $ax + by + c = 0$ の法線ベクトルは $(a, b)$。距離とは、点から直線へ下ろした垂線の長さ、つまり点と直線上の任意の点 $P_1(x_1, y_1)$ を結ぶベクトル $\overrightarrow{P_1P_0}$ の、法線方向への射影の長さに等しい：

$$d = \frac{\left|a(x_0 - x_1) + b(y_0 - y_1)\right|}{\sqrt{a^2 + b^2}} = \frac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}$$

（$ax_1 + by_1 = -c$ を使って整理した。）分母の $\sqrt{a^2 + b^2}$ は法線ベクトルの長さでの割り算＝単位法線ベクトルへの射影、分子は「点の座標を直線の左辺に代入した値」の絶対値、と読むと忘れにくい。符号付きの値 $\dfrac{a x_0 + b y_0 + c}{\sqrt{a^2 + b^2}}$（絶対値を外したもの）が正か負かで、点が直線のどちら側にあるかも分かる。

## 使う手順

1. 直線を一般形 $ax + by + c = 0$ に直す（$y = mx + n$ の形のままでは使えない。移項して $mx - y + n = 0$ の形にする）
2. 点の座標を $a x_0 + b y_0 + c$ に代入し、絶対値を取る
3. $\sqrt{a^2 + b^2}$ で割る

## 典型的な使用場面

- **円と直線の位置関係**：円の中心から直線までの距離 $d$ と半径 $r$ を比較する（$d < r$ 交わる、$d = r$ 接する、$d > r$ 離れる）。弦の長さは $2\sqrt{r^2 - d^2}$ で出る（[円と直線の関係](circle-line.md)）。
- **三角形の面積**：底辺を直線とみて、対頂点からの距離を高さとして使う（[点の座標](coordinates.md) の距離公式と組み合わせる）。
- **平行線間の距離**：$ax + by + c_1 = 0$ と $ax + by + c_2 = 0$（係数 $a$、$b$ をそろえた形）では $d = \dfrac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$。一方の直線上の点を他方への距離公式に入れたもの。
- **角の二等分線**：2 直線からの距離が等しい点の軌跡として、$\dfrac{|a_1 x + b_1 y + c_1|}{\sqrt{a_1^2 + b_1^2}} = \dfrac{|a_2 x + b_2 y + c_2|}{\sqrt{a_2^2 + b_2^2}}$ と置く（絶対値を外すとき $\pm$ の 2 本が出る）。

## 易错点

- [ ] $y = mx + n$ の形のまま距離の公式に代入する（公式は一般形専用。必ず $ax + by + c = 0$ に移項してから $a$、$b$、$c$ を読む）
- [ ] 分子の絶対値を外したまま答える（距離は非負。符号付きの値は「どちら側か」を見るためのもので、答えには絶対値が必要）
- [ ] 平行線間の距離で係数 $a$、$b$ をそろえずに $c$ の差を取る（$2x + 2y + 1 = 0$ と $x + y + 3 = 0$ のように係数が比例しているだけでは、そのまま $c$ を引けない）
