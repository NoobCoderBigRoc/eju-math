# 円の方程式

- 标准式：$(x - a)^2 + (y - b)^2 = r^2$，圆心 $(a, b)$ 半径 $r$
- 一般式：$x^2 + y^2 + lx + my + n = 0$（平方完成得到标准式，确认半径平方 $> 0$）

## 一般式から標準式へ

一般式から中心・半径を読み取る手順は平方完成（平方完成）で統一できる：

1. $x$ の項と $y$ の項をそれぞれまとめる：$(x^2 + lx) + (y^2 + my) = -n$
2. それぞれに $\left(\dfrac{l}{2}\right)^2$、$\left(\dfrac{m}{2}\right)^2$ を両辺に加えて平方完成する：

$$\left(x + \frac{l}{2}\right)^2 + \left(y + \frac{m}{2}\right)^2 = \frac{l^2 + m^2 - 4n}{4}$$

3. 読み取る：中心 $\left(-\dfrac{l}{2}, -\dfrac{m}{2}\right)$、半径の 2 乗 $\dfrac{l^2 + m^2 - 4n}{4}$

右辺の値で図形の種類が決まる：$> 0$ のとき円（半径 $\dfrac{\sqrt{l^2 + m^2 - 4n}}{2}$）；$= 0$ のとき 1 点 $\left(-\dfrac{l}{2}, -\dfrac{m}{2}\right)$ のみ；$< 0$ のとき図形なし（点は存在しない）。一般式が与えられたら、まずこの判定をするのが定石。

## 円の決め方の使い分け

| 与えられる条件 | 使う形 |
| --- | --- |
| 中心と半径 | 标准式に直接代入 |
| 直径の両端 2 点 $A(x_1, y_1)$、$B(x_2, y_2)$ | $(x - x_1)(x - x_2) + (y - y_1)(y - y_2) = 0$（円周角が直角になることの言い換え） |
| 3 点を通る | 一般式に 3 点を代入し、$l$、$m$、$n$ の連立方程式を解く |
| 中心が特定の直線上にある + 2 点を通る | 中心を $(a, \text{直線の式})$ と置いて標準式に代入 |

直径の両端の形は、展開すると $x^2 + y^2$ の係数がそろった一般式になり、中心が 2 点の中点であることも読み取れる。

## 一般式になるための条件

$x^2 + y^2 + lx + my + n = 0$ が円を表すには、① $x^2$ と $y^2$ の係数が等しい（一般式では 1 にそろえてある）、② $xy$ の項がない、③ $l^2 + m^2 - 4n > 0$、の三つが必要。係数に文字が含まれる問題では、この条件から文字の範囲を決める形で出題される。

## 易错点

- [ ] 一般式から中心・半径を出すとき平方完成の定数移項ミス（平方完成时常数移项出错，特に $\left(\dfrac{l}{2}\right)^2$ を片辺にだけ加えるミス）
- [ ] 中心の座標の符号（中心は $\left(-\dfrac{l}{2}, -\dfrac{m}{2}\right)$ で、$-\dfrac{l}{2}$ のマイナスを落とす）
- [ ] 半径の 2 乗が $0$ 以下になる場合を円として扱う（$=0$ は点、$<0$ は図形なし。一般式が円を表す条件の確認を最初にする）
