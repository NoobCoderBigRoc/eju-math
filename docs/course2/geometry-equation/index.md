# 図形と方程式简介（数学II）

几何问题代数化：坐标与直线、圆、轨迹与区域。是ベクトル与式と曲線的共同前置。

本项目的具体内容都在下面的细目页中（左侧导航点开「9. 図形と方程式」即可逐层展开）。

## 在 EJU 中的位置

本项目是解析几何的入口，分量实在，题型气质以计算为主线：「设坐标 → 列方程 → 代数处理」这一套流程贯穿全项目，軌跡与領域部分则带有明显的读图、作图成分。
它与ベクトル项目是同一批图形问题的两种语言（坐标版与向量版），互为表里；处理二次曲线的式と曲線项目也以本项目的圆与軌跡的方法为前置。
