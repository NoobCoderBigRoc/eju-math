# 図形と方程式要点总结

考前确认本页：分点・直線・円の公式群、点と直線の距離の使いどころ、軌跡の標準手順と領域の読み方。

## 公式・定理清单

### 点と直線

- 2 点間の距離：$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ —— 大小比較だけなら 2 乗のままでも処理できる
- 内分点：$AB$ を $m : n$ に分ける点は $\left(\dfrac{n x_A + m x_B}{m + n}, \dfrac{n y_A + m y_B}{m + n}\right)$ —— 权重は端点と交叉対応する
- 外分点：$\left(\dfrac{-n x_A + m x_B}{m - n}, \dfrac{-n y_A + m y_B}{m - n}\right)$ —— 内分の $n$ を $-n$ に置き換えた形で、$m = n$ のとき存在しない
- 重心：$\left(\dfrac{x_A + x_B + x_C}{3}, \dfrac{y_A + y_B + y_C}{3}\right)$ —— 3 頂点座標の平均
- 直線の式：点斜式 $y - y_1 = m(x - x_1)$、切片式 $\dfrac{x}{a} + \dfrac{y}{b} = 1$、一般式 $ax + by + c = 0$ —— 一般式の $(a, b)$ は法線ベクトル
- 平行・垂直（一般形）：平行 $\iff a_1 b_2 - a_2 b_1 = 0$、垂直 $\iff a_1 a_2 + b_1 b_2 = 0$ —— 鉛直線が絡んでもそのまま使える
- 点と直線の距離：$d = \dfrac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}$ —— 直線を一般形に直してから使う
- 平行線間の距離：係数をそろえた $ax + by + c_1 = 0$、$ax + by + c_2 = 0$ で $d = \dfrac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$

### 円

- 円の標準式：$(x - a)^2 + (y - b)^2 = r^2$ —— 中心 $(a, b)$、半径 $r$
- 円の一般式：$x^2 + y^2 + lx + my + n = 0$ の中心は $\left(-\dfrac{l}{2}, -\dfrac{m}{2}\right)$、半径の 2 乗は $\dfrac{l^2 + m^2 - 4n}{4}$ —— 正なら円、$0$ なら 1 点、負なら図形なし
- 直径の両端 $A$、$B$ から：$(x - x_1)(x - x_2) + (y - y_1)(y - y_2) = 0$ —— 円周角が直角であることの言い換え
- 円と直線の位置関係：中心からの距離 $d$ で、$d < r$ 交わる、$d = r$ 接する、$d > r$ 離れる —— 弦の長さは $2\sqrt{r^2 - d^2}$
- 円上の点 $(x_1, y_1)$ における接線（中心が原点の円）：$x_1 x + y_1 y = r^2$
- 公共弦：2 つの円の方程式の差を取ると、共有点を通る直線の方程式になる

### 軌跡と領域

- 軌跡の求め方：動点 $P(x, y)$ を置き、条件を $x, y$ の等式に翻訳して整理する —— 最後に除外点の有無を確認する
- 不等式の領域：境界線を引き、境界上にないテスト点を代入して成り立つ側を選ぶ —— 境界を含むかで実線・破線を描き分ける
- 線形計画法：多角形領域上の 1 次式の最大・最小は必ず頂点のどれかで取る

## 解法パターン

- **円の決定**：3 点を通る → 一般式に代入して $l, m, n$ の連立方程式；直径の両端 → 直径の形；中心が直線上＋2 点 → 中心を文字で置いて標準式
- **距離が絡む条件**：円と直線の位置関係・弦長・三角形の面積は → 円の中心や対頂点から直線への距離に帰着させる
- **定点を通る直線**：パラメータ $k$ を含む直線群は → $f + k g = 0$ と置き、$k$ の係数と残りを両方 0 にする連立で定点を出す
- **軌跡**：$PA = PB$ 型の距離条件は → 両辺を 2 乗して引くと 1 次式に落ちる；求めた後は除外点を点検する
- **領域の最大・最小**：連立不等式の領域で 1 次式の最大値を聞かれたら → 頂点を全部求めて値を比べるだけ

## 考前注意

- [ ] 内分点の公式で $m$、$n$ の位置を取り違えない（中点や端点の極端な場合で検算する）
- [ ] 一般式から読む中心は $\left(-\dfrac{l}{2}, -\dfrac{m}{2}\right)$ で、マイナスを落とさない
- [ ] 点と直線の距離は $ax + by + c = 0$ の形に直してから代入する
- [ ] 垂直の判定を傾きの積 $= -1$ だけで済ませ、鉛直線の場合を落とさない
- [ ] 軌跡は方程式を出すだけで終わらず、除外点の確認まで行う
