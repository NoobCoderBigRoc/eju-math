# 図形と方程式要点总结

考前确认本页：分点・直線・円的公式群、点と直線の距離的用法、軌跡的标准步骤与領域的读法。

## 公式・定理清单

### 点と直線

- 2 点間の距離：$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ —— 只比较大小时可以保持平方形式处理
- 内分点：分 $AB$ 为 $m : n$ 的点是 $\left(\dfrac{n x_A + m x_B}{m + n}, \dfrac{n y_A + m y_B}{m + n}\right)$ —— 权重与端点交叉对应
- 外分点：$\left(\dfrac{-n x_A + m x_B}{m - n}, \dfrac{-n y_A + m y_B}{m - n}\right)$ —— 是把内分公式中的 $n$ 换成 $-n$ 的形式；$m = n$ 时不存在
- 重心：$\left(\dfrac{x_A + x_B + x_C}{3}, \dfrac{y_A + y_B + y_C}{3}\right)$ —— 三个顶点坐标的平均
- 直線の式：点斜式 $y - y_1 = m(x - x_1)$、切片式 $\dfrac{x}{a} + \dfrac{y}{b} = 1$、一般式 $ax + by + c = 0$ —— 一般式中的 $(a, b)$ 是法線ベクトル
- 平行・垂直（一般形）：平行 $\iff a_1 b_2 - a_2 b_1 = 0$、垂直 $\iff a_1 a_2 + b_1 b_2 = 0$ —— 涉及鉛直線时也能直接用
- 点と直線の距離：$d = \dfrac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}$ —— 先把直線化成一般形再用
- 平行線間の距離：两直線系数对齐为 $ax + by + c_1 = 0$、$ax + by + c_2 = 0$ 时，$d = \dfrac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$

### 円

- 円の標準式：$(x - a)^2 + (y - b)^2 = r^2$ —— 中心 $(a, b)$、半径 $r$
- 円の一般式：$x^2 + y^2 + lx + my + n = 0$ 的中心是 $\left(-\dfrac{l}{2}, -\dfrac{m}{2}\right)$，半径的平方是 $\dfrac{l^2 + m^2 - 4n}{4}$ —— 该值为正时是円、为 $0$ 时是一个点、为负时无图形
- 直径的両端 $A$、$B$：$(x - x_1)(x - x_2) + (y - y_1)(y - y_2) = 0$ —— 是「直径所对的円周角为直角」的改写
- 円と直線の位置関係：按中心到直線的距离 $d$ 判断，$d < r$ 相交、$d = r$ 相切、$d > r$ 相离 —— 弦长为 $2\sqrt{r^2 - d^2}$
- 円上点 $(x_1, y_1)$ 处的接線（中心为原点的円）：$x_1 x + y_1 y = r^2$
- 公共弦：两円的方程式相减，得到过两円公共点的直線方程式

### 軌跡と領域

- 軌跡の求め方：设动点 $P(x, y)$，把条件翻译成关于 $x, y$ 的等式并整理 —— 最后确认有无除外点
- 不等式の領域：画出境界線，代入不在境界上的测试点，取使不等式成立的一侧 —— 境界是否包含用实线、虚线区分
- 線形計画法：多边形領域上一次式的最大・最小，必在某个頂点处取得

## 解法パターン

- **确定円的方程式**：过 3 点 → 代入一般式解 $l, m, n$ 的連立方程式；已知直径両端 → 用直径形式；中心在某直線上且过 2 点 → 把中心设为未知量用標準式
- **涉及距离的条件**：円と直線の位置関係・弦長・三角形の面積 → 归结为円心或頂点到直線的距离
- **过定点の直線**：含参数 $k$ 的直線族 → 写成 $f + k g = 0$，令 $k$ 的系数与剩余部分同时为 $0$，联立求定点
- **軌跡**：$PA = PB$ 型距离条件 → 两边平方后相减，降为一次式；求出后检查除外点
- **領域上的最大・最小**：在連立不等式的領域上问一次式的最大值 → 求出全部頂点逐一比较

## 考前注意

- [ ] 内分点公式中不要把 $m$、$n$ 的位置放反（用中点或端点的极端情形验算）
- [ ] 从一般式读出的中心是 $\left(-\dfrac{l}{2}, -\dfrac{m}{2}\right)$，不要漏掉负号
- [ ] 点と直線の距離要先化成 $ax + by + c = 0$ 的形式再代入
- [ ] 垂直判定不要只用斜率之积 $= -1$，会漏掉鉛直線的情形
- [ ] 軌跡不能只写出方程式，要检查除外点
