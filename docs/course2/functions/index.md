# 関数简介（数学III）

分数関数・無理関数与逆関数・合成関数，是进入数学III（極限・微積分）的门面。

本项目的具体内容都在下面的细目页中（左侧导航点开「17. 関数」即可逐层展开）。

## 在 EJU 中的位置

本项目本身篇幅不大，但地位是数学III（極限・微積分）的门面，不可跳过：分数関数・無理関数与逆関数・合成関数的扱いに慣れることが前提条件。
题型气质以读图为中心——定義域・漸近線・グラフの形を先に押さえる進め方は、そのまま極限项目（漸近線と極限の読み合い）与微分法项目（グラフの概形）の作業手順に引き継がれる。
