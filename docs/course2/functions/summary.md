# 関数要点总结

考前确认本页：分数関数・無理関数的定義域与漸近線读法、逆関数与合成関数的处理基本步骤。
作为数学 III 的入口项目，这里考的是先抓住定義域与漸近線的推进方式。

## 公式・定理清单

### 分数関数と無理関数

- 分数関数の標準形：$y = \dfrac{k}{x - p} + q$ 是 $y = \dfrac{k}{x}$ 平移得到的双曲線 —— 漸近線是 $x = p$ 与 $y = q$、定義域 $x \ne p$、値域 $y \ne q$
- 一般分数関数の漸近線：把分子做帯分数化，化成整数部分与 $\dfrac{\text{定数}}{x - p}$ 的形式后再读 —— 竖直漸近線在分母为 $0$ 的点
- 無理関数の定義域：$y = \sqrt{ax + b}$ 的定義域是根号内 $\ge 0$ —— 先确定定義域，再处理値域・方程式，这个顺序不能反
- 無理関数のグラフ：$y = \sqrt{ax + b}$ 是放物線的「半支」，$y = \sqrt{a - x^2}$ 型是半円 —— 定義域的端点就是图象的端点

### 逆関数と合成関数

- 逆関数の存在条件：原関数在（指定区間内）単調 —— 不単調的関数必须限定区間才有逆関数
- 逆関数の求め方：把 $y = f(x)$ 解出 $x = g(y)$，再交换 $x$ 与 $y$ —— 与原関数的定義域・値域互换
- 逆関数のグラフ：与原関数的图象关于直線 $y = x$ 对称 —— 可以用对称性作图和验算
- 合成関数：$(g \circ f)(x) = g(f(x))$ —— 先内侧后外侧，一般不能交换顺序
- 合成関数の定義域：限于内侧输出落入外侧定義域的范围 —— 式子能写出来，也要另外确认定義域

## 解法パターン

- **画分数関数图象**：分子次数不低于分母时 → 先帯分数化，读出漸近線与平移量再画
- **無理関数的値域与方程式**：出现含根号的式子时 → 先确定根号内 $\ge 0$ 的定義域，在该范围内处理
- **求逆関数**：问 $f^{-1}$ 时 → 确认単調区間，解出 $x$ 后交换字母，并注明定義域
- **合成関数的函数值**：$(g \circ f)(a)$ 这类具体值 → 从内侧的 $f(a)$ 起逐个代入；与 $(f \circ g)$ 是不同的计算
- **無理関数的値域**：问値域时 → 从定義域端点处的関数值读出（先画出半支的形状）
- **逆関数的图象**：作图或确认形状时 → 把原関数的图象关于直線 $y = x$ 翻折
- **逆関数的定義域・値域**：问逆関数一侧的定義域・値域时 → 直接改读原関数的値域・定義域

## 考前注意

- [ ] 無理関数要在一开始确认根号内 $\ge 0$ 的定義域
- [ ] 逆関数的存在需要単調性，不要忘记与原関数交换定義域・値域
- [ ] 合成顺序不能交换（$(g \circ f)$ 与 $(f \circ g)$ 一般不同）
- [ ] 分数関数的漸近線要帯分数化后再读（保持原形容易把水平漸近線读错）
- [ ] 求出逆関数后，不仅要写式子，还要注明定義域
