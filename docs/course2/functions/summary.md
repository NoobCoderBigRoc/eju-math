# 関数要点总结

考前确认本页：分数関数・無理関数の定義域と漸近線の読み方、逆関数と合成関数の扱いの基本手順。
数学III の入口の項目として、定義域と漸近線を先に押さえる進め方がここで問われる。

## 公式・定理清单

### 分数関数と無理関数

- 分数関数の標準形：$y = \dfrac{k}{x - p} + q$ は $y = \dfrac{k}{x}$ を平行移動した双曲線 —— 漸近線は $x = p$ と $y = q$、定義域 $x \ne p$、値域 $y \ne q$
- 一般の分数関数の漸近線：分子を帯分数化して整数部分と $\dfrac{\text{定数}}{x - p}$ の形に直してから読む —— 竖直漸近線は分母が 0 になる点
- 無理関数の定義域：$y = \sqrt{ax + b}$ の定義域は根号内 $\ge 0$ —— 先に定義域を確定してから値域・方程式を処理するのが順序
- 無理関数のグラフ：$y = \sqrt{ax + b}$ は放物線の「半支」、$y = \sqrt{a - x^2}$ 型は半円 —— 定義域の端がグラフの端になる

### 逆関数と合成関数

- 逆関数の存在条件：元の関数が（指定した区間で）単調であること —— 単調でない関数は区間を限らないと逆関数を持たない
- 逆関数の求め方：$y = f(x)$ を $x$ について解いて $x = g(y)$ とし、$x$ と $y$ を入れ替える —— 元の関数と定義域・値域が入れ替わる
- 逆関数のグラフ：元の関数のグラフと直線 $y = x$ に関して対称 —— 対称性で作図と検算ができる
- 合成関数：$(g \circ f)(x) = g(f(x))$ —— 先に内側、後に外側で、一般に順序を入れ替えられない
- 合成関数の定義域：内側の出力が外側の定義域に入る範囲に限られる —— 式が作れても定義域は別に確認する

## 解法パターン

- **分数関数のグラフ**：分子の次数が分母以上なら → まず帯分数化し、漸近線と平行移動量を読んでから描く
- **無理関数の値域・方程式**：根号を含む式が出たら → 根号内 $\ge 0$ の定義域を先に確定し、その範囲の中で処理する
- **逆関数を求める**：$f^{-1}$ を聞かれたら → 単調な区間を確認し、$x$ について解いて文字を入れ替え、定義域も併記する
- **合成関数の値**：$(g \circ f)(a)$ のような具体値は → 内側の $f(a)$ から順に代入する；$(f \circ g)$ とは別物として計算する
- **無理関数の値域**：値域を聞かれたら → 定義域の端点における値から読み取る（グラフの半支の形を先に描く）
- **逆関数のグラフ**：逆関数の作図や形の確認は → 元の関数のグラフを直線 $y = x$ に関して折り返す
- **逆関数の定義域・値域**：逆関数側の定義域・値域を聞かれたら → 元の関数の値域・定義域をそのまま読み替える

## 考前注意

- [ ] 無理関数は根号内 $\ge 0$ の定義域確認を最初に行う
- [ ] 逆関数の存在には単調性が必要で、元の関数との定義域・値域の交換を忘れない
- [ ] 合成の順序は入れ替えられない（$(g \circ f)$ と $(f \circ g)$ は一般に異なる）
- [ ] 分数関数の漸近線は帯分数化してから読む（元の形のままでは横の漸近線を読み違える）
- [ ] 逆関数を求めたら、式だけでなく定義域も併記する
