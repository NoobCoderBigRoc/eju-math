# 微分法要点总结

考前确认三件事：導関数の公式網を合成関数まで含めて正確に使えること、増減表で極値と最大・最小を落とさないこと、グラフ描画のチェックリスト（定義域・漸近線・変曲点）。

## 公式・定理清单

### 導関数

- 微分係数 $f'(a) = \lim_{h \to 0} \dfrac{f(a + h) - f(a)}{h}$ —— 定義に従う計算では差商の極限をそのまま処理する
- $(x^n)' = n x^{n-1}$、$(e^x)' = e^x$、$(a^x)' = a^x \log a$ —— $a^x$ には $\log a$ の因子が付く
- $(\sin x)' = \cos x$、$(\cos x)' = -\sin x$、$(\tan x)' = \dfrac{1}{\cos^2 x}$ —— 三角関数の微分は弧度法が前提、$\cos$ の符号に注意
- $(\log x)' = \dfrac{1}{x}$、$(\log_a x)' = \dfrac{1}{x \log a}$、$(\log|x|)' = \dfrac{1}{x}$ —— 負の範囲では絶対値つきで扱う
- 積：$(fg)' = f'g + fg'$；商：$\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$ —— 商は分子の順序（$f'g - fg'$）を取り違えない
- 合成関数：$\{f(g(x))\}' = f'(g(x))\, g'(x)$ —— 外の微分に内の微分を掛ける。$(\log g(x))' = \dfrac{g'(x)}{g(x)}$ の形も頻出
- 逆関数の微分：$\dfrac{dy}{dx} = \dfrac{1}{dx/dy}$ —— $x$ で微分しにくいときの逃げ道
- 第 $n$ 次導関数：$(\sin x)^{(n)} = \sin\left(x + \dfrac{n\pi}{2}\right)$、$(e^{ax})^{(n)} = a^n e^{ax}$、$(\log x)^{(n)} = (-1)^{n-1}\dfrac{(n - 1)!}{x^n}$ —— 数回微分して規律（符号・階乗・位相）を読み取る

### 導関数の応用

- 接線：$y = f'(a)(x - a) + f(a)$；法線の傾きは $-\dfrac{1}{f'(a)}$ —— 接点の座標と傾きの2点セットで書く
- $f' > 0$ で増加、$f' < 0$ で減少；$f'$ の符号が変わる点が極値 —— $f' = 0$ だけでは極値と言えない
- $f'' > 0$ で下に凸、$f'' < 0$ で上に凸；$f''$ の符号が変わる点が変曲点 —— こちらも符号の変化が条件
- 近似式：$f(a + h) \approx f(a) + f'(a)h$ —— $(1 + h)^r \approx 1 + rh$、$\log(1 + h) \approx h$ などが特例。基準点 $a$ は正確に計算できる点に取る
- 速度 $v = x'(t)$、加速度 $a = x''(t)$；平面運動の速さ $\sqrt{(x')^2 + (y')^2}$ —— 速さの増減は $v$ と $a$ の符号の組み合わせで判定する

## 解法パターン

- **増減・極値型**：最大・最小や極値を求める → $f'$ の符号表（増減表）を作り、閉区間では端点も候補に入れる
- **接線型**：接線・法線の方程式 → 接点における $f'(a)$ を傾きとして点斜式に代入する。接点が未知なら接点を文字で置く
- **グラフ描画型**：関数のグラフを描く → 定義域・対称性・増減表・凹凸・漸近線・切片のチェックリスト順に処理する
- **近似値型**：$\sqrt{4.02}$ のような近似値を求める → 近くの基準点 $a$ で1次近似 $f(a) + f'(a)h$ を使う
- **第 $n$ 次導関数型**：一般項を求める → 3〜4回微分して係数・符号・指数の規律を観察し、一般形を組み立てる

## 考前注意

- [ ] 合成関数の内側の微分 $g'(x)$ を掛け忘れる（链式法则漏乘内层导数）
- [ ] $(a^x)'$ で $\log a$ の因子を付け忘れる（$e^x$ と同じと思い込まない）
- [ ] 極値点と $f' = 0$ の点は同値ではない（変号しない点は極値でない）
- [ ] 最大値・最小値は閉区間の端点も候補（闭区间最值别忘端点）
- [ ] 漸近線の確認漏れ、特に分数関数の水平・斜め漸近線
