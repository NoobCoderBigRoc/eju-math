# 微分法要点总结

考前确认三件事：導関数的公式网（含合成関数）能准确运用、用増減表求極値和最大・最小不漏项、画图时有检查清单意识（定義域・漸近線・変曲点）。

## 公式・定理清单

### 導関数

- 微分係数 $f'(a) = \lim_{h \to 0} \dfrac{f(a + h) - f(a)}{h}$ —— 按定义计算时，直接处理差商的極限
- $(x^n)' = n x^{n-1}$、$(e^x)' = e^x$、$(a^x)' = a^x \log a$ —— $(a^x)'$ 多一个 $\log a$ 因子
- $(\sin x)' = \cos x$、$(\cos x)' = -\sin x$、$(\tan x)' = \dfrac{1}{\cos^2 x}$ —— 三角関数的微分以弧度法为前提，$\cos$ 前的符号别错
- $(\log x)' = \dfrac{1}{x}$、$(\log_a x)' = \dfrac{1}{x \log a}$、$(\log|x|)' = \dfrac{1}{x}$ —— 负数范围用带绝对值的形式处理
- 積：$(fg)' = f'g + fg'$；商：$\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$ —— 商的分子顺序（$f'g - fg'$）不要弄反
- 合成関数：$\{f(g(x))\}' = f'(g(x))\, g'(x)$ —— 外层导数乘内层导数；$(\log g(x))' = \dfrac{g'(x)}{g(x)}$ 的形式也高频出现
- 逆関数の微分：$\dfrac{dy}{dx} = \dfrac{1}{dx/dy}$ —— 对 $x$ 不好微分时的退路
- 第 $n$ 次導関数：$(\sin x)^{(n)} = \sin\left(x + \dfrac{n\pi}{2}\right)$、$(e^{ax})^{(n)} = a^n e^{ax}$、$(\log x)^{(n)} = (-1)^{n-1}\dfrac{(n - 1)!}{x^n}$ —— 微分几次后读出规律（符号・阶乘・相位）

### 導関数の応用

- 接線：$y = f'(a)(x - a) + f(a)$；法線的斜率为 $-\dfrac{1}{f'(a)}$ —— 写时配齐切点坐标与斜率这两项
- $f' > 0$ 时增加、$f' < 0$ 时减少；$f'$ 变号的点才是極値 —— 仅 $f' = 0$ 不能断定是極値
- $f'' > 0$ 时下凸、$f'' < 0$ 时上凸；$f''$ 变号的点是変曲点 —— 同样以符号变化为条件
- 近似式：$f(a + h) \approx f(a) + f'(a)h$ —— $(1 + h)^r \approx 1 + rh$、$\log(1 + h) \approx h$ 等都是其特例；基准点 $a$ 取能精确算出的点
- 速度 $v = x'(t)$、加速度 $a = x''(t)$；平面运动的速率为 $\sqrt{(x')^2 + (y')^2}$ —— 速率的增减由 $v$ 与 $a$ 的符号组合判定

## 解法パターン

- **增减与極値型**：求最大・最小或極値 → 作 $f'$ 的符号表（増減表），闭区间时端点也列入候选
- **接線型**：求接線・法線的方程 → 以切点处的 $f'(a)$ 为斜率代入点斜式；切点未知时先设切点为字母
- **作图型**：画函数的图形 → 按定義域・对称性・増減表・凹凸・漸近線・截点的清单顺序处理
- **近似值型**：求 $\sqrt{4.02}$ 这类近似值 → 在附近的基准点 $a$ 处用一次近似 $f(a) + f'(a)h$
- **第 $n$ 次導関数型**：求一般项 → 微分 3～4 次，观察系数・符号・指数的规律，拼出一般形式

## 考前注意

- [ ] 合成関数求导时漏乘内侧的微分 $g'(x)$（链式法则漏乘内层导数）
- [ ] $(a^x)'$ 漏掉 $\log a$ 因子（别以为和 $e^x$ 一样）
- [ ] 極値点与 $f' = 0$ 的点并不等价（不变号的点不是極値）
- [ ] 闭区间上的最大・最小值别漏端点作为候选
- [ ] 漏查漸近線，尤其是分数関数的水平・斜漸近線
