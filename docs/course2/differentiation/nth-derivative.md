# 第n次導関数

## 1. 定義

関数 $f(x)$ を繰り返し微分して得られる導関数を順に **第2次導関数** $f''(x)$、**第3次導関数** $f'''(x)$、… といい、$n$ 回微分したものを **第 $n$ 次導関数** と呼んで $f^{(n)}(x)$ と書く（$f^{(0)} = f$、$f^{(1)} = f'$）。表記は $\dfrac{d^n y}{dx^n}$ でも同じ意味である。

## 2. 求め方（帰納的に規律を探す）

閉じた公式がない関数は、次の手順で一般項を組み立てるのが標準的な解法である。

1. まず $f'(x)$、$f''(x)$、$f'''(x)$、$f^{(4)}(x)$ あたりまで実際に微分する。
2. 係数・符号・指数の変化の規律を観察する（符号は $(-1)^n$ 型、係数は階乗 $n!$ や累乗 $a^n$ 型、三角関数は $\dfrac{\pi}{2}$ ずつ位相が進む周期型が多い）。
3. 見つけた規律で $f^{(n)}(x)$ を書き、必要なら数学的帰納法で正しさを確認する。

## 3. 覚えるべき公式

| 関数 | 第 $n$ 次導関数 |
| --- | --- |
| $e^x$ | $e^x$ |
| $e^{ax}$ | $a^n e^{ax}$ |
| $a^x$ | $a^x (\log a)^n$ |
| $\sin x$ | $\sin\left(x + \dfrac{n\pi}{2}\right)$ |
| $\cos x$ | $\cos\left(x + \dfrac{n\pi}{2}\right)$ |
| $\log x$ | $(-1)^{n-1} \dfrac{(n - 1)!}{x^n}$ |
| $\dfrac{1}{x}$ | $(-1)^n \dfrac{n!}{x^{n+1}}$ |
| $\dfrac{1}{1 - x}$ | $\dfrac{n!}{(1 - x)^{n+1}}$ |

三角関数の公式は「微分するたびに位相が $\dfrac{\pi}{2}$ 進む」と読むと覚えやすい：$\sin \to \cos \to -\sin \to -\cos \to \sin$ と4回で一巡する。

## 易错点

- [ ] $(-1)^n$ の符号の付け方（$n$ の偶奇で確認する；$\log x$ 系は $(n - 1)!$ と $(-1)^{n-1}$ で指数が1ずれる）
- [ ] 階乗 $n!$ と累乗 $a^n$ の混同（係数に出るのは多くの場合階乗）
- [ ] $\sin$ の第 $n$ 次導関数で位相 $\dfrac{n\pi}{2}$ を足し忘れる（形は $\sin$ のままとは限らない）
