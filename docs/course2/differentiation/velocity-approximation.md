# 速度・加速度と近似式

## 1. 速度と加速度

時刻 $t$ における位置が $x = x(t)$ で与えられるとき：

- **速度**：$v(t) = \dfrac{dx}{dt} = x'(t)$（位置の変化率。符号は向きを表す）
- **加速度**：$a(t) = \dfrac{dv}{dt} = v'(t) = x''(t)$（速度の変化率、すなわち位置の第2次導関数）

平均速度 $\dfrac{x(t + h) - x(t)}{h}$ の $h \to 0$ の極限が瞬間の速度であり、微分係数の定義そのものである。平面運動では成分ごとに微分し、速さはベクトルの大きさ $\sqrt{(x')^2 + (y')^2}$ で与えられる。加速度が負であることは「減速」を意味しない（負の向きへの加速である）；速さが増えるか減るかは、$v$ と $a$ の符号が同符号か異符号かで決まる。

## 2. 近似式（1次近似）

$x = a$ の近くでは、関数のグラフはその点での接線で近似できる：

$$f(a + h) \approx f(a) + f'(a)h \qquad (|h| \text{ が小さいとき})$$

$h$ が小さいほど精度が上がり、誤差はおよそ $h^2$ のオーダーになる。よく使う形：

- $\sqrt{a + h} \approx \sqrt{a} + \dfrac{h}{2\sqrt{a}}$
- $\dfrac{1}{1 + h} \approx 1 - h$
- $(1 + h)^r \approx 1 + rh$
- $e^h \approx 1 + h$、$\log(1 + h) \approx h$、$\sin h \approx h$

如 $\sqrt{4.02} \approx 2 + \dfrac{1}{4}(0.02)$（$f(x) = \sqrt{x}$、$a = 4$、$h = 0.02$ として接線で近似したもの）。

## 易错点

- [ ] 近似式は $h$ が小さい前提（近似式只在增量很小时可用；$h$ の絶対値が大きいと誤差が無視できない）
- [ ] 近似の基準点 $a$ の選び方（$f(a)$ と $f'(a)$ が正確に計算できる点を選ぶ；$\sqrt{4.02}$ なら $a = 4$）
- [ ] 加速度の符号をそのまま「減速」と読む（速さの増減は速度と加速度の符号の組み合わせで判定する）
- [ ] $h$ の符号ミス（$a$ より小さい側で近似するときは $h < 0$ になる）
