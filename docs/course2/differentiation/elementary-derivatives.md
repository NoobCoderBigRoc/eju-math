# 三角関数・指数関数・対数関数の導関数

## 1. 基本公式

| 関数 | 導関数 |
| --- | --- |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\dfrac{1}{\cos^2 x}$（$= 1 + \tan^2 x$） |
| $e^x$ | $e^x$ |
| $a^x$（$a > 0$） | $a^x \log a$ |
| $\log x$ | $\dfrac{1}{x}$ |
| $\log_a x$ | $\dfrac{1}{x \log a}$ |
| $\log \|x\|$ | $\dfrac{1}{x}$ |

注意：三角関数の微分公式がこの形になるのは **弧度法（ラジアン）が前提**。度数法で測った角では $\dfrac{\pi}{180}$ の因子が付いてしまうため、微積分では必ず弧度法で扱う。

## 2. 公式の出どころ

- $(\tan x)'$：$\tan x = \dfrac{\sin x}{\cos x}$ に商の微分を適用すると $\dfrac{\cos^2 x + \sin^2 x}{\cos^2 x} = \dfrac{1}{\cos^2 x}$ となる。
- $(a^x)'$：$a^x = e^{x \log a}$ と書き直して合成関数の微分を使うと $e^{x \log a} \cdot \log a = a^x \log a$ を得る。$\log a$ の因子は「底を $e$ に直したときの内側の微分」である。
- $(\log_a x)'$：底の変換公式 $\log_a x = \dfrac{\log x}{\log a}$ より、分母の $\log a$ は定数として外に出る。

## 3. 合成関数と組み合わせた形

試験では単体よりも、内側に関数を入れた形で出ることが多い。外側の公式に内側の微分を掛ける：

- $(\sin g(x))' = \cos g(x) \cdot g'(x)$
- $(e^{g(x)})' = e^{g(x)} \cdot g'(x)$
- $(\log g(x))' = \dfrac{g'(x)}{g(x)}$（$g(x) > 0$）

## 易错点

- [ ] $(a^x)'$ で $\log a$ の因子を付け忘れる（$e^x$ と同じと思い込まない；$a = e$ のときだけ因子が 1 になる）
- [ ] $(\cos x)'$ のマイナス符号を落とす
- [ ] $\log$ の微分で $\log|x|$ の絶対値を無視し、$x < 0$ の範囲を落とす
- [ ] 合成関数の内側の微分 $g'(x)$ の掛け忘れ（特に $(\log g(x))'$ の分子）
