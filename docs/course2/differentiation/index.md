# 微分法简介（数学II・III）

导数的定义、公式网与应用：切線、増減与極値、関数のグラフ、速度与近似式。导数本质上是項目 18 的极限。

本项目的具体内容都在下面的细目页中（左侧导航点开「19. 微分法」即可逐层展开）。

## 在 EJU 中的位置

本项是 Course 2 的核心大项目之一，题型是「计算 + 作图」的成套组合：導関数計算、増減表、グラフ描画、接線与近似往往在同一道大题里接力出现。它前接項目 18 極限（导数就是差商的极限），处理的对象则全是項目 17 いろいろな関数的三角・指数・対数函数及其合成；向后由微積分学の基本定理与項目 20 積分法锁在一起，复习时应把这三项看作一个整体。
