# 複素数と図形

用复数描述几何条件：

- 两点 $\alpha, \beta$ 的中点 $\dfrac{\alpha + \beta}{2}$；线段的垂直平分线 $|z - \alpha| = |z - \beta|$
- 圆：$|z - \alpha| = r$；圆的内部/外部对应 $<$ / $>$
- 直线：$z$ 与 $\bar{z}$ 的一次方程 $\bar{\alpha} z + \alpha \bar{z} = \ldots$ 形式（用 $\bar z$ 消去虚部）
- 回転と相似：$w = \beta + (\text{回転・拡大})(z - \alpha)$ 描述绕 $\alpha$ 的旋转相似变换

**演習：回転**

点 $1 + i$ を原点のまわりに $\dfrac{\pi}{2}$ だけ回転した点を求めよ。

??? example "思路・解答"
    **答案**

    $-1 + i$

    **思路**

    旋转 $\dfrac{\pi}{2}$ 等于乘以 $i$：$i(1 + i) = i + i^2 = -1 + i$。

    **解答**

    $$i(1 + i) = -1 + i$$

**演習：複素数と図形**

$|z - 2i| = 2$ を満たす複素数 $z$ のうち、$|z|$ が最大となるものを求めよ。

??? example "思路・解答"
    **答案**

    $z = 4i$（最大値 4）

    **思路**

    $|z - 2i| = 2$ 是以 $2i$ 为圆心、半径 2 的圆；圆上离原点最远的点在「原点—圆心」连线延长线上，即 $2i + 2i = 4i$。

    **解答**

    $$|z| \le |2i| + 2 = 4, \qquad \text{最大は } z = 4i \text{ のとき}$$

## 易错点

- [ ] 偏角の主値の範囲（$-\pi < \arg z \le \pi$）を揃える（偏角主值范围要统一）
