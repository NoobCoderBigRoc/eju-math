# 複素数平面要点总结

考前确认三件事：怎样化为極形式、乘除与旋转的读法、把图形条件翻译成复数式子的套路。比计算本身更重要的是「用代数硬推还是用图形来读」的切换意识。

## 公式・定理清单

### 複素数平面

- $|z| = \sqrt{a^2 + b^2}$、$z\bar{z} = |z|^2$ —— 模的平方必须经共轭得到，不能用 $z^2$ 代替
- 2点の距離 $= |z_1 - z_2|$、中点 $= \dfrac{z_1 + z_2}{2}$ —— 与坐标几何同形，原点以外的基点先作差
- $z + \bar{z} = 2\operatorname{Re} z$、$z - \bar{z} = 2i\operatorname{Im} z$ —— 实部、虚部分离的标准手法
- $z$ が実数 $\iff z = \bar{z}$；$z$ が純虚数 $\iff z + \bar{z} = 0$ かつ $z \ne 0$ —— 凡「证明某数为实数」的问题，都靠计算共轭、证明与原数一致来解决

### 複素数の極形式と回転

- $z = r(\cos\theta + i\sin\theta)$、$r = |z| \ge 0$、$-\pi < \theta \le \pi$ —— $\theta$ 的象限由 $\cos\theta = a/r$ 与 $\sin\theta = b/r$ 两式共同决定
- 乘积：模相乘、角相加；商：模相除、角相减 —— 乘除先化为極形式再处理
- $(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$（ド・モアブルの定理）—— 乘方时模取 $n$ 次幂、角乘以 $n$
- 方程 $z^n = w$ 的解有 $n$ 个，在圆周上等间隔分布 —— 求方根时不要漏掉个数
- 乘以 $|w| = 1$ 的 $w$ 等于绕原点的旋转；绕一般点 $\alpha$ 的旋转为 $z' - \alpha = w(z - \alpha)$ —— 先把 $\alpha$ 平移到原点再处理

### 複素数と図形

- 圆：$|z - \alpha| = r$，内部取 $<$，外部取 $>$ —— 即把「到中心距离一定」翻译成式子
- 線分の垂直二等分線：$|z - \alpha| = |z - \beta|$ —— 到两点距离相等的条件
- 直线：$\bar{\alpha} z + \alpha \bar{z} = \cdots$ 的形式 —— 用 $\bar{z}$ 消去虚部

## 解法パターン

- **乘方・方根型**：$a + bi$ 的高次幂或 $z^n = w$ → 先化为極形式，用ド・モアブル处理
- **旋转定顶点型**：正三角形・正方形的未知顶点 → 给表示边的复数乘上 $\cos 60^\circ + i\sin 60^\circ$ 等旋转因子
- **轨迹・图形条件型**：条件中含 $|z - \alpha|$ → 直译成距离的语言，按圆・垂直二等分線来读
- **实数・纯虚数证明型**：证明某值为实数 → 计算 $\bar{z}$，证明与 $z$ 一致（或 $z + \bar{z} = 0$）
- **最大・最小型**：圆上的点使 $|z|$ 取最大・最小 → 在原点与圆心连线与圆的交点处取得（三角不等式）

## 考前注意

- [ ] $|z|^2$ 要写成 $z\bar{z}$ 而不是 $z^2$（模的平方必须经共轭得到）
- [ ] 偏角的象限要由 $\cos$、$\sin$ 两者的符号共同决定（只看一个会把第二、三象限弄混）
- [ ] 極形式中的 $r$ 不取负值（符号靠给偏角加上 $\pi$ 来吸收）
- [ ] 判定純虚数时不包含 $z = 0$（$0$ 同时也是实数）
- [ ] $n$ 次方根共有 $n$ 个，不要漏数
