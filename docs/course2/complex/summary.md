# 複素数平面要点总结

考前确认三件事：極形式への直し方、乗除・回転の読み方、図形条件を複素数の式に直す型。計算そのものより「代数で押すか図形で読むか」の切り替えが要点。

## 公式・定理清单

### 複素数平面

- $|z| = \sqrt{a^2 + b^2}$、$z\bar{z} = |z|^2$ —— 模的平方必须经共轭得到，不能用 $z^2$ 代替
- 2点の距離 $= |z_1 - z_2|$、中点 $= \dfrac{z_1 + z_2}{2}$ —— 与坐标几何同形，原点以外的基点先作差
- $z + \bar{z} = 2\operatorname{Re} z$、$z - \bar{z} = 2i\operatorname{Im} z$ —— 实部、虚部分离的标准手法
- $z$ が実数 $\iff z = \bar{z}$；$z$ が純虚数 $\iff z + \bar{z} = 0$ かつ $z \ne 0$ —— 「実数であることを示せ」は共轭を計算して一致を示す

### 複素数の極形式と回転

- $z = r(\cos\theta + i\sin\theta)$、$r = |z| \ge 0$、$-\pi < \theta \le \pi$ —— $\theta$ は $\cos\theta = a/r$、$\sin\theta = b/r$ の両方で象限を決める
- 積：模は積・角は和；商：模は商・角は差 —— 乗除は極形式に直してから処理する
- $(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$（ド・モアブルの定理）—— 累乗は模を累乗し角を $n$ 倍する
- $z^n = w$ の解は $n$ 個、円周上に等間隔 —— 方根は個数を落とさない
- $|w| = 1$ の $w$ を掛ける $=$ 原点中心の回転；一般の点 $\alpha$ 中心は $z' - \alpha = w(z - \alpha)$ —— 先に $\alpha$ を原点へずらす

### 複素数と図形

- 円：$|z - \alpha| = r$、内部は $<$、外部は $>$ —— 「中心からの距離一定」の翻訳
- 線分の垂直二等分線：$|z - \alpha| = |z - \beta|$ —— 2点から等距離の条件
- 直線：$\bar{\alpha} z + \alpha \bar{z} = \cdots$ の形 —— $\bar{z}$ を使って虚部を消す

## 解法パターン

- **累乗・方根型**：$a + bi$ の高次冪や $z^n = w$ → まず極形式に直し、ド・モアブルで処理する
- **回転で頂点を決める型**：正三角形・正方形の未知の頂点 → 辺の複素数に $\cos 60^\circ + i\sin 60^\circ$ などの回転因子を掛ける
- **軌跡・図形条件型**：$|z - \alpha|$ を含む条件 → 距離の言葉に直訳し、円・垂直二等分線として読む
- **実数・純虚数の証明型**：値が実数であることを示す → $\bar{z}$ を計算して $z$ と一致（または $z + \bar{z} = 0$）を示す
- **最大・最小型**：円上の点で $|z|$ の最大・最小 → 原点と円心を結ぶ直線との交点で取る（三角不等式）

## 考前注意

- [ ] $|z|^2$ は $z^2$ ではなく $z\bar{z}$（模的平方必须经共轭得到）
- [ ] 偏角は $\cos$、$\sin$ の両方の符号で象限を決める（片方だけでは第2・3象限を取り違える）
- [ ] 極形式の $r$ に負の値を許さない（符号は偏角に $\pi$ を加えて吸収する）
- [ ] 純虚数の判定に $z = 0$ を含めない（$0$ は実数でもある）
- [ ] $n$ 次方根は $n$ 個あることを数え落とさない
