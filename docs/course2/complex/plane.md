# 複素数平面と極形式

点 $z = a + bi$ 对应平面上的点 $(a, b)$；原点到该点的距离是 $|z| = \sqrt{a^2 + b^2}$（絶対値），与实轴的夹角是偏角 $\arg z$。

和差对应向量加减；共轭 $\bar{z} = a - bi$ 关于实轴对称；$z\bar{z} = |z|^2$。

極形式（极形式）：

$$z = r(\cos\theta + i\sin\theta), \qquad r = |z|,\ \theta = \arg z$$

乘除在极形式下变为「模相乘、角相加」：乘以单位模的复数即旋转。回転：乘以 $\cos\theta + i\sin\theta$ 等于绕原点旋转 $\theta$；绕任意点 $\alpha$ 的旋转：$z' - \alpha = (\cos\theta + i\sin\theta)(z - \alpha)$。
