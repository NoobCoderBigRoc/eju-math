# 複素数平面

実部を横軸（実軸）、虚部を縦軸（虚軸）にとった平面を複素数平面（ガウス平面）という。複素数 $z = a + bi$（$a, b$ は実数）を点 $(a, b)$ に対応させることで、複素数の演算が平面上の移動・回転として見えるようになる。これが [いろいろな式](../polynomials/complex-equations.md) で代数として扱った複素数との違いで、本項目の出発点。

## 絶対値と偏角

点 $z = a + bi$ について：

- 絶対値：原点からの距離 $|z| = \sqrt{a^2 + b^2}$。常に $0$ 以上の実数で、$|z| = 0$ なのは $z = 0$ のときだけ。
- 偏角：実軸の正の向きから測った角 $\arg z$。$2\pi$ の整数倍だけ不定性があるため、通常は主値 $-\pi < \arg z \le \pi$ の範囲で答える。

2 点 $z_1$、$z_2$ の距離は差の絶対値 $|z_1 - z_2|$、中点は $\dfrac{z_1 + z_2}{2}$ で、座標のときと同形。

## 共役複素数

$\bar{z} = a - bi$ を $z$ の共役複素数という。幾何的には実軸に関する対称点。性質：

- $z + \bar{z} = 2a = 2\operatorname{Re} z$（実数になる）
- $z - \bar{z} = 2bi = 2i\operatorname{Im} z$
- $z\bar{z} = a^2 + b^2 = |z|^2$
- $\overline{z_1 \pm z_2} = \bar{z}_1 \pm \bar{z}_2$、$\overline{z_1 z_2} = \bar{z}_1 \bar{z}_2$、$\overline{\bar{z}} = z$

判定への応用：$z$ が実数 ⇔ $z = \bar{z}$；$z$ が純虚数 ⇔ $z + \bar{z} = 0$ かつ $z \ne 0$。「この複素数が実数であることを示せ」という証明では、$\bar{z}$ を計算して $z$ と一致することを示すのが定石。

## 和・差の幾何的意味

和差对应向量加减：和 $z_1 + z_2$ は原点と 2 点が作る平行四辺形の第 4 の頂点に対応する。差 $z_1 - z_2$ は点 $z_2$ から点 $z_1$ へ向かうベクトルに対応し、その絶対値が 2 点間距離 $|z_1 - z_2|$ になる。共轭 $\bar{z} = a - bi$ 关于实轴对称；$z\bar{z} = |z|^2$。

複素数平面の問題は「代数で計算するか、図形として読むか」の切り替えが要点で、回転が絡む場合は $z$ を [極形式](polar-form.md) に直してから処理する。

## 易错点

- [ ] $|z|^2$ は $z^2$ ではなく $z\bar{z}$（模的平方必须经共轭得到，$z^2$ 一般仍是复数，不能代替 $|z|^2$）
- [ ] 偏角 $\arg z$ の主値の範囲（$-\pi < \arg z \le \pi$）をそろえる（偏角定象限时要用 $\cos$、$\sin$ 两个符号，第 2、3 象限的取舍是典型错误）
- [ ] 純虚数の判定に $z = 0$ を含めてしまう（$0$ は実数でもあるので、纯虚数要加 $z \ne 0$ 的条件）
