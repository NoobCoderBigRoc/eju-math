# 複素数平面简介（数学C）

复数即平面上的点：加减对应向量、乘法对应旋转与伸缩，是与ベクトル并行的第二套几何语言。

本项目的具体内容都在下面的细目页中（左侧导航点开「15. 複素数平面」即可逐层展开）。

## 在 EJU 中的位置

本项是 Course 2 里几何气质最浓的项目之一：纯计算不重，难在把图形条件翻译成复数式子、再把结果读回图形。与ベクトル是同一几何的两套语言，常以「用向量也行、用复数也行」的方式出题；極形式与回転直接调用三角函数的知识，軌跡部分则是図形と方程式的延伸。
