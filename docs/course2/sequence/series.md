# 数列とその和

## 1. 等差数列と等比数列

- 等差（公差 $d$）：$a_n = a_1 + (n - 1)d$，$S_n = \dfrac{n(a_1 + a_n)}{2}$
- 等比（公比 $r$）：$a_n = a_1 r^{n-1}$，$S_n = \dfrac{a_1(r^n - 1)}{r - 1}$（$r \ne 1$）

## 2. 階差数列

原数列 $\{a_n\}$ 的差 $b_n = a_{n+1} - a_n$ 成规律时，$a_n = a_1 + \sum_{k=1}^{n-1} b_k$（$n \ge 2$）。

## 3. いろいろな数列の和

- $\sum_{k=1}^{n} k = \dfrac{n(n + 1)}{2}$、$\sum k^2 = \dfrac{n(n + 1)(2n + 1)}{6}$、$\sum k^3 = \left\{\dfrac{n(n + 1)}{2}\right\}^2$
- 部分分数分解（部分分数分解）处理 $\sum \dfrac{1}{k(k + 1)}$ 类（分母可因式分解时拆成差，利用望远镜消去）；等比×等差混合列用「$S - rS$」錯位相减（ずらして引く）。

??? example "演習：部分分数分解"
    **问题**

    $\displaystyle \sum_{k=1}^{n} \frac{1}{k(k + 1)}$ を求めよ。

    **答案**

    $\dfrac{n}{n + 1}$

    **思路**

    $\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$，中间项两两抵消，只剩首尾。

    **解答**

    $$\sum_{k=1}^{n} \left(\frac{1}{k} - \frac{1}{k + 1}\right) = 1 - \frac{1}{n + 1} = \frac{n}{n + 1}$$

## 易错点

- [ ] $\sum$ の項数を数え違える（特に $n - 1$ 項までの和）
- [ ] 等比数列の和で $r = 1$ の場合を分ける（公比为 1 时和的公式要另算）
