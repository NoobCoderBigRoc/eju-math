# 数列简介（数学B）

等差・等比是骨架，階差与遞推是变化，数学的帰納法是证明工具。本项目是項目 18 極限（無限級数）的前置。

本项目的具体内容都在下面的细目页中（左侧导航点开「12. 数列」即可逐层展开）。

## 在 EJU 中的位置

本项目是一个相对独立的完整单元，分量稳定，题型气质是计算与证明并重：一般項と和の計算が中心で、数学的帰納法是 EJU 证明题的标准工具之一，书写格式本身就是得分点。
它与極限项目直接联动——無限級数就是数列の和の極限，本项目是其前置；$\sum$ の計算感覚は確率分布项目里期待値を求める場面でも使われる。
