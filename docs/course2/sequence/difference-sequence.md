# 階差数列

## 1. 定義と公式

数列 $\{a_n\}$ に対して、隣り合う項の差 $b_n = a_{n + 1} - a_n$ を項とする数列 $\{b_n\}$ を、もとの数列の **階差数列** という。差を順に足し上げると途中の項が打ち消し合う（望遠鏡型の和になる）ため、$n \ge 2$ のとき

$$a_n = a_1 + \sum_{k = 1}^{n - 1} b_k$$

が成り立つ。$\{b_n\}$ の一般項が分かれば、右辺の和を計算して $\{a_n\}$ の一般項が得られる。

## 2. 解法の手順

1. $b_n = a_{n + 1} - a_n$ を計算し、$\{b_n\}$ の一般項を求める（等差・等比・分数式など見慣れた形になることが多い）。
2. $\{b_n\}$ の和の公式で $\sum_{k=1}^{n-1} b_k$ を求める。$b_k$ が分数のときは部分分数分解して望遠鏡型にする。
3. $a_n = a_1 + \sum_{k = 1}^{n - 1} b_k$ に代入して整理する。得られた式は **$n \ge 2$ で成り立つ**ので、$n = 1$ のときも満たすかを別に確認する（多くの場合そのまま一致するが、一致しない問題もある）。

## 3. 階差がさらに数列になるとき

$b_n$ 自体が簡単な形にならない場合、$\{b_n\}$ の階差（第2階差）を取る方法もある。第2階差が定数になる数列は $a_n$ が $n$ の2次式であり、一般項を $a_n = An^2 + Bn + C$ と置いて係数を決める方法も有効である。また、漸化式 $a_{n + 1} = a_n + f(n)$ は階差が $f(n)$ であることを意味するので、そのまま本節の公式で解ける（[漸化式と数列](recurrence.md) 参照）。

## 易错点

- [ ] 和の上限を取り違える（$\sum$ は $k = 1$ から $n - 1$ まで；$n$ 項ではなく $n - 1$ 項の和）
- [ ] $n = 1$ の確認を省く（公式は $n \ge 2$ 前提）
- [ ] $b_n$ の符号ミス（$b_n = a_{n + 1} - a_n$ であって逆ではない）
