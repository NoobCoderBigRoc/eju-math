# 数列要点总结

考前确认本页：等差・等比と和の公式、階差・部分分数・漸化式の解法の型、帰納法の証明手順。

## 公式・定理清单

### 数列とその和

- 等差数列（公差 $d$）：一般項 $a_n = a_1 + (n - 1)d$、和 $S_n = \dfrac{n(a_1 + a_n)}{2}$ —— 和は「項数 ×（初項＋末項）÷ 2」
- 等比数列（公比 $r$）：一般項 $a_n = a_1 r^{n-1}$、和 $S_n = \dfrac{a_1(r^n - 1)}{r - 1}$（$r \ne 1$）—— $r = 1$ のときは全項が $a_1$ なので $S_n = n a_1$ と別扱いにする
- $\sum_{k=1}^{n} k = \dfrac{n(n + 1)}{2}$、$\sum_{k=1}^{n} k^2 = \dfrac{n(n + 1)(2n + 1)}{6}$、$\sum_{k=1}^{n} k^3 = \left\{\dfrac{n(n + 1)}{2}\right\}^2$
- 部分分数分解：$\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$ —— 分母が因数分解できる分数の和は、差の形に直すと中間項が消える（望遠鏡型）
- 階差数列：$b_n = a_{n + 1} - a_n$ とすると、$n \ge 2$ で $a_n = a_1 + \sum_{k=1}^{n-1} b_k$ —— 和の上限は $n$ ではなく $n - 1$
- 第 2 階差：階差の階差が定数になる数列は、一般項が $n$ の 2 次式になる —— $a_n = An^2 + Bn + C$ と置いて係数を決める手もある

### 漸化式と数学的帰納法

- 漸化式 $a_{n+1} = pa_n + q$（$p \ne 1$）：不動点 $\alpha = p\alpha + q$ を求め、$b_n = a_n - \alpha$ と置くと等比数列になる
- 漸化式 $a_{n+1} = a_n + f(n)$：階差が $f(n)$ の数列として累加で解ける
- 漸化式 $a_{n+1} = \dfrac{p a_n}{q a_n + r}$ 型：両辺の逆数を取ると等差・等比の形に帰着する
- 連立漸化式：$a_{n+1}$、$b_{n+1}$ が互いに定義し合う形は、和 $a_n + b_n$ と差 $a_n - b_n$ の数列を作ると解ける形になることが多い
- 数学的帰納法：(i) $n = 1$ のとき成立を確認し、(ii) $n = k$ のときの成立を仮定して $n = k + 1$ のときも成立することを示す —— (ii) で仮定を実際に使うのが本質

## 解法パターン

- **階差で一般項**：数列の規則が読みにくかったら → 階差 $b_n$ を求めて累加し、最後に $n = 1$ でも合うか確認する
- **分数列の和**：$\dfrac{1}{k(k + 1)}$ のような分母が積の形なら → 部分分数分解して差の形にし、望遠鏡型に消去する
- **等差×等比の和**：$(ak + b) r^k$ 型の和は → $S$ と $rS$ をずらして引き、等比数列の和に帰着させる
- **漸化式の型判定**：分式型は逆数を取って等差・等比化し、連立型は和と差を作って新しい数列に直す
- **数列の証明**：通項の等式・不等式・整除性を示すなら → 数学的帰納法の 2 段構えで、仮定を使った箇所が分かるように書く

## 考前注意

- [ ] 等比数列の和では $r = 1$ の場合を分けて処理する
- [ ] 階差の公式の和の上限は $n - 1$ で、得られた一般項は $n = 1$ のとき別に確認する
- [ ] $\sum$ の項数を数え違えない（特に $n - 1$ 項までの和）
- [ ] 不動点 $\alpha$ は $a_n$ から引く側の定数で、符号を取り違えない
- [ ] 帰納法の (ii) で仮定を使わずに結論だけを書かない
- [ ] 階差の符号：$b_n = a_{n + 1} - a_n$ であって、逆向きに取らない
