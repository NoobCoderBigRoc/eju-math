# 数列要点总结

考前确认本页：等差・等比与求和公式、階差・部分分数・漸化式的解法套路、帰納法的证明步骤。

## 公式・定理清单

### 数列とその和

- 等差数列（公差 $d$）：一般項 $a_n = a_1 + (n - 1)d$、和 $S_n = \dfrac{n(a_1 + a_n)}{2}$ —— 和等于「项数 ×（首項＋末項）÷ 2」
- 等比数列（公比 $r$）：一般項 $a_n = a_1 r^{n-1}$、和 $S_n = \dfrac{a_1(r^n - 1)}{r - 1}$（$r \ne 1$）—— $r = 1$ 时各项都是 $a_1$，$S_n = n a_1$，要分开处理
- $\sum_{k=1}^{n} k = \dfrac{n(n + 1)}{2}$、$\sum_{k=1}^{n} k^2 = \dfrac{n(n + 1)(2n + 1)}{6}$、$\sum_{k=1}^{n} k^3 = \left\{\dfrac{n(n + 1)}{2}\right\}^2$
- 部分分数分解：$\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$ —— 分母可因数分解的分数求和时，化成差的形式后中间项相消（望遠鏡型）
- 階差数列：记 $b_n = a_{n + 1} - a_n$，则 $n \ge 2$ 时 $a_n = a_1 + \sum_{k=1}^{n-1} b_k$ —— 求和上限是 $n - 1$，不是 $n$
- 第 2 階差：階差的階差为常数的数列，一般項是 $n$ 的 2 次式 —— 也可以设 $a_n = An^2 + Bn + C$ 定系数

### 漸化式と数学的帰納法

- 漸化式 $a_{n+1} = pa_n + q$（$p \ne 1$）：先求不動点 $\alpha = p\alpha + q$，再设 $b_n = a_n - \alpha$，化为等比数列
- 漸化式 $a_{n+1} = a_n + f(n)$：看作階差为 $f(n)$ 的数列，用累加求解
- 漸化式 $a_{n+1} = \dfrac{p a_n}{q a_n + r}$ 型：两边取倒数，化归为等差・等比的形式
- 連立漸化式：$a_{n+1}$、$b_{n+1}$ 互相定义的情形，构造和 $a_n + b_n$ 与差 $a_n - b_n$ 两个数列往往就能解
- 数学的帰納法：(i) 确认 $n = 1$ 时成立；(ii) 假设 $n = k$ 时成立，证明 $n = k + 1$ 时也成立 —— 关键是 (ii) 中必须真正用到假设

## 解法パターン

- **用階差求一般項**：数列规律看不清时 → 求階差 $b_n$ 并累加，最后确认 $n = 1$ 时也符合
- **分数列求和**：$\dfrac{1}{k(k + 1)}$ 这类分母为乘积形式时 → 部分分数分解化成差的形式，按望遠鏡型消去
- **等差×等比求和**：$(ak + b) r^k$ 型的和 → 把 $S$ 与 $rS$ 错位相减，化归为等比数列的和
- **漸化式类型判断**：分式型取倒数化为等差・等比；連立型构造和与差的新数列
- **数列的证明**：证明通項的等式・不等式・整除性时 → 用数学的帰納法的两段式书写，并让用到假设的位置看得出来

## 考前注意

- [ ] 等比数列求和时要把 $r = 1$ 的情形分开处理
- [ ] 階差公式的求和上限是 $n - 1$；得到的一般項要在 $n = 1$ 时另行确认
- [ ] 不要数错 $\sum$ 的项数（尤其是到 $n - 1$ 项为止的和）
- [ ] 不動点 $\alpha$ 是从 $a_n$ 中减去的那个常数，不要弄错符号
- [ ] 帰納法的 (ii) 中不要只写结论而不使用假设
- [ ] 階差的符号：$b_n = a_{n + 1} - a_n$，不要取反方向
