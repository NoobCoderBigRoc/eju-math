# 漸化式と数学的帰納法

## 1. 漸化式と数列

标准型与其变形方法：

- $a_{n+1} = pa_n + q$（$p \ne 1$）：找不动点 $\alpha = p\alpha + q$，令 $b_n = a_n - \alpha$ 化为等比。
- $a_{n+1} = a_n + f(n)$：阶差型，累加。
- $a_{n+1} = \dfrac{pa_n}{qa_n + r}$ 类：取倒数化为等差/等比。
- 连立漸化式（$a_{n+1}, b_{n+1}$ 互相定义）：作和、作差构造新数列。

## 2. 数学的帰納法

证明模板：(i) $n = 1$ 时成立；(ii) 假设 $n = k$ 时成立，证 $n = k + 1$ 时也成立——在 (ii) 中必须**显式用到假设**。对不等式、整除性、数列通项的证明都用此法。

??? example "演習：漸化式"
    **问题**

    $a_1 = 1$、$a_{n+1} = 2a_n + 3$ で定められる数列の一般項を求めよ。

    **答案**

    $a_n = 2^{n+1} - 3$

    **思路**

    不动点：$\alpha = 2\alpha + 3$ 得 $\alpha = -3$。令 $b_n = a_n + 3$，则 $b_{n+1} = 2b_n$ 是公比 2 的等比数列，$b_1 = 4$。

    **解答**

    $$b_n = 4 \cdot 2^{n - 1} = 2^{n + 1} \quad\Longrightarrow\quad a_n = 2^{n + 1} - 3$$

??? example "演習：数学的帰納法"
    **问题**

    すべての自然数 $n$ に対して $1 + 2 + \cdots + n = \dfrac{n(n + 1)}{2}$ が成り立つことを数学的帰納法で証明せよ。

    **答案**

    証明は下記

    **思路**

    两段式：$n = 1$ 验证；假设 $n = k$ 成立，两边同加 $k + 1$ 后整理成 $k + 1$ 的公式形态。

    **解答**

    (i) $n = 1$：左辺 $1$、右辺 $\dfrac{1 \cdot 2}{2} = 1$，成立。

    (ii) $n = k$ 时成立，即 $1 + \cdots + k = \dfrac{k(k + 1)}{2}$ と仮定すると、

    $$1 + \cdots + k + (k + 1) = \frac{k(k + 1)}{2} + (k + 1) = \frac{(k + 1)(k + 2)}{2}$$

    这是 $n = k + 1$ 的式子。故对一切自然数成立。$\blacksquare$

## 易错点

- [ ] 特性方程式（不动点）的符号（$\alpha = p\alpha + q$ 解出的 $\alpha$ 是减在 $a_n$ 一侧的常数）
- [ ] 帰納法で仮定を使わずに結論だけ書く（归纳步中没有真正用到归纳假设）
- [ ] 連立漸化式は和と差を作ってみる（联立递推先试作和、作差）
