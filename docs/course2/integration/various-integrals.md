# いろいろな関数の積分

積分の計算は「被積分関数の型を見て処理法を選ぶ」のが基本になる。代表的な型と処理法をまとめる。

## 1. 型別の処理法

| 被積分関数の型 | 処理法 |
| --- | --- |
| 分数式で分子の次数 ≧ 分母の次数 | 先に割り算して**帯分数化**（整式 + 真分数式）する |
| 分数式で分母が因数分解できる | **部分分数分解**：$\dfrac{1}{(x - a)(x - b)} = \dfrac{1}{a - b}\left(\dfrac{1}{x - a} - \dfrac{1}{x - b}\right)$ の形に割る |
| $\dfrac{f'(x)}{f(x)}$ の形 | $\displaystyle \int \frac{f'(x)}{f(x)}\, dx = \log \|f(x)\| + C$（分子が分母の微分になっているかをまず確認） |
| $\sin^2 x$、$\cos^2 x$ | 半角公式で降次：$\sin^2 x = \dfrac{1 - \cos 2x}{2}$、$\cos^2 x = \dfrac{1 + \cos 2x}{2}$ |
| $\sin^m x \cos^n x$（どちらか奇数乗） | 奇数乗の側を1つ残して $t = \cos x$（または $\sin x$）と置換；両方偶数乗なら半角で降次 |
| $\sqrt{a^2 - x^2}$ を含む | $x = a\sin\theta$ と置換（根号が $a\cos\theta$ になって外れる） |
| $\sqrt{x}$、$\sqrt{ax + b}$ を含む | 根号全体を $t$ と置く：$t = \sqrt{ax + b}$ とすると $x$ は $t$ の2次式になり有理関数化できる |
| $\log x$ 単体 | 部分積分（$1 \cdot \log x$ と見て $\displaystyle \int \log x\, dx = x\log x - x + C$） |

## 2. 処理の選び方（手順）

1. まず整式の積分・基本公式に帰着できないか見る（帯分数化、展開、恒等式変形）。
2. $f(g(x)) \cdot g'(x)$ の構造が見えたら置換積分、積の形で片方を微分すると簡単になるなら部分積分。
3. 分数式は部分分数分解、三角関数は次数の下げ方、根号は置換、という型ごとの定石に当てはめる。

計算後は微分して被積分関数に戻るか検算する習慣をつけると、符号や係数のミスを防げる。

## 易错点

- [ ] 分数式を帯分数化せずに部分分数分解しようとする（分子の次数 ≧ 分母のときは先に割り算）
- [ ] $\dfrac{f'(x)}{f(x)}$ 型で $\log$ の中の絶対値を落とす
- [ ] 半角公式の符号（$\sin^2$ は $1 - \cos 2x$、$\cos^2$ は $1 + \cos 2x$）を取り違える
- [ ] 根号の置換で $dx$ の変換（$dx = g'(t)\, dt$）を忘れる
