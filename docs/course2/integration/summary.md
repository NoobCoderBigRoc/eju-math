# 積分法要点总结

考前确认三件事：被積分関数の型から処理法を即座に選べること、定積分の区間処理（換元時の付け替え・絶対値の分割）、面積・体積・弧長の公式の使い分け。

## 公式・定理清单

### 不定積分と定積分

- $\int x^n dx = \dfrac{x^{n + 1}}{n + 1} + C$（$n \ne -1$）、$\int \dfrac{1}{x} dx = \log|x| + C$、$\int e^x dx = e^x + C$ —— 基本公式は絶対値まで含めて正確に
- 微積分学の基本定理：$\int_a^b f(x)\, dx = F(b) - F(a)$ —— 区間を入れ替えると符号が変わり、$\int_a^a = 0$
- 対称区間では奇関数の積分は $0$、偶関数は片側の2倍 —— 計算を始める前に形を見る
- 置換積分：$f(g(x))\, g'(x)$ の構造を見たら $t = g(x)$ —— 定積分では積分区間も $t$ の範囲に付け替える
- 部分積分：$\int f g' = fg - \int f' g$ —— 多項式×指数・三角では多項式側を微分する。$\log x$ 単体も部分積分（$1 \cdot \log x$ と見る）
- $\int \dfrac{f'(x)}{f(x)}\, dx = \log |f(x)| + C$ —— 分子が分母の微分になっていないかをまず確認する
- 分数式は分子の次数 ≧ 分母なら帯分数化、因数分解できる分母は部分分数分解 —— 手順の順序を守る
- $\sin^2 x = \dfrac{1 - \cos 2x}{2}$、$\cos^2 x = \dfrac{1 + \cos 2x}{2}$ —— 三角の偶数冪は半角で降次、奇数冪を含む積は1つ残して置換する

### 積分の応用

- 面積：$S = \int_a^b |f(x) - g(x)|\, dx$ —— 交点で区間を決め、区間ごとに上下を確認する
- 回転体の体積（$x$ 軸まわり）：$V = \pi \int_a^b \{f(x)\}^2 dx$ —— $\pi$ と2乗を落とさない。断面積が分かる立体は $V = \int_a^b S(x)\, dx$
- 曲線の長さ：$L = \int_a^b \sqrt{1 + \{f'(x)\}^2}\, dx$；媒介変数では $L = \int_\alpha^\beta \sqrt{\left(\dfrac{dx}{dt}\right)^2 + \left(\dfrac{dy}{dt}\right)^2}\, dt$ —— 根号の中が完全平方式になる形が多い
- 極座標の面積 $S = \dfrac{1}{2}\int r^2 \, d\theta$ —— 式と曲線の極方程式と連携する

## 解法パターン

- **型判定型**：積分を計算する → 帯分数化・部分分数・$f'/f$ 型・置換・部分積分のどれに当てはまるかを被積分関数の形から先に決める
- **面積型**：2曲線で囲まれた部分 → 交点を求めて区間を区切り、各区間で「上 − 下」を積分する。$y$ 軸との面積は $x$ を $y$ の関数として積分する
- **回転体型**：回転体の体積 → 回転軸を確認し、$\pi \int \{f(x)\}^2$ の形に立てる（$y$ 軸まわりは変数を入れ替える）
- **弧長型**：曲線の長さ → 表示（$y = f(x)$ / 媒介変数 / 極座標）に応じた公式を選び、根号の中を完全平方式に整理してから積分する
- **絶対値つき定積分型**：$|f(x)|$ を含む → 符号が変わる点で区間を分割してから積分する

## 考前注意

- [ ] $\int \dfrac{1}{x} dx = \log|x| + C$ の絶対値（对数里的绝对值别丢）
- [ ] 置換積分で定積分の区間を付け替えない（定积分换元忘记换限）
- [ ] 面積は「上－下」の符号付きでなく絶対値で積む（面积取上减下的正值，分段确认上下）
- [ ] 回転体の $\pi$ と $\{f(x)\}^2$ の付け忘れ（旋转体公式里的 π 与平方别漏）
- [ ] 曲線の長さで $\sqrt{A^2} = |A|$ の絶対値と、媒介変数・極座標での積分区間の直し忘れ
