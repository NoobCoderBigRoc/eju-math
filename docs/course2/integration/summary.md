# 積分法要点总结

考前确认三件事：能按被積分関数的型立即选出处理法、定積分的区间处理（换元时同步换限・含绝对值时分割区间）、面積・体積・弧長公式的选用区分。

## 公式・定理清单

### 不定積分と定積分

- $\int x^n dx = \dfrac{x^{n + 1}}{n + 1} + C$（$n \ne -1$）、$\int \dfrac{1}{x} dx = \log|x| + C$、$\int e^x dx = e^x + C$ —— 基本公式要连绝对值一起记准确
- 微積分学の基本定理：$\int_a^b f(x)\, dx = F(b) - F(a)$ —— 交换区间上下限符号改变，且 $\int_a^a = 0$
- 对称区间上奇関数的積分为 $0$、偶関数等于一侧的两倍 —— 动手计算前先看形式
- 置換積分：看到 $f(g(x))\, g'(x)$ 的结构就设 $t = g(x)$ —— 定積分时积分区间也要换成 $t$ 的范围
- 部分積分：$\int f g' = fg - \int f' g$ —— 多项式×指数・三角时对多项式一侧求导；$\log x$ 单独出现时也用部分積分（看作 $1 \cdot \log x$）
- $\int \dfrac{f'(x)}{f(x)}\, dx = \log |f(x)| + C$ —— 先确认分子是不是分母的导数
- 分式：分子次数 ≧ 分母时先帯分数化（化为带分式），分母能因数分解时作部分分数分解 —— 按顺序处理
- $\sin^2 x = \dfrac{1 - \cos 2x}{2}$、$\cos^2 x = \dfrac{1 + \cos 2x}{2}$ —— 三角函数的偶次幂用半角公式降次，含奇次幂的乘积留一个因子作置換

### 積分の応用

- 面積：$S = \int_a^b |f(x) - g(x)|\, dx$ —— 用交点定区间，逐区间确认上下
- 旋转体的体积（绕 $x$ 轴）：$V = \pi \int_a^b \{f(x)\}^2 dx$ —— $\pi$ 与平方都别漏；已知截面积的立体用 $V = \int_a^b S(x)\, dx$
- 曲線的长度：$L = \int_a^b \sqrt{1 + \{f'(x)\}^2}\, dx$；参数形式为 $L = \int_\alpha^\beta \sqrt{\left(\dfrac{dx}{dt}\right)^2 + \left(\dfrac{dy}{dt}\right)^2}\, dt$ —— 根号内多半能凑成完全平方式
- 極座標的面積 $S = \dfrac{1}{2}\int r^2 \, d\theta$ —— 与「式と曲線」中的極方程式联动

## 解法パターン

- **按型判定**：计算積分 → 先按被積分関数的形式判定属于帯分数化・部分分数・$f'/f$ 型・置換・部分積分中的哪一种
- **面積型**：两曲线围成的部分 → 求交点划定区间，各区间按「上 − 下」積分；与 $y$ 轴围成的面積把 $x$ 看作 $y$ 的函数来積分
- **旋转体型**：求旋转体的体积 → 先确认旋转轴，再列成 $\pi \int \{f(x)\}^2$ 的形式（绕 $y$ 轴时交换变量）
- **弧長型**：求曲線长度 → 按表示形式（$y = f(x)$ / 媒介変数 / 極座標）选公式，把根号内整理成完全平方式后再積分
- **含绝对值的定積分型**：含 $|f(x)|$ → 在变号点处分割区间再積分

## 考前注意

- [ ] $\int \dfrac{1}{x} dx = \log|x| + C$ 的绝对值别丢
- [ ] 定積分换元时忘记同步换限
- [ ] 面積不按绝对值处理（应分段确认上下、取正值）
- [ ] 旋转体体积漏 $\pi$ 或漏 $\{f(x)\}^2$ 的平方
- [ ] 曲線长度中漏 $\sqrt{A^2} = |A|$ 的绝对值，或参数・極座標下忘记调整積分区间
