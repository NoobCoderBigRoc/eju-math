# 不定積分と定積分

## 1. 基本性質

- $\int x^n dx = \dfrac{x^{n + 1}}{n + 1} + C$（$n \ne -1$）；$\int \dfrac{1}{x} dx = \log|x| + C$；$\int e^x dx = e^x + C$；$\int \sin x\, dx = -\cos x + C$；$\int \cos x\, dx = \sin x + C$
- 定积分与微积分基本定理：$\int_a^b f(x)\, dx = F(b) - F(a)$；交换限符号变，$\int_a^a = 0$。
- 偶函数/奇函数在对称区间：奇函数积分为 0，偶函数为一侧的 2 倍。

## 2. 置換積分法・部分積分法

- 置換積分（换元）：见到 $f(g(x)) g'(x)$ 结构令 $t = g(x)$；定积分换元要同时换积分限。
- 部分積分（分部）：$\int f g' = fg - \int f' g$；多项式×指数/三角时对多项式求导、另一边积分（优先级：対数 > 逆三角 > 多項式 > 指数・三角）。

## 3. いろいろな関数の積分

分数式先带分数化/部分分数分解；$\sqrt{}$ 型用三角/双曲置换或根号整体置换；$\sin^2, \cos^2$ 先用半角降次。

??? example "演習：定積分"
    **问题**

    $\displaystyle \int_0^1 (x^2 + 1)\, dx$ の値を求めよ。

    **答案**

    $\dfrac{4}{3}$

    **思路**

    找原函数后代上下限。

    **解答**

    $$\int_0^1 (x^2 + 1)\, dx = \left[\frac{x^3}{3} + x\right]_0^1 = \frac{1}{3} + 1 = \frac{4}{3}$$

??? example "演習：部分積分"
    **问题**

    $\displaystyle \int_0^1 x e^x\, dx$ の値を求めよ。

    **答案**

    $1$

    **思路**

    $\int x e^x = x e^x - \int e^x = (x - 1)e^x$（对 $x$ 求导、对 $e^x$ 积分）。

    **解答**

    $$\left[(x - 1)e^x\right]_0^1 = 0 \cdot e - (-1) \cdot 1 = 1$$

## 易错点

- [ ] 置換積分で定積分の区間を付け替えない（定积分换元忘记换限）
- [ ] 絶対値つき関数の定積分は符号で区間を分割する（含绝对值的定积分按符号分段）
- [ ] $\int \dfrac{1}{x} dx = \log|x| + C$ の絶対値（对数里的绝对值别丢）
