# 積分法简介（数学II・III）

积分是微分的逆运算，也是面积・体積・曲線の長さ的计算器，与項目 19 由微積分学の基本定理相连。

本项目的具体内容都在下面的细目页中（左侧导航点开「20. 積分法」即可逐层展开）。

## 在 EJU 中的位置

本项与微分法并列 Course 2 的核心，计算量是全卷最重的一类：積分計算本身讲究「看型选法」，应用段（面積・体積・曲線の長さ）则把画图、定区间、列式连成一串。衔接关系有三条：被積分関数は項目 17 いろいろな関数的函数群，微分公式记反了这里全盘出错；項目 16 的媒介変数表示・極座標在这里收尾成弧長与面積；定積分的背景与評価又时时回到項目 18 極限。复习时与微分法配对进行最有效。
