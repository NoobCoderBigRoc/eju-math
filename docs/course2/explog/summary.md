# 指数関数・対数関数要点总结

考前确认本页：指数法則と対数の性質、「同底にそろえて比べる」解法の型、真数条件を落とさない運用。

## 公式・定理清单

### 指数関数

- 指数の拡張：$a^0 = 1$（$a \ne 0$）、$a^{-n} = \dfrac{1}{a^n}$、$a^{1/n} = \sqrt[n]{a}$、$a^{m/n} = \sqrt[n]{a^m}$ —— 分数指数の定義は底 $a > 0$ が前提
- 指数法則（$a, b > 0$）：$a^r \cdot a^s = a^{r + s}$、$\dfrac{a^r}{a^s} = a^{r - s}$、$(a^r)^s = a^{rs}$、$(ab)^r = a^r b^r$、$\left(\dfrac{a}{b}\right)^r = \dfrac{a^r}{b^r}$
- 指数関数 $y = a^x$（$a > 0, a \ne 1$）：定義域は実数全体、値域は $y > 0$、点 $(0, 1)$ を通り漸近線は $y = 0$ —— $a > 1$ で増加、$0 < a < 1$ で減少

### 対数関数

- 対数の定義：$a^p = M \iff \log_a M = p$（$a > 0, a \ne 1, M > 0$）—— 真数 $M > 0$ が全ての出発点
- $\log_a MN = \log_a M + \log_a N$ —— 積の対数は対数の和になるが、$\log_a(M + N)$ は分解できない
- $\log_a \dfrac{M}{N} = \log_a M - \log_a N$
- $\log_a M^r = r \log_a M$
- 底の変換公式：$\log_a b = \dfrac{\log_c b}{\log_c a}$ —— 底をそろえる必要があるとき使う
- 対数関数 $y = \log_a x$：定義域は $x > 0$、点 $(1, 0)$ を通り漸近線は $x = 0$ —— $y = a^x$ の逆関数で、グラフは直線 $y = x$ に関して対称
- 対数関数の平行移動：$y = \log_a (x - p) + q$ の定義域は $x > p$、漸近線は $x = p$ —— 移動量は定義域と漸近線のずれで読む
- 底が逆数の対数：$\log_{1/a} x = -\log_a x$ —— グラフ同士は $x$ 軸に関して対称になる
- 常用対数：$M$ の桁数は $\lfloor \log_{10} M \rfloor + 1$ —— 整数部分がそのまま桁数にはならない

## 解法パターン

- **指数方程式の置換**：$4^x$ と $2^x$ が混ざっていたら → $t = 2^x$（$t > 0$）と置いて $t$ の 2 次方程式に直す
- **指数の大小・不等式**：底をそろえて指数同士を比べる → $a > 1$ では向き不変、$0 < a < 1$ では向きが逆転する
- **対数の計算**：対数の和・差の形は → 性質を逆向きに使って積・商の 1 つの対数にまとめる
- **対数の大小比較**：底の違う対数同士は → 底の変換公式で底をそろえてから真数を比べる
- **対数方程式・不等式**：まず全ての真数条件を書き → 底をそろえて真数同士を比べ → 最後に真数条件との共通部分を取る
- **桁数・最高位の数字**：大きな累乗が出たら → 常用対数を取って整数部分と小数部分に分け、整数部分 $+1$ が桁数

## 考前注意

- [ ] 真数条件（真数 $> 0$）は最初に書いて最後まで落とさず、解との共通部分を取る
- [ ] 底が $0 < a < 1$ のとき、脱対数・指数の比較で不等号の向きが逆転する
- [ ] $\log_a(M + N)$ は $\log_a M + \log_a N$ に分解できない
- [ ] 負の指数は逆数の意味であって、$a^{-n}$ を $-a^n$ と読み違えない
- [ ] 桁数は常用対数の整数部分 $+1$ である
