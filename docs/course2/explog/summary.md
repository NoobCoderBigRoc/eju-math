# 指数関数・対数関数要点总结

考前确认本页：指数法則与対数的性質、「化为同底再比较」的解法套路，以及不丢真数条件的操作。

## 公式・定理清单

### 指数関数

- 指数の拡張：$a^0 = 1$（$a \ne 0$）、$a^{-n} = \dfrac{1}{a^n}$、$a^{1/n} = \sqrt[n]{a}$、$a^{m/n} = \sqrt[n]{a^m}$ —— 分数指数的定义以底 $a > 0$ 为前提
- 指数法則（$a, b > 0$）：$a^r \cdot a^s = a^{r + s}$、$\dfrac{a^r}{a^s} = a^{r - s}$、$(a^r)^s = a^{rs}$、$(ab)^r = a^r b^r$、$\left(\dfrac{a}{b}\right)^r = \dfrac{a^r}{b^r}$
- 指数関数 $y = a^x$（$a > 0, a \ne 1$）：定義域是全体实数，値域是 $y > 0$，过点 $(0, 1)$，漸近線是 $y = 0$ —— $a > 1$ 时递增，$0 < a < 1$ 时递减

### 対数関数

- 対数の定義：$a^p = M \iff \log_a M = p$（$a > 0, a \ne 1, M > 0$）—— 真数条件 $M > 0$ 是一切的出发点
- $\log_a MN = \log_a M + \log_a N$ —— 积的対数等于対数的和，但 $\log_a(M + N)$ 不能分解
- $\log_a \dfrac{M}{N} = \log_a M - \log_a N$
- $\log_a M^r = r \log_a M$
- 底の変換公式：$\log_a b = \dfrac{\log_c b}{\log_c a}$ —— 需要统一底数时使用
- 対数関数 $y = \log_a x$：定義域是 $x > 0$，过点 $(1, 0)$，漸近線是 $x = 0$ —— 它是 $y = a^x$ 的逆関数，图象关于直線 $y = x$ 对称
- 対数関数の平行移動：$y = \log_a (x - p) + q$ 的定義域是 $x > p$，漸近線是 $x = p$ —— 平移量从定義域与漸近線的偏移读出
- 底为倒数的対数：$\log_{1/a} x = -\log_a x$ —— 两图象关于 $x$ 轴对称
- 常用対数：$M$ 的位数是 $\lfloor \log_{10} M \rfloor + 1$ —— 整数部分本身不是位数，要 $+1$

## 解法パターン

- **指数方程式的换元**：$4^x$ 与 $2^x$ 混杂时 → 设 $t = 2^x$（$t > 0$），化为关于 $t$ 的 2 次方程式
- **指数的大小与不等式**：化为同底后比较指数 → $a > 1$ 时方向不变，$0 < a < 1$ 时方向反转
- **対数计算**：遇到対数的和、差形式 → 逆用性質合并成一个积、商的対数
- **対数大小比较**：底数不同的対数之间 → 先用底の変換公式统一底数，再比较真数
- **対数方程式・不等式**：先写出全部真数条件 → 化为同底比较真数 → 最后与真数条件取交集
- **位数与最高位数字**：遇到大的幂 → 取常用対数，分成整数部分与小数部分，整数部分 $+1$ 即位数

## 考前注意

- [ ] 真数条件（真数 $> 0$）要一开始就写出并保留到最后，与解取交集
- [ ] 底在 $0 < a < 1$ 时，脱対数、比较指数时不等号方向反转
- [ ] $\log_a(M + N)$ 不能分解为 $\log_a M + \log_a N$
- [ ] 负指数表示倒数，不要把 $a^{-n}$ 误读成 $-a^n$
- [ ] 位数是常用対数的整数部分 $+1$
