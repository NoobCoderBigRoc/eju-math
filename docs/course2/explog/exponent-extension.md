# 指数の拡張

## 1. 拡張の段階

指数は「指数法則 $a^{m + n} = a^m \cdot a^n$ がそのまま成り立つように」という方針で、正の整数から順に拡張されてきた（以下 $a > 0$）。

| 指数の範囲 | 定義 | 根拠 |
| --- | --- | --- |
| 正の整数 $n$ | $a^n$ は $a$ を $n$ 個掛けたもの | — |
| $0$ | $a^0 = 1$ | $a^{n} = a^{n + 0} = a^n \cdot a^0$ を満たすため |
| 負の整数 $-n$ | $a^{-n} = \dfrac{1}{a^n}$ | $a^n \cdot a^{-n} = a^0 = 1$ を満たすため |
| 有理数 $\dfrac{m}{n}$ | $a^{1/n} = \sqrt[n]{a}$、$a^{m/n} = \sqrt[n]{a^m}$ | $\left(a^{1/n}\right)^n = a$ を満たす正の数として定める |
| 実数 | 有理数指数の極限として定義される | $a^{\sqrt{2}}$ などもこの方法で意味を持つ |

## 2. 底が正である理由

分数指数では底 $a > 0$ が必須である。例えば $a = -1$ とすると $(-1)^{1/2}$ は実数にならず、$(-8)^{1/3}$ のような場合も指数法則が崩れる（$\left((-8)^{1/3}\right)^2$ と $\left((-8)^2\right)^{1/6}$ で値が一致しない）。また $0^0$ は定義されず、$0$ の負の指数も存在しない。実数範囲で指数を一貫して扱うため、底は正に限る。

## 3. 指数法則（有理数・実数指数でも成立）

$a, b > 0$、$r, s$ は実数として：

- $a^r \cdot a^s = a^{r + s}$
- $\dfrac{a^r}{a^s} = a^{r - s}$
- $(a^r)^s = a^{rs}$
- $(ab)^r = a^r b^r$
- $\left(\dfrac{a}{b}\right)^r = \dfrac{a^r}{b^r}$

## 4. 累乗根との関係

$a^{1/n} = \sqrt[n]{a}$ なので、分数指数の計算は累乗根の計算と同じである。根号の計算規則（$\sqrt[n]{a}\sqrt[n]{b} = \sqrt[n]{ab}$ など）は、上の指数法則の言い換えとして理解するとよい。指数関数 $y = a^x$ の定義域が全実数になるのは、この拡張があってこそである。

## 易错点

- [ ] $a^{m/n}$ の定義は $a > 0$ が前提（分数指数的定义以底数为正为前提）
- [ ] $(a^r)^s = a^{rs}$ を負の底に適用する（底が負だと法則自体が成り立たない場合がある）
- [ ] $a^0 = 1$ の例外（$a = 0$ のとき $0^0$ は定義されない）
- [ ] $a^{-n}$ を $-a^n$ と読み違える（負の指数は逆数の意味）
