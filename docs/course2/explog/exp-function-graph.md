# 指数関数とそのグラフ

$y = a^x$（$a > 0, a \ne 1$）：

- 定义域全体实数、值域正数；恒过 $(0, 1)$；渐近线 $y = 0$
- $a > 1$ 时递增、$0 < a < 1$ 时递减
- 方程/不等式：化为同底比较指数（底 $> 1$ 保序，$< 1$ 反序）

**演習：指数方程式**

$4^x - 3 \cdot 2^x + 2 = 0$ を解け。

??? example "思路・解答"
    **答案**

    $x = 0, 1$

    **思路**

    $4^x = (2^x)^2$，令 $t = 2^x > 0$ 化为关于 $t$ 的二次方程。

    **解答**

    $$t^2 - 3t + 2 = 0 \;\Longrightarrow\; (t - 1)(t - 2) = 0 \;\Longrightarrow\; t = 1, 2 \;\Longrightarrow\; x = 0, 1$$

## 易错点

- [ ] 底が1より小さいとき指数の大小が逆になる（底小于 1 时指数大小关系反转）
