# 指数関数・対数関数简介（数学II）

指数与对数互为表里：图像关于直线 y = x 对称，方程与不等式都靠「同底比较」解决，常用対数负责位数估算。

本项目的具体内容都在下面的细目页中（左侧导航点开「10. 指数関数・対数関数」即可逐层展开）。

## 在 EJU 中的位置

本项目分量中等，题型气质是概念意识与计算各半：単調性（底大于 1 还是小于 1）与真数条件这条定义域意识贯穿所有方程式・不等式，解法本身则收敛到「同底にそろえて比べる」一个型。
它与関数项目的逆関数概念直接相连（指数と対数は互いに逆関数），并作为微分法・積分法中指対関数の微積分の地基；常用対数的桁数处理也常与数列的等比数列问题联动出现。
