## 1. ベクトルと内積（平面・空間共通）

对 $\vec{a} = (a_1, a_2)$、$\vec{b} = (b_1, b_2)$（空间再加第三个成分），和、差、数乘都按成分逐个算。

$$
\vec{a} \cdot \vec{b} = |\vec{a}|\,|\vec{b}|\cos\theta = a_1 b_1 + a_2 b_2 \quad \text{（空間では } +\, a_3 b_3 \text{）}
$$

- 垂直条件：$\vec{a} \cdot \vec{b} = 0$（两者都不是零向量时）
- 平行条件（平面）：$\vec{a} \parallel \vec{b} \iff a_1 b_2 - a_2 b_1 = 0$
- 大小：$|\vec{a}| = \sqrt{\vec{a} \cdot \vec{a}}$。内积满足分配律，但向量**没有除法**。

## 2. 位置ベクトルと図形

以原点为 $O$，点 $A$、$B$ 的位置向量记 $\vec{a}$、$\vec{b}$。把 $AB$ 按 $m : n$ 内分的点的位置向量是 $\dfrac{n\vec{a} + m\vec{b}}{m + n}$，中点是 $\dfrac{\vec{a} + \vec{b}}{2}$（权重规则与 [図形と方程式](geometry-equation.md) 相同）。

三点 $A$、$B$、$C$ 共线的条件是能写成 $\overrightarrow{OC} = s\vec{a} + t\vec{b}$（$s + t = 1$）。三角形面积为

$$
S = \frac{1}{2}\sqrt{|\vec{a}|^2 |\vec{b}|^2 - (\vec{a} \cdot \vec{b})^2}
$$

## 3. ベクトル方程式

过点 $A(\vec{a})$、方向向量为 $\vec{d}$ 的直线是 $\vec{p} = \vec{a} + t\vec{d}$。过点 $A$ 且与向量 $\vec{n}$ 垂直的直线（平面）是 $\vec{n} \cdot (\vec{p} - \vec{a}) = 0$。空间中形式相同：平面方程式 $ax + by + cz + d = 0$ 的法线向量就是 $(a, b, c)$。

## 例题（演习）

??? example "例题 1：内積となす角（平面）"
    $\vec{a} = (1, 2)$、$\vec{b} = (3, -1)$ のなす角 $\theta$ の $\cos\theta$ を求めよ。

    **思路**：内积既用成分算、又用大小与夹角表示，两边对照。

    **解答**：$\vec{a} \cdot \vec{b} = 3 - 2 = 1$，$|\vec{a}| = \sqrt{5}$，$|\vec{b}| = \sqrt{10}$，所以 $\cos\theta = \dfrac{1}{\sqrt{50}} = \dfrac{\sqrt{2}}{10}$。

    **答案**：$\cos\theta = \dfrac{\sqrt{2}}{10}$

??? example "例题 2：内積（空間）"
    $\vec{a} = (1, 2, -1)$、$\vec{b} = (2, 0, 1)$ の内積となす角の $\cos$ を求めよ。

    **思路**：空间内积同样是各成分积之和，别漏第三个成分。

    **解答**：$\vec{a} \cdot \vec{b} = 2 + 0 - 1 = 1$。$|\vec{a}| = \sqrt{6}$、$|\vec{b}| = \sqrt{5}$，所以 $\cos\theta = \dfrac{1}{\sqrt{30}}$。

    **答案**：内積 $1$、$\cos\theta = \dfrac{1}{\sqrt{30}}$

??? example "例题 3：垂直条件から定数を決める"
    $\vec{a} = (2, 1)$、$\vec{b} = (1, -3)$ のとき、$\vec{a} + t\vec{b}$ が $\vec{a}$ と垂直になるような $t$ を求めよ。

    **思路**：用垂直条件「内積为 0」列方程。

    **解答**：$(\vec{a} + t\vec{b}) \cdot \vec{a} = |\vec{a}|^2 + t\,\vec{a} \cdot \vec{b} = 5 + t(2 - 3) = 5 - t = 0$，所以 $t = 5$。

    **答案**：$t = 5$

## 易错点

- [ ] 把 $(\vec{a} \cdot \vec{b})\vec{c}$ 当作向量的乘法结合律（结果是向量，意义不同）
- [ ] 混淆平行条件与垂直条件的公式
- [ ] 内分点的权重写反（与図形と方程式同一注意点）
- [ ] 空间向量计算时漏掉第三个成分
