# 関数とその極限

## 1. 関数の極限

- $\dfrac{0}{0}$ 型：因数分解约分，或有理化后再代入。
- 重要极限：$\lim_{x \to 0} \dfrac{\sin x}{x} = 1$、$\lim_{x \to 0} \dfrac{e^x - 1}{x} = 1$、$\lim_{x \to 0} \dfrac{\log(1 + x)}{x} = 1$（$x$ 必须以弧度/自然对数为前提）。
- 片侧极限（左極限・右極限）不一致则极限不存在；挟み撃ち（夹逼）处理 $\dfrac{\sin}{}$ 型估值。

## 2. 関数の連続性

$f$ 在 $x = a$ 连续 $\iff \lim_{x \to a} f(x) = f(a)$（含定义域内）。中間値の定理（介值定理）：连续函数在 $[a, b]$ 上取遍 $f(a)$ 与 $f(b)$ 之间的一切值——判定方程实根存在性的工具。

??? example "演習：関数の極限"
    **问题**

    $\displaystyle \lim_{x \to 0} \frac{\sin 3x}{x}$ を求めよ。

    **答案**

    $3$

    **思路**

    凑出 $\dfrac{\sin 3x}{3x}$ 的形：整体乘以 3。

    **解答**

    $$\lim_{x \to 0} \frac{\sin 3x}{x} = 3 \lim_{x \to 0} \frac{\sin 3x}{3x} = 3 \cdot 1 = 3$$

## 易错点

- [ ] $\lim \dfrac{\sin x}{x} = 1$ は弧度法が前提（该公式以弧度制为前提）
- [ ] 分段関数の分岐点では左・右極限を別に調べる（分段点要分别查左右极限）
