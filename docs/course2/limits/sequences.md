# 数列とその極限

## 1. 数列の極限

等比数列 $r^n$：$|r| < 1$ 时收敛于 0、$r = 1$ 时为 1、$r \le -1$ 或 $r > 1$ 时发散（$r = -1$ 是振動）。分数式数列的极限：分子分母同除以最高次项。有理化处理根号差：$\sqrt{n + 1} - \sqrt{n} = \dfrac{1}{\sqrt{n + 1} + \sqrt{n}} \to 0$。

## 2. 無限級数の和

无穷级数收敛 $\iff$ 部分和 $S_n$ 收敛，且必须 $a_n \to 0$（必要条件）。无穷等比级数：$|r| < 1$ 时和 $= \dfrac{a}{1 - r}$，否则发散。部分分数/阶差型级数用「$S_n$ 望远镜」后取极限。

??? example "演習：無限等比級数"
    **问题**

    無限等比級数 $1 + \dfrac{1}{3} + \dfrac{1}{9} + \cdots$ の和を求めよ。

    **答案**

    $\dfrac{3}{2}$

    **思路**

    初项 1、公比 $\dfrac{1}{3}$，$|r| < 1$ 可用和公式。

    **解答**

    $$S = \frac{1}{1 - \frac{1}{3}} = \frac{3}{2}$$

??? example "演習：数列の極限"
    **问题**

    $\displaystyle \lim_{n \to \infty} (\sqrt{n + 1} - \sqrt{n})$ を求めよ。

    **答案**

    $0$

    **思路**

    $\infty - \infty$ 型，先乘共轭有理化再估。

    **解答**

    $$\sqrt{n + 1} - \sqrt{n} = \frac{1}{\sqrt{n + 1} + \sqrt{n}} \to \frac{1}{\infty} = 0$$

## 易错点

- [ ] 級数が収束するための $a_n \to 0$ は必要条件（だけ）であること（$a_n\to 0$ 只是级数收敛的必要条件）
- [ ] $(\sqrt{n + a} - \sqrt{n + b})$ は有理化してから（根号差的极限先有理化）
