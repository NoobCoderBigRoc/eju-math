# 極限简介（数学III）

微积分的语言基础：数列の極限（与無限級数）与関数の極限（与連続性）。

本项目的具体内容都在下面的细目页中（左侧导航点开「18. 極限」即可逐层展开）。

## 在 EJU 中的位置

本项是数学III 的入口，分量不在自身题量，而在它是微分法・積分法两大项目的语言前提：导数的定义、重要极限都是后续公式的源头。单独出题时多为小型极限计算与連続性的判定；向前与数列（等比数列・漸化式）直接相连，向后所有微积分的题都默认这里的型处理（不定形、有理化、挟み撃ち）已经过关。
