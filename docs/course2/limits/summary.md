# 極限要点总结

考前确认三件事：不定形の処理パターン（最高次で割る・有理化・部分和）、3つの重要極限、連続性と中間値の定理の使いどころ。ここは微分法の前提なので、型の判定を速く正確に。

## 公式・定理清单

### 数列とその極限

- 等比数列 $r^n$：$|r| < 1$ で $0$ に収束、$r = 1$ で $1$、$r \le -1$ または $r > 1$ で発散（$r = -1$ は振動）—— まず $|r|$ と $1$ の大小で判定する
- 分数式の数列の極限は分子・分母を最高次項で割る —— $\infty/\infty$ 型の定石
- 根号の差：$\sqrt{n + 1} - \sqrt{n} = \dfrac{1}{\sqrt{n + 1} + \sqrt{n}} \to 0$ —— $\infty - \infty$ 型は共役を掛けて有理化する
- 無限級数が収束すれば $a_n \to 0$（必要条件）—— 逆は成り立たないので、$a_n \to 0$ だけでは収束と言えない
- 無限等比級数：$|r| < 1$ のとき和 $= \dfrac{a}{1 - r}$ —— 条件を外すと公式は使えない
- 部分分數・階差型の級数は部分和 $S_n$ が望遠鏡式に相殺する —— $S_n$ を書いてから極限を取る

### 関数とその極限

- $\displaystyle \lim_{x \to 0} \frac{\sin x}{x} = 1$ —— 前提は弧度法。$\sin kx$ の形は $\dfrac{\sin kx}{kx}$ を作って係数を外に出す
- $\displaystyle \lim_{x \to 0} \frac{e^x - 1}{x} = 1$、$\displaystyle \lim_{x \to 0} \frac{\log(1 + x)}{x} = 1$ —— 指数・対数の基本極限
- $\dfrac{0}{0}$ 型は因数分解で約分するか有理化してから代入する —— 不定形のまま代入しない
- 左側極限と右側極限が一致しなければ極限は存在しない —— 分段関数・絶対値では片側ずつ調べる
- 連続の3条件：$f(a)$ が定義される、$\lim_{x \to a} f(x)$ が存在する、その2つが等しい —— 1つでも欠ければ不連続
- 中間値の定理：閉区間 $[a, b]$ で連続なら $f(a)$ と $f(b)$ の間の値をすべて取る —— 解の存在証明に使うが、個数は保証しない

## 解法パターン

- **数列の不定形型**：$\infty/\infty$ は最高次で割り、$\infty - \infty$（根号の差）は有理化する → 形を整えてから評価する
- **級数の和型**：和を求める → まず部分和 $S_n$ を閉じた形にし（等比・望遠鏡）、その極限を取る
- **重要極限への帰着型**：$\sin$・$e^x$・$\log$ を含む $0/0$ 型 → $\dfrac{\sin x}{x}$ などの基本形が見えるよう分母分子をそろえる
- **解の存在証明型**：方程式 $f(x) = 0$ の解の存在を示す → 異符号になる両端の値を見つけ、中間値の定理を適用する
- **連続性の判定型**：分段関数の接続点 → 左側極限・右側極限・関数値の3つを並べて比較する

## 考前注意

- [ ] $\lim \dfrac{\sin x}{x} = 1$ は弧度法が前提（该公式以弧度制为前提）
- [ ] 級数が収束するための $a_n \to 0$ は必要条件（だけ）であること（$a_n\to 0$ 只是级数收敛的必要条件）
- [ ] $(\sqrt{n + a} - \sqrt{n + b})$ は有理化してから評価する（根号差的极限先有理化）
- [ ] 中間値の定理を「解がちょうど1つ」と読み替える（存在の保証のみで、個数は保証されない）
- [ ] 極限値と関数値を混同する（极限存在但不等于函数值时仍不连续）
