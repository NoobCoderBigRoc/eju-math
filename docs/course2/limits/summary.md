# 極限要点总结

考前确认三件事：不定形的处理套路（除以最高次项・有理化・部分和）、三个重要極限、連続性与中間値の定理的用处。这里是微分法的前提，型的判定要快而准。

## 公式・定理清单

### 数列とその極限

- 等比数列 $r^n$：$|r| < 1$ 时收敛于 $0$，$r = 1$ 时为 $1$，$r \le -1$ 或 $r > 1$ 时发散（$r = -1$ 时振荡）—— 先比较 $|r|$ 与 $1$ 的大小来判定
- 分式数列的極限：分子分母同除以最高次项 —— $\infty/\infty$ 型的定式
- 根号之差：$\sqrt{n + 1} - \sqrt{n} = \dfrac{1}{\sqrt{n + 1} + \sqrt{n}} \to 0$ —— $\infty - \infty$ 型乘共轭式有理化
- 無限級数收敛则 $a_n \to 0$（必要条件）—— 逆命题不成立，仅凭 $a_n \to 0$ 不能断定收敛
- 無限等比級数：$|r| < 1$ 时和 $= \dfrac{a}{1 - r}$ —— 不满足条件就不能用公式
- 部分分式・階差型的級数，其部分和 $S_n$ 会望远镜式相消 —— 先写出 $S_n$ 再取極限

### 関数とその極限

- $\displaystyle \lim_{x \to 0} \frac{\sin x}{x} = 1$ —— 前提是弧度法。遇 $\sin kx$ 的形式，凑出 $\dfrac{\sin kx}{kx}$ 再把系数提到外面
- $\displaystyle \lim_{x \to 0} \frac{e^x - 1}{x} = 1$、$\displaystyle \lim_{x \to 0} \frac{\log(1 + x)}{x} = 1$ —— 指数与对数的基本極限
- $\dfrac{0}{0}$ 型先因数分解约分或有理化再代入 —— 不要保持不定形直接代入
- 左極限与右極限不一致则極限不存在 —— 分段関数・絶対値要逐侧检查
- 連続的三个条件：$f(a)$ 有定义、$\lim_{x \to a} f(x)$ 存在、两者相等 —— 缺一即不連続
- 中間値の定理：在闭区间 $[a, b]$ 上連続，则取遍 $f(a)$ 与 $f(b)$ 之间的所有值 —— 用于证明解的存在性，但不保证个数

## 解法パターン

- **数列不定形型**：$\infty/\infty$ 同除最高次项，$\infty - \infty$（根号之差）作有理化 → 先整理形式再求值
- **級数求和型**：求和 → 先把部分和 $S_n$ 化成封闭形式（等比・望远镜相消），再取極限
- **归结到重要極限型**：含 $\sin$・$e^x$・$\log$ 的 $0/0$ 型 → 把分子分母凑齐，使 $\dfrac{\sin x}{x}$ 等基本形显现出来
- **解的存在性证明型**：证明方程 $f(x) = 0$ 有解 → 找两端异号的函数值，套用中間値の定理
- **連続性判定型**：分段関数的连接点 → 把左極限・右極限・函数值三者并列比较

## 考前注意

- [ ] $\lim \dfrac{\sin x}{x} = 1$ 的前提是弧度法（弧度制）
- [ ] $a_n \to 0$ 只是級数收敛的必要条件
- [ ] $(\sqrt{n + a} - \sqrt{n + b})$ 要先有理化再求值（根号差的极限先有理化）
- [ ] 把中間値の定理误读成「解恰好只有一个」（它只保证存在，不保证个数）
- [ ] 混淆極限值与函数值（极限存在但不等于函数值时仍不连续）
