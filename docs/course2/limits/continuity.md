# 関数の連続性

## 1. 連続の定義

関数 $f$ が $x = a$ で **連続** であるとは、次の3つがすべて満たされることである。

1. $f(a)$ が定義されている（$a$ が定義域に含まれる）
2. 極限 $\displaystyle \lim_{x \to a} f(x)$ が存在する（左側極限と右側極限が一致する）
3. $\displaystyle \lim_{x \to a} f(x) = f(a)$

区間 $I$ のすべての点で連続な関数を「$I$ で連続」という。多項式関数・三角関数・指数関数・対数関数はいずれも、その定義域の各点で連続である。また、連続関数の和・差・積・商（分母 ≠ 0）および合成関数も連続である。

## 2. 不連続の分類

$x = a$ で不連続になる場合は、どの条件が崩れたかで分類できる。

| 型 | 状況 | 例の形 |
| --- | --- | --- |
| 除去可能な不連続 | 極限は存在するが $f(a)$ が未定義、または値がずれている | $\dfrac{x^2 - 1}{x - 1}$ は $x = 1$ で未定義だが極限は $2$ |
| ジャンプ不連続 | 左側極限と右側極限が存在するが一致しない | 分段関数の接続点で値が跳ぶ |
| 無限大へ発散 | $|f(x)| \to \infty$ となる | $\dfrac{1}{x}$ の $x = 0$ |

判定は分段点・定義域の境界点ごとに、左側極限、右側極限、関数値の3つを並べて確認する手順で行う。

## 3. 中間値の定理

**中間値の定理**：関数 $f$ が閉区間 $[a, b]$ で連続ならば、$f(a)$ と $f(b)$ の間の任意の値 $k$ に対して、$f(c) = k$ となる $c$（$a < c < b$）が少なくとも1つ存在する。

使用条件は「**閉区間 $[a, b]$ 全体で連続**」であること（端点だけでなく区間内のすべての点で連続が必要）。

主な用途は方程式の解の存在証明：$f(x) = 0$ の解を示すには、$f(a)$ と $f(b)$ が異符号（$f(a) f(b) < 0$）となる $a, b$ を見つければ、$a$ と $b$ の間に解が存在する。ただし定理が保証するのは存在だけで、解の個数や値は分からない。

## 易错点

- [ ] 分段関数の分岐点では左・右極限を別に調べる（分段点要分别查左右极限）
- [ ] 中間値の定理を「解がちょうど1つ」と読み替える（存在の保証のみで、個数は保証されない）
- [ ] 極限値と関数値の混同（$\lim_{x \to a} f(x)$ が存在しても $f(a)$ と一致しなければ不連続）
- [ ] 中間値の定理の前提（閉区間で連続）を確認しない
