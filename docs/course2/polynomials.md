## 1. 式と証明

**恒等式**：$x$ 的恒等式成立 ⟺「两边同类项（同次项）的系数全部相等」。解法有系数比较法与代入足够多个数值的方法，按题目给的条件选。

**二項定理**（二项式定理）：

$$
(a + b)^n = \sum_{k=0}^{n} {}_n C_k\, a^{n-k} b^k
$$

通项是 ${}_n C_k\, a^{n-k} b^k$。只问某个系数的题目，先定出让次数符合要求的 $k$，再算组合数。

**分数式**：先约分再通分，前提是因数分解，且不要忘记分母 ≠ 0 的条件。

**等式・不等式的証明**：基本手法是作差后因数分解或配方。不等式 $a^2 + b^2 \geqq 2ab$ 与算术-几何平均关系 $\dfrac{a + b}{2} \geqq \sqrt{ab}$（$a, b > 0$）是不等式证明的高频起点。

## 2. 高次方程式

**剰余の定理**（余数定理）：多項式 $f(x)$ 除以 $x - \alpha$ 的余数是 $f(\alpha)$。**因数定理**：$f(\alpha) = 0 \iff f(x)$ 含有因式 $x - \alpha$。

**解と係数の関係**（根与系数关系，3 次方程式 $x^3 + px^2 + qx + r = 0$ 的解 $\alpha, \beta, \gamma$）：

$$
\alpha + \beta + \gamma = -p, \qquad \alpha\beta + \beta\gamma + \gamma\alpha = q, \qquad \alpha\beta\gamma = -r
$$

**複素数解の性質**：实系数方程若有虚数解 $a + bi$（$b \ne 0$），其共轭 $a - bi$ 也是解。二次方程判别式为负时，两解是共轭的一对虚数——求另一解时直接写共轭即可。

## 例题（演习）

??? example "例题 1：二項定理"
    $(2x - 1)^5$ の展開式における $x^3$ の係数を求めよ。

    **思路**：在通项 ${}_5C_k (2x)^{5-k} (-1)^k$ 中取 $5 - k = 3$，即 $k = 2$。

    **解答**：${}_5C_2 \cdot 2^3 \cdot (-1)^2 = 10 \times 8 = 80$。

    **答案**：$80$

??? example "例题 2：剰余の定理"
    $f(x) = x^3 - 2x^2 + ax - 3$ を $x - 2$ で割った余りが $5$ であるとき、$a$ の値を求めよ。

    **思路**：余数等于 $f(2)$，代入即得关于 $a$ 的一次方程。

    **解答**：$f(2) = 8 - 8 + 2a - 3 = 2a - 3 = 5$，所以 $a = 4$。

    **答案**：$a = 4$

??? example "例题 3：解と係数の関係"
    3次方程式 $x^3 - 6x^2 + 11x - 6 = 0$ の 3 つの解 $\alpha, \beta, \gamma$ について、$\alpha + \beta + \gamma$、$\alpha\beta + \beta\gamma + \gamma\alpha$、$\alpha\beta\gamma$ を求めよ（実際、この方程式の解は $1, 2, 3$ である）。

    **思路**：把系数代入根与系数关系，再用实际的解验算一遍。

    **解答**：和为 $6$，两两积之和为 $11$，积为 $6$。验算：$1 + 2 + 3 = 6$，$1\cdot2 + 2\cdot3 + 3\cdot1 = 11$，$1\cdot2\cdot3 = 6$，一致。

    **答案**：$6$、$11$、$6$

## 易错点

- [ ] 二项式定理里漏掉 $(2x)^{5-k}$ 中系数 $2$ 的幂
- [ ] 混淆「実数解の個数」与「解の個数（含复数）」
- [ ] 分数式计算时无视分母 ≠ 0 的条件与约分前的形式
- [ ] 根与系数关系的符号记错（特别是 $\alpha\beta\gamma = -r$）
