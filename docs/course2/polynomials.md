## 1. 恒等式と等式・不等式の証明

$f(x) \equiv g(x)$ は「すべての $x$ について $f(x) = g(x)$ が成り立つ」ことである。恒等式が成り立つのは、両辺の**同じ次数の係数がすべて等しい**ときであり、係数比較か、適当な $x$ の値を代入して得られる連立方程式（待定係数法）で係数を決める。

等式の証明は、左辺 − 右辺 $= 0$ を示すか、両辺を別々に変形して同じ形にする。不等式の証明では、差が $0$ 以上であることを平方完成などで示す。基本になる不等式は次の 2 つである。

$$
a^2 + b^2 \geqq 2ab, \qquad a + b \geqq 2\sqrt{ab} \quad (a > 0,\ b > 0)
$$

後者は相加平均と相乗平均の関係で、等号が成り立つのは $a = b$ のときである。**等号成立条件を書き添える**のが証明の作法である。

## 2. 二項定理

$$
(a+b)^n = \sum_{k=0}^{n} {}_n\mathrm{C}_k\, a^{n-k} b^k
$$

一般項は ${}_{n}\mathrm{C}_{k}\, a^{n-k} b^{k}$ で、$k = 0, 1, \dots, n$ に対して係数は ${}_n\mathrm{C}_k = {}_n\mathrm{C}_{n-k}$ を満たす。係数の並びはパスカルの三角形

$$
{}_{n+1}\mathrm{C}_k = {}_n\mathrm{C}_k + {}_n\mathrm{C}_{k-1}
$$

に従う。特定の項の係数を求めるときは、まず一般項を書き、求める文字の指数から $k$ を決める。

## 3. 複素数と高次方程式

$i^2 = -1$ とし、複素数 $a + bi$ の共役複素数を $a - bi$ という。**実数係数の方程式が虚数解をもつとき、その共役も解になる**。したがって実数係数の 3 次方程式は少なくとも 1 つの実数解をもつ。

**剰余の定理**：整式 $f(x)$ を $x - \alpha$ で割った余りは $f(\alpha)$ である。

**因数の定理**：

$$
f(\alpha) = 0 \iff (x - \alpha) \mid f(x)
$$

高次方程式は、因数の定理で 1 つの解を見つけて次数を下げ、残りを 2 次方程式として解くのが基本である。

**解と係数の関係**：3 次方程式 $x^3 + ax^2 + bx + c = 0$ の 3 解を $\alpha, \beta, \gamma$ とすると

$$
\alpha + \beta + \gamma = -a, \qquad \alpha\beta + \beta\gamma + \gamma\alpha = b, \qquad \alpha\beta\gamma = -c
$$

$\alpha^2 + \beta^2 + \gamma^2 = (\alpha + \beta + \gamma)^2 - 2(\alpha\beta + \beta\gamma + \gamma\alpha)$ のように、対称式はこの 3 つの基本対称式で表せる。

## 例題（演習）

!!! note "例題の扱いについて"
    本ページの例題は、真題の出題形式（穴埋め式）に合わせた自作の演習問題である。EJU の試験問題は JASSO の著作物のため本站には転載しない。真題そのものは [JASSO 公式の過去問題サンプル](https://www.jasso.go.jp/ryugaku/eju/examinee/pastpaper_sample/) で確認できる。

??? example "例題 1：二項定理の係数"
    $(2x - 1)^5$ の展開式における $x^3$ の係数を求めよ。

    **考え方**：一般項を書き、$x$ の指数が $3$ になる $k$ を決める。

    **解答**：一般項は ${}_5\mathrm{C}_k (2x)^{5-k}(-1)^k$ である。$5 - k = 3$ より $k = 2$ となり、係数は

    $$
    {}_5\mathrm{C}_2 \cdot 2^3 \cdot (-1)^2 = 10 \times 8 = 80
    $$

    **答え**：$80$

??? example "例題 2：因数の定理による因数分解"
    $f(x) = x^3 - 2x^2 - 5x + 6$ を因数分解せよ。

    **考え方**：$f(1) = 0$ であることに気づき、$(x - 1)$ で割って次数を下げる。

    **解答**：$f(1) = 1 - 2 - 5 + 6 = 0$ より、$f(x)$ は $(x - 1)$ で割り切れる。割り算を行うと

    $$
    f(x) = (x - 1)(x^2 - x - 6) = (x - 1)(x - 3)(x + 2)
    $$

    **答え**：$(x - 1)(x - 3)(x + 2)$

??? example "例題 3：解と係数の関係"
    3 次方程式 $x^3 - 6x^2 + 11x - 6 = 0$ の 3 解を $\alpha, \beta, \gamma$ とするとき、$\alpha^2 + \beta^2 + \gamma^2$ の値を求めよ。

    **考え方**：解を実際に求めず、解と係数の関係から対称式の値を出す。

    **解答**：解と係数の関係より $\alpha + \beta + \gamma = 6$、$\alpha\beta + \beta\gamma + \gamma\alpha = 11$ であるから

    $$
    \alpha^2 + \beta^2 + \gamma^2 = (\alpha + \beta + \gamma)^2 - 2(\alpha\beta + \beta\gamma + \gamma\alpha) = 36 - 22 = 14
    $$

    **答え**：$14$

## よくあるミス

- [ ] 二項定理の一般項で、$(2x)^{5-k}$ のように**係数 $2$ の累乗を忘れる**
- [ ] 剰余の定理で、$x - \alpha$ で割った余りは $f(\alpha)$ であるのに、$f(-\alpha)$ と取り違える
- [ ] 実数係数の方程式の虚数解について、共役も解になることを使わずに解を 1 つしか挙げない
- [ ] 解と係数の関係で、$x^3 + ax^2 + bx + c = 0$ の 3 解の積が $-c$ であること（符号）を間違える
- [ ] 不等式の証明で、等号成立条件を書かない
