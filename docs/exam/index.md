# EJU 数学考试总览

日本留学试验（EJU）数学分为两个课程：

- **Course 1（コース1）**：供需要基础数学的学部・学科（文科及对数学要求相对较低的理科）；
- **Course 2（コース2）**：供需要较高数学的学部・学科（理科）。

??? info "课程的选择"
    报考哪个 Course 由**志愿大学的学部・学科指定**决定。考生在考试当天二选一，问题册是同一本（两册合一）。

## 考试形式

| 项目 | 内容 |
| --- | --- |
| 考试时长 | 80 分钟 |
| 形式 | **穴埋め式**（把数字、符号、文字填入空格并在答题卡上涂记），不是四选一的选择题 |
| 满分 | 200 分（实行得点调整／分数等化） |
| 计算工具 | 不可使用计算器 |

!!! tip "穴埋め式意味着什么"
    没有选项可排除，答案必须以题目指定的形式（最简分数、根式形式等）精确填入。计算过程的准确性与答案形式的规范性直接决定得分；再加上题干是日语，**读题速度**是第一道门槛——这也是本站例题题面坚持用日语的原因。

## 出题范围结构

出题项目共 20 项，Course 1 考项目 1〜7，Course 2 考项目 1〜20 全部。详情见 [出題範囲（シラバス）](syllabus.md)。

=== "Course 1（項目 1〜7）"

    | 领域 | 大致比重（参考） |
    | --- | --- |
    | 数と式、集合と命題 | ~10% |
    | 2次関数 | ~20% |
    | 図形と計量 | ~15% |
    | 場合の数と確率（含期待値） | ~20% |
    | 整数の性質 | ~15% |
    | 図形の性質 | ~20% |

=== "Course 2（項目 1〜20）"

    | 领域 | 大致比重（参考） |
    | --- | --- |
    | 项目 1〜7（Course 1 范围） | 作为基础随处出现 |
    | いろいろな式、図形と方程式 | ~10% |
    | 三角関数、指数関数・対数関数 | ~15% |
    | 数列、確率分布、ベクトル、複素数平面、式と曲線、関数、極限 | ~35% |
    | 微分法、積分法 | ~30% |

> 比重是根据近年出题估计的参考值，官方不公布精确配点（因实行得点调整）。
