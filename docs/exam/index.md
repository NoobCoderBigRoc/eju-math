# EJU 数学考试总览

日本留学试验（EJU，日本留学生考试）数学分为两门：

- **数学 1（Course 1）**：面向文科及部分理科、艺术类学部；
- **数学 2（Course 2）**：面向理工科学部。

??? info "选考规则"
    报考哪个 Course 由**志愿学部的要求**决定。同一考生一次考试只考其中一门。

## 考试形式

| 项目 | 说明 |
| --- | --- |
| 考试时长 | 80 分钟（记述科目之外，数学单独计时） |
| 题型 | 全部为**选择题**（四选一），题干以日语出题 |
| 评分 | 200 分满点，采用**得分等化**（不同年份/科目换算） |
| 计算工具 | 不可使用计算器 |

!!! tip "与国内高考的核心差异"
    EJU 数学**全部为选择题**，且部分题目可用代值、画图、特殊化等技巧快速排除选项；但题干语言为日语，**审题速度**是第一道门槛。

## 内容结构

=== "Course 1（文科数学）"

    | 板块 | 大致占比 |
    | --- | --- |
    | 数与式、集合与命题 | ~10% |
    | 二次函数 | ~20% |
    | 图形与计量（三角比） | ~15% |
    | 概率 | ~15% |
    | 数据的统计分析 | ~15% |
    | 整数的性质 | ~10% |
    | 图形的性质 | ~15% |

=== "Course 2（理科数学）"

    | 板块 | 大致占比 |
    | --- | --- |
    | 式与证明、高次方程 | ~10% |
    | 图形与方程 | ~10% |
    | 三角函数、指数对数 | ~20% |
    | 数列、向量、复数平面 | ~30% |
    | 微分与积分 | ~30% |

> 占比为根据近年真题的估计值，官方不公布精确分值（得分等化）。
