# EJU 数学 試験の概要

日本留学試験（EJU）の数学には 2 つのコースがある：

- **コース1**：基礎的な数学を必要とする学部・学科のため（文系学部および数学を必要とする程度が比較的少ない理系学部用）；
- **コース2**：より高度な数学を必要とする学部・学科のため（理系学部用）。

??? info "コースの選択"
    どちらのコースを受験するかは、**志望する大学の学部・学科の指定**に従う。受験者は試験当日に一方を選択する。問題冊子は 1 冊にまとまっている。

## 試験形式

| 項目 | 内容 |
| --- | --- |
| 試験時間 | 80 分 |
| 形式 | **穴埋め式**（空欄に数字・符号・文字を記入し、解答用紙にマークする）。四者択一の選択式ではない |
| 配点 | 200 点満点（得点調整が行われる） |
| 計算道具 | 電卓は使用できない |

!!! tip "穴埋め式の意味すること"
    選択肢がないため、答えは指定された形式（最も簡単な分数、根号の形など）で正確に記入しなければならない。計算過程の正確さと答えの形式の整え方が、そのまま得点に直結する。

## 出題範囲の構成

出題項目は全 20 項目で、コース1 は項目 1〜7、コース2 は項目 1〜20 のすべてが出題範囲である。詳細は [出題範囲（シラバス）](syllabus.md) を参照。

=== "コース1（項目 1〜7）"

    | 分野 | 大まかな比重（目安） |
    | --- | --- |
    | 数と式、集合と命題 | ~10% |
    | 2次関数 | ~20% |
    | 図形と計量 | ~15% |
    | 場合の数と確率（期待値を含む） | ~20% |
    | 整数の性質 | ~15% |
    | 図形の性質 | ~20% |

=== "コース2（項目 1〜20）"

    | 分野 | 大まかな比重（目安） |
    | --- | --- |
    | 項目 1〜7（コース1 の範囲） | 基礎として随所に出題 |
    | いろいろな式、図形と方程式 | ~10% |
    | 三角関数、指数関数・対数関数 | ~15% |
    | 数列、確率分布、ベクトル、複素数平面、式と曲線、関数、極限 | ~35% |
    | 微分法、積分法 | ~30% |

> 比重は近年の出題に基づく目安であり、公式に公表された配点ではない（得点調整のため）。
