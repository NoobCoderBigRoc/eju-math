# 学習戦略

## 3 周の学習サイクル

```mermaid
graph LR
  A[第1周<br>知識の体系化] --> B[第2周<br>分野別の演習]
  B --> C[第3周<br>模擬演習]
  C --> A
```

### 第 1 周：知識ツリーを作る（4〜6 週間）

- 本サイトの項目順に進み、各章の公式を自分の手で書き出せる状態にする；
- 難しい問題は追わず、「問題文を見て項目と使う公式が分かる」ことを目標にする。

### 第 2 周：分野別の演習（3〜4 週間）

- 間違えた問題を分野ごとに分類し、各分野で繰り返し出る型を固める；
- コース1 は**整数の性質**、コース2 は**微分法・積分法の総合問題**を重点的に。

### 第 3 周：時間を計る演習（試験前 3 週間）

- 80 分を厳密に計って解く習慣をつける；
- 特殊値の代入・端点の確認・図による見積もりなど、**自分の答えを検算する**技術を身につける（穴埋め式には選択肢がないため、検算が生命線になる）。

## 穴埋め式への対策

!!! example "特殊値の代入（検算）"
    恒等式や関数の性質を問う問題では、$x = 0, 1, -1$ などを代入して自分の答えと矛盾しないか確認する。矛盾があれば計算に戻る合図である。

!!! example "極端な場合の確認（検算）"
    確率や数列の問題では、$n = 1, 2$ の場合や、面積が 0 に近づく極端な場合で答えが妥当か確かめる。

!!! warning "頻出の失点パターン"
    - 日本語の問題文の否定表現（〜ない、〜でない）を読み違える；
    - 求める量を取り違える（$a$ か $a^2$ か、確率か期待値か）；
    - 答えの形式が指定と違う（約分していない、根号の形が最簡でない）；
    - 解答用紙のマークの位置がずれる（穴埋め式では致命的）。
