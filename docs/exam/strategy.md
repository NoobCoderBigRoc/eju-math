# 备考策略

## 三轮学习循环

```mermaid
graph LR
  A[第1轮<br>知识体系化] --> B[第2轮<br>按领域刷题]
  B --> C[第3轮<br>限时模拟]
  C --> A
```

### 第 1 轮：搭知识树（4〜6 周）

- 按本站项目顺序推进，每章公式能默写、术语（日语）能认读；
- 不追求难题，目标是「看到题面能判断属于哪个项目、用哪个公式」。

### 第 2 轮：按领域刷题（3〜4 周）

- 错题按领域归类，把每个领域反复出现的题型练熟；
- Course 1 重点放在**整数の性質**，Course 2 重点放在**微分法・積分法的综合题**。

### 第 3 轮：限时训练（考前 3 周）

- 严格按 80 分钟计时成套做题；
- 练验算技术：代入特殊值、检查端点、画图估算——穴埋め式没有选项可排除，**验算是生命线**。

## 穴埋め式对策

!!! example "代入特殊值（验算）"
    问恒等式、函数性质的题目，把 $x = 0, 1, -1$ 代入自己的答案看是否矛盾。矛盾就是回到计算的信号。

!!! example "检查极端情形（验算）"
    概率、数列类题目，用 $n = 1, 2$ 的小情形或面积趋近 0 的极端情形验证答案是否合理。

!!! warning "高频失分模式"
    - 读错日语题面的否定表达（〜ない、〜でない）；
    - 求错对象（问的是 $a$ 还是 $a^2$，是確率还是期待値）；
    - 答案形式不符合指定（没约分、根式不是最简形式）；
    - 答题卡涂错位（穴埋め式下这是致命伤）。
